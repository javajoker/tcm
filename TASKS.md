## How to use this list

- **One task = one commit** (project rule). The commit message is `type(scope): summary` with the task id in the body. Regenerated `data/` goes in the same commit as the generator change.
- **Status:** `[x]` done · `[ ]` to do. Update this file in the commit that completes the task.
- **Priority:** **P0** MVP must-have · **P1** MVP should-have · **P2** post-MVP.
- **Size:** **S** ≤ ½ day · **M** 1–2 days · **L** 3–5 days · **XL** > 1 week (split before starting if possible).
- **Deps:** task ids that must be done (or at least started with a stable interface) first.
- **Done when:** the acceptance criterion; the general definition of done in [`CHECKLIST.md`](CHECKLIST.md) §1 always applies as well.
