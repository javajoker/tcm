# Accessibility records

One file per release candidate: copy [`TEMPLATE.md`](TEMPLATE.md) to `<release>.md` (for example `0.1.0-rc1.md`), fill it in while running the pass of the [accessibility protocol](../accessibility-protocol.md), and link it from the release checklist (§6). Records are kept in the repository so that results stay comparable between releases and the release decision can show its evidence. They contain **no health data**: use the synthetic sample person.
