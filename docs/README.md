## Precedence when documents disagree

1. **Numbers in `data/`** beat numbers in prose.
2. **Diagnosis SOP** (logic) → **algorithm spec** (five-phase maths) → **PRD** (requirements) → **tech spec / UX spec** (how it is built and shown).
3. **Safety policy** owns notice wording and safety behaviour; **i18n guide** owns terminology and forbidden wording; both override copy in the UX spec.
4. A conflict is a documentation bug: fix the lower-precedence document and note it in its changelog.

## Language rule

All documents are English **except** the diagnosis SOP, which is Traditional Chinese (Taiwan wording), the Traditional Chinese translation of the algorithm spec (`wuxing-algorithm.zh-TW.md`, kept in sync with the authoritative English version), the learning book (`book/zh-Hant/`) and the course with its textbook (`course/zh-Hant/`), both Traditional Chinese only, by the owner's choice. User-visible app text is `zh-Hant` by default with an English translation.
