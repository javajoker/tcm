# 九、方劑：一首方的分工

## 一個問題

一首方是幾味藥的清單，還是一個分工明確的團隊？如果是團隊，能不能量出每個人出了多少力？

## 中醫怎麼看

> 「主病之謂君，佐君之謂臣，應臣之謂使。」——《素問·至真要大論》

> 「君一臣二，制之小也。」——《素問·至真要大論》

> 「當用相須、相使者良，勿用相惡、相反者。若有毒宜制，可用相畏、相殺者。」——《神農本草經·序錄》

例如小柴胡湯中的半夏與生薑：

> 「半夏有毒，用之必須生薑，此是取其所畏，以相制耳。」——《本草經集注·序錄上》

## 模型怎麼寫

App 把方中每味藥的作用加起來，再算上它們之間的七情，得到整方的作用；選方，就是找出最能把帳上的偏差拉回零點的方。方解寫成五步，每一步都有數字：

1. **病機**：偏差最大的幾處，例如脾氣虛、心血虛。
2. **治法**：方的治法，以及它真正照顧到哪幾處。
3. **方**：整體能把偏差拉回多少。
4. **藥**：每味藥各自出了多少力，合起來恰好等於整方。
5. **未盡**：還沒拉回的部分——這就是加減的理由。

既然知道每味藥出了多少力，就能回頭檢查古人的分工。量出來的結果大多與古人的標記相符；不相符的地方，App 不擅自改標記，而是列給醫師審閱。例如補中益氣湯的黃耆，在盤面上補脾氣的力量不如人參，但它的「升陽」是方向，不是份量。三十三首方劑都這樣逐一檢查，報告只列問題，不自動修改。

## 兩相對照

古人用「分工」描述方劑，模型用「貢獻」描述；兩者互相檢查，不一致之處往往最有啟發——有時是模型看不見的東西，有時是資料的缺漏。

**模型的簡化：** 盤面沒有「少陽」，所以和解少陽的方劑在模型裡看起來作用不大——這是模型的盲點，不是方劑的問題；劑型與煎服法也不進入計算。
