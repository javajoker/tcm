# 二、陰陽：一把尺

在 App 裡，陰陽不是一個玄妙的總結，而是**有正有負的尺**。每一把尺都以「平均健康的人」為零點，偏向一端就是一種失衡。

> 「病有總要，寒、熱、虛、實、表、裡、陰、陽，八字而已。」——《醫學心悟·寒熱虛實表裡陰陽辨》

## 三把尺

| 尺 | 範圍 | 讀法 |
|---|---|---|
| 寒熱 | −1（寒）… +1（熱） | 火、暑、陰虛把它往熱推；寒、陽虛把它往寒推 |
| 虛實 | −1（虛）… +1（實） | 虛損把它往虛推；邪氣、痰瘀、氣滯把它往實推 |
| 表 | 0 … 1 | 外感初起、惡寒為主時才升高 |

陰陽總綱由這三把尺推得，不另外計算。

> 「陰勝則陽病，陽勝則陰病。陽勝則熱，陰勝則寒。」——《素問·陰陽應象大論》

> 「陽虛則外寒，陰虛則內熱。」——《素問·調經論》

這兩句正是寒熱尺的寫法：陽虛的人會被算成偏寒，陰虛的人會被算成偏熱，即使他們沒有感受外邪。

## 先看地圖，再定八綱

問診時，App 會先依幾個關鍵症狀做「八綱初判」，但這個初判**只用來決定問哪些題、檢查答案是否矛盾**。真正的八綱，是等全部證據合成盤面之後才由盤面算出來的。這樣做是為了避免被單一症狀牽著走——寒熱真假、虛實夾雜，都要看整體。

> 「邪氣盛則實，精氣奪則虛。」——《素問·通評虛實論》

**模型的簡化：** 「半表半裡」不放在尺上，而由證型的分流處理；寒熱錯雜、虛實夾雜時，App 不硬算一個平均，而是標示「錯雜」並降低信心、建議就醫。
