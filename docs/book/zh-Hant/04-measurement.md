# 四、量測：由外知內

## 一個問題

看不見臟腑，怎麼知道裡面發生了什麼？量到的東西，又有多可信？

## 中醫怎麼看

> 「有諸內者形諸外。」——《丹溪心法·能合色脈可以萬全》

內在的變化一定會表現在外面，所以望色、聽聲、問寒熱、按脈，都是量測。量測有條件，古人連時間都規定了：

> 「診法常以平旦。」——《素問·脈要精微論》

舌也有分區，各部對應不同的臟腑：

> 「滿舌屬胃。中心亦屬胃。舌尖屬心。舌根屬腎。兩旁屬肝膽。四畔屬脾。」——《傷寒指掌·察舌》

## 模型怎麼寫

App 看不到也摸不到，所以以問診為核心：沿用十問歌，再補上睡眠與情志，共十二個面向，並依前面的回答決定下一題，先問最能分辨兩個相近證型的題目。每一筆資料都標上可信度：

| 資料 | 係數 |
|---|---|
| 自述的症狀 | 1.0 |
| 器材量到的脈率 | 0.9 |
| 依指引自己看的舌象、面色 | 0.7 |
| 自己判斷的脈象 | 0.5 |

明確回答「沒有」，是一筆反對的證據；回答「不確定」或跳過，不計分，但會降低信心。在一切之前，App 先問一組該立刻就醫的問題；回答「是」，甚至只是「不確定」，都先顯示就醫通知。

> 「小大不利治其標，小大利治其本。」——《素問·標本病傳論》

## 兩相對照

醫者的眼與手經過多年訓練，是精密的儀器；App 只能讀使用者自己的觀察，所以把每一筆資料的可信度寫在明處，而不是假裝它看得見。

**模型的簡化：** 望、切兩診只能讀使用者自己的觀察，因此被打折；聞診只靠自述；自己看舌仍可能受光線、飲食與染苔影響。
