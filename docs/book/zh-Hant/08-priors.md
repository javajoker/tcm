# 八、天時與先天：先驗不等於診斷

中醫講天人相應：季節、年運，甚至出生的時刻，都可能影響一個人的偏向。App 把這些放在一張**個人化常模盤面**上，但給它戴上兩副枷鎖：有上限、不加分。

> 「必先歲氣，無伐天和。」——《素問·五常政大論》

## 三塊參照

| 塊 | 從哪裡來 | 上限 |
|---|---|---|
| 先天 | 生辰八字（自願提供，預設不開） | ±1.0 |
| 流年 | 八字流年，加上五運六氣 | ±0.75、±0.5 |
| 時令 | 四氣調神：春肝、夏心、長夏脾、秋肺、冬腎 | 當令 +0.5 |

> 「春三月，此謂發陳。」——《素問·四氣調神大論》

> 「歲木太過，風氣流行，脾土受邪。」——《素問·氣交變大論》

三塊加總後再設上限，映射到五臟時只動氣與陽（功能），不動血與陰（物質）。

## 先驗不製造、也不掩蓋證據

這是整個模型最重要的一條規則：

1. 證型的分數**只用症狀與體徵**；八字、年運、季節不加分。
2. 你實際的偏差（與平均健康的人相比）**不會被先驗抵銷**。八字說「木弱」，不能把真實的肝系症狀解釋掉。
3. 先驗只用在四個地方：兩個證型幾乎平手時的裁決、預防與調養的方向、時令易感的提醒、以及解釋。

App 也會比較你的實際偏差與常模的方向：同向，可能偏體質性；反向（例如常模偏旺、症狀卻顯示虛），多半是後天的飲食勞倦所致。

> 「同時得病，其病各異。」——《靈樞·五變》

**模型的簡化與地位：** 八字是傳統文化的先驗，沒有臨床驗證；五運六氣是古籍理論，預測力有爭議；時令最為通用。三者都只是有上限、可關閉、分開呈現的參照。
