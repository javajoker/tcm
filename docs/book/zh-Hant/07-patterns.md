# 七、辨證：由證據推病機

辨證是推論：手上有一堆證據，要找出最能解釋它們的病機。App 的做法很樸素，但每一步都說得出理由。

## 計分

每個證型都有一張表：哪些症狀支持它（權重 1–3），哪些症狀反對它，哪些症狀至少要有一個（必要症狀）。

```
得分 = Σ（支持的症狀 × 權重 × 輕重 × 可信度） − Σ（反對的症狀 × 權重 × 可信度）
百分比 = 得分 ÷ 滿分；必要症狀一個都沒有，百分比減半
```

輕重分輕、中、重（0.6、0.8、1.0）；可信度見上一章。百分比 60 以上算「典型」，40 到 59 是「傾向」，20 到 39 只是「提示」。

> 「但見一證便是，不必悉具。」——《傷寒論·辨太陽病脈證並治中》

App 的版本是：不必所有症狀都有，但**關鍵症狀**要在；少了它，分數就打對折。

## 鑑別

最可能的兩個證型分數接近時，App 會找出「A 很看重而 B 不看重」的症狀，追問下去；結果頁也會說明：「如果還有某某症狀，會更偏向哪一個證。」

## 信心

結論可不可靠，看三件事：核心題答了多少、第一名領先第二名多少、資料整體的可信度。三者都夠，信心才高；資料不足時，App 會說「資訊不足」，而不是硬給一個答案，並且只提供一般調養。

> 「謹察陰陽所在而調之，以平為期。」——《素問·至真要大論》

## 當證型庫裡找不到

證型庫目前收錄 23 個常見證型。如果症狀不落在其中任何一個，App 會改用證素（病位 + 病性）拼出一個描述，例如「脾、濕」，並明說這是組合出來的。

**模型的簡化：** 權重是根據教材與古籍擬定的草稿，尚待醫師校準；寒熱錯雜、虛實夾雜的病人，App 會標示錯雜、降低信心、建議就醫，而不嘗試細分。
