# 以模型讀中醫——這個 App 怎麼想

寫給熟悉中華文化、讀得懂古文、想用最少時間弄懂這個 App 思路的讀者。十二章，每章一個想法，大約五分鐘讀完。

三個約定：

1. **引文都經過核對。** 書中每一段古籍引文，都已在專案收錄的原典中逐字找到（出處標在引文後）。
2. **只講道理，不談用藥。** 本書解釋 App 如何思考，不教人抓藥；書中沒有任何份量，也不建議任何人服用什麼。是否用藥、如何用藥，必須由執業中醫師親自診察後決定。
3. **模型不是醫師。** App 把傳統的思路寫成可以計算、可以追溯的規則；它整理證據、說明理由，但看不到舌、摸不到脈，也不替任何人做決定。
