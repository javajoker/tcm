# 以模型讀中醫——這個 App 怎麼想

一本短書，換一個角度讀中醫。教科書問的是「中醫說什麼」；這本書問的是：如果要把中醫寫成一個可以計算、可以檢查的模型，得從哪些角度看它？十二章，每章一個角度，先說中醫怎麼看，再說 App 怎麼寫，最後兩相對照，並說出模型簡化了什麼。每章大約五分鐘讀完。

本書與[《中醫學系統課程》](../../course/zh-Hant/README.md)是一套：課程有系統地講中醫本身，本書看這些道理怎樣成為 App 的模型。兩者可以分開讀；想打好基礎，先讀課程。

三個約定：

1. **引文都經過核對。** 書中每一段古籍引文，都已在專案收錄的原典中逐字找到（出處標在引文後）。
2. **只講道理，不談用藥。** 本書解釋 App 如何思考，不教人抓藥；書中沒有任何份量，也不建議任何人服用什麼。是否用藥、如何用藥，必須由執業中醫師親自診察後決定。
3. **模型不是醫師。** App 把傳統的思路寫成可以計算、可以追溯的規則；它整理證據、說明理由，但看不到舌、摸不到脈，也不替任何人做決定。
