# 十一、因人因時因地：同病異治

同樣的證，不同的人、不同的季節、不同的地方，用藥也該不同。這就是三因制宜。

> 「聖人雜合以治，各得其所宜。故治所以異而病皆愈者，得病之情，知治之大體也。」——《素問·異法方宜論》

## App 怎麼做

從推薦的方劑出發，依序：

1. **先去掉這個人不能用的藥**：懷孕應避免的、與過敏相符的、與正在使用的藥物相衝的。如果被去掉的是君藥，就**整個不列**，並說明原因——沒有君的方，不成方。
2. **古籍的加減**：如果你剛好有某個加減法所針對的症狀，就照書加減，並註明出處。
3. **照顧未盡之處**：看看還有哪些偏差沒有拉回，從可用的藥中挑最合適的；連同上一步照書加入的，全方最多加兩味。挑選看的是**它能治什麼**；它也必須避開你的禁忌、你的體質所不宜，以及與方中藥物相惡、相反的。
4. **定份量**（只在開發版本中顯示，供醫師參考）：君藥先放在藥典範圍的中間，其餘按原方比例，再依下面的因素調整。

## 調整的因素

| 因素 | 依據 | 怎麼調 |
|---|---|---|
| 病勢 | 能毒者以厚藥 | 偏差輕則輕用，重則略重 |
| 年齡 | 人之勝毒，各有不同 | 小兒依年齡減量；年長者約三分之二 |
| 體質 | 寒者熱之，熱者寒之 | 陽虛者減寒涼、陰虛者減溫燥、痰濕者減滋膩 |
| 季節 | 用寒遠寒，用熱遠熱 | 春夏減溫熱、秋冬減寒涼，春秋減得較輕，長夏不調；君藥不減 |
| 地域 | 西北之氣散而寒之 | 目前不調整，等各地的規則經過確認 |

> 「能毒者以厚藥，不勝毒者以薄藥。」——《素問·五常政大論》

> 「胃厚、色黑、大骨及肥骨者，皆勝毒；故其瘦而薄胃者，皆不勝毒也。」——《靈樞·論痛》

> 「用寒遠寒，用涼遠涼，用溫遠溫，用熱遠熱，食宜同法。」——《素問·六元正紀大論》

> 「西北之氣散而寒之，東南之氣收而溫之，所謂同病異治也。」——《素問·五常政大論》

季節為什麼不動君藥？因為同一篇裡，黃帝問到不避寒熱時怎麼辦，岐伯答：

> 「發表不遠熱，攻裡不遠寒。」——《素問·六元正紀大論》

治療真正需要時，季節不擋路。君藥是對著病機去的，所以它的份量留給病來決定，只有其餘的藥隨季節增減。

另外有幾條不變的原則：毒性藥永遠不因任何因素加量；任何份量都不超過藥典範圍的上限。

## 誰看得到

公開版本看得到推薦的方名，看不到加減與份量。加減與份量只在開發版本中，以「供中醫師參考」的形式呈現——開立處方是醫師的專業行為，在多數地方受法律規範。

**模型的簡化：** 這些因素與係數都是草稿，尚待醫師與藥師審定；地域規則尚未啟用。
