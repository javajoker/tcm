# 三、狀態：人體的帳本

## 一個問題

要說一個人「偏了」，先得知道記哪些帳：哪裡多了，哪裡少了，多少才算偏？

## 中醫怎麼看

臟腑是功能的系統，氣血津液是在其中生成、運行、消耗的東西；邪氣與痰瘀是外來或內生的負擔；營在脈中，衛在脈外。

> 「其清者為營，濁者為衛，營在脈中，衛在脈外。」——《靈樞·營衛生會》

> 「衛氣者，所以溫分肉，充皮膚，肥腠理，司開闔者也。」——《靈樞·本藏》

> 「血氣不和，百病乃變化而生。」——《素問·調經論》

## 模型怎麼寫

App 的帳叫做盤面，全部從「平均健康的人」的零點起算：

| 層 | 記什麼 | 範圍 |
|---|---|---|
| 臟腑 | 肝心脾肺腎與膽、小腸、胃、大腸、膀胱，各記氣、血、陰、陽 | −3 … +3 |
| 氣滯 | 各臟腑之氣是否鬱滯 | 0 … 3 |
| 六邪 | 風、寒、暑、濕、燥、火 | 0 … 3 |
| 病理產物 | 痰、飲、瘀、食積 | 0 … 3 |
| 營衛 | 衛氣、營氣，以及衛所主司的腠理開闔 | −3 … +3 |

每個證型由一兩個證素——病位乘上病性——入帳。古人說：

> 「脾氣虛則四肢不用。」——《靈樞·本神》

App 則把脾氣虛記為脾的氣減一分；腎陽虛記為腎的陽減一分，同時寒增一分半。兩個證型說的是同一件事時（例如脾氣虛與中氣下陷），帳上以「飽和」的方式合成，越接近上限越難再加，不會重複記兩次。

## 兩相對照

帳上的「寒」可能來自外感，也可能來自陽虛；看是哪個證型把它帶上帳，就知道它從哪裡來——中醫說的「審證求因」，在模型裡就是這筆帳的來歷。帳本只記結果，原因與機理由推理說明，這讓兩者不會混在一起。

**模型的簡化：** 津液沒有單獨一欄，主要藉陰、燥、飲、痰表現；經絡、三焦與奇恆之腑不在帳上；衛氣晝行於陽、夜行於陰與睡眠的關係，只用來解釋，不入帳。
