# 六、時間：一日、一年、一生

## 一個問題

同一個人，早晨與夜晚、春天與冬天、二十歲與七十歲，是同一個人嗎？天時與生辰，能說明多少？

## 中醫怎麼看

中醫把人放在天時之中：一日之中有衛氣的出入，一年之中有四時與歲運，一生之中有腎氣的盛衰。

> 「氣至陽而起，至陰而止。」——《靈樞·營衛生會》

> 「春三月，此謂發陳。」——《素問·四氣調神大論》

> 「女子七歲，腎氣盛」——《素問·上古天真論》

> 「必先歲氣，無伐天和。」——《素問·五常政大論》

## 模型怎麼寫

App 把時間放在一張「個人化常模盤面」上，分成三塊：

| 塊 | 從哪裡來 | 上限 |
|---|---|---|
| 先天 | 生辰八字（自願提供，預設不開） | ±1.0 |
| 流年 | 八字流年，加上五運六氣 | ±0.75、±0.5 |
| 時令 | 四氣調神：春肝、夏心、長夏脾、秋肺、冬腎 | 當令 +0.5 |

三塊加總後再設上限，映射到五臟時只動氣與陽（功能），不動血與陰（物質）。最重要的一條規則：證型的分數只用症狀與體徵，八字、年運、季節都不加分；實際的偏差也不會被先驗抵銷。先驗只用在四個地方：兩個證型幾乎平手時的裁決、預防與調養的方向、時令易感的提醒，以及解釋。

## 兩相對照

傳統把人與天時連在一起，模型同意，卻把「天時」與「證據」分開記帳：同向的偏差可能是體質，反向的多半是後天的飲食勞倦；但無論哪一種，都不能用命理把真實的症狀解釋掉。

**模型的簡化與地位：** 八字是傳統文化的先驗，沒有臨床驗證；五運六氣是古籍理論，預測力有爭議；時令最為通用。三者都只是有上限、可關閉、分開呈現的參照；晝夜的規律只用來解釋。
