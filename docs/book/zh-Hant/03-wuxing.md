# 三、五行：五個抽屜與生剋

五行在 App 裡有兩種用法：一是**分類**，二是**關係**。

## 分類：五個抽屜

肝、心、脾、肺、腎各歸一行，五味、五色、五方、季節也各有歸屬。這些對應全部取自《素問》，例如：

> 「東方生風，風生木，木生酸，酸生肝，肝生筋，筋生心，肝主目。」——《素問·陰陽應象大論》

> 「酸入肝，辛入肺，苦入心，鹹入腎，甘入脾。」——《素問·宣明五氣》

App 用這些抽屜把臟腑的狀態加總成「五行功能值」：某一行的功能強弱，主要看它的臟（七成），也看它的腑（三成），取的是氣與陽——也就是功能，而不是物質。

## 關係：生剋乘侮

五行之間會互相牽動。古人說得很清楚：

> 「氣有餘則制己所勝而侮所不勝，其不及則己所不勝侮而乘之，己所勝輕而侮之。」——《素問·五運行大論》

> 「見肝之病，知肝傳脾，當先實脾。」——《金匱要略·臟腑經絡先後病脈證》

App 把這些話寫成五條規則，算出每一行的「傳變壓力」：

| 某一行 | 規則 | 被牽動的 |
|---|---|---|
| 有餘 | 制己所勝 | 它所剋的一行 |
| 有餘 | 侮所不勝 | 剋它的一行 |
| 有餘 | 子盜母氣 | 它的母行 |
| 不及 | 乘侮自深 | 自己 |
| 不及 | 母病及子 | 它的子行 |

傳變壓力**只用來解釋與提醒**：哪一臟可能被拖累、調養時要先護哪裡。例如脾土虛時，肺金也會受到「母病及子」的拖累，這正是「培土生金」的道理。它不會被加進你實際的症狀地圖裡。

> 「虛者補其母，實者瀉其子。」——《難經·六十九難》

**模型的簡化：** 傳變的強弱係數是待校準的線性近似；「亢則害，承乃制」那種自我調節的動態，模型只取了一步。
