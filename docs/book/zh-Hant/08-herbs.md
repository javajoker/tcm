# 八、本草：一味藥的座標

## 一個問題

一味藥，能不能像地圖上的一個點那樣描述？兩味藥放在一起，又會怎樣？

## 中醫怎麼看

古人用四氣、五味、升降浮沉、歸經與毒性描述藥性，還注意到質地、炮製與份量都會改變藥的方向：

> 「藥有酸、鹹、甘、苦、辛五味，又有寒、熱、溫、涼四氣，及有毒無毒。」——《神農本草經·序錄》

> 「酸鹹無升，甘辛無降，寒無浮，熱無沉，其性然也。」——《本草綱目·序例上·升降浮沉》

> 「凡藥輕虛者浮而升，重實者沉而降。」——《本草備要·藥性總義》

> 「葛根輕浮，少用則浮而外散，多用則沉而內降矣。」——《本草新編·葛根》

## 模型怎麼寫

每一味藥都有一組座標，每一維都由一條寫明的規則推得，並記下用了哪條規則——錯了，改規則，而不是改數字：

| 座標 | 怎麼來 |
|---|---|
| 四氣 | 大寒到大熱，記為 −3 到 +3 |
| 五味 | 酸、苦、甘、辛、鹹、淡、澀 |
| 歸經 | 依記載的順序，排在前面的分量較重 |
| 陰陽 | 氣占五成、味占三成、升降占兩成 |
| 五行 | 五味所入（六成）加上歸經的五行（四成） |
| 升降浮沉 | 藥的類別與功效、氣味、入藥部位，三者合成 |
| 毒性 | 無毒、小毒、有毒、大毒 |

藥效方面，App 假設效用會飽和——加倍不會加倍；負擔會加速——超過常量後增加得更快；有毒的藥永遠不加量。兩味藥之間的七情，從《本草綱目》讀出兩百多組，每一組都保留原文出處：

> 「有單行者，有相須者，有相使者，有相畏者，有相惡者，有相反者，有相殺者。」——《神農本草經·序錄》

## 兩相對照

座標讓七百多味藥可以互相比較，規則讓每個數字都查得到來歷。古人「少用、多用，方向不同」的觀察，模型只用飽和與負擔的假設作保守的近似；炮製則以分開記錄的品項表現，例如地黃與熟地黃。

**模型的簡化：** 座標由規則推得，是草稿；走守、剛柔、《藥品化義》的八個面向，目前只作說明，不進入計算。
