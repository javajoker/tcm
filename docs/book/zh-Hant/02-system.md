# 二、系統：平衡與回饋

## 一個問題

人體這麼複雜，為什麼中醫只用幾對概念，就能描述一整個人？

## 中醫怎麼看

陰陽是一對互相制約、又互相依存的量；五行是五個互相資生、互相約束的部分。健康不是某個量越大越好，而是彼此維持在適當的範圍；一方過強，就有另一方來制約它。

> 「亢則害，承乃制。」——《素問·六微旨大論》

> 「病有總要，寒、熱、虛、實、表、裡、陰、陽，八字而已。」——《醫學心悟·寒熱虛實表裡陰陽辨》

## 模型怎麼寫

App 把陰陽寫成三把以「平均健康的人」為零點的尺，陰陽總綱由它們推得：

| 尺 | 範圍 | 讀法 |
|---|---|---|
| 寒熱 | −1（寒）… +1（熱） | 火、暑、陰虛往熱推；寒、陽虛往寒推 |
| 虛實 | −1（虛）… +1（實） | 虛損往虛推；邪氣、痰瘀、氣滯往實推；汗出往虛，無汗往實 |
| 表 | 0 … 1 | 外感初起、惡寒為主時升高 |

五行則有兩種用法。一是歸類：某一行的強弱，主要看它的臟（七成），也看它的腑（三成），取的是氣與陽。二是關係：某一行有餘時，壓力傳向它所勝的一行、克它的一行與它的母行；不及時，落在它自己與它的子行。

> 「氣有餘則制己所勝而侮所不勝，其不及則己所不勝侮而乘之，己所勝輕而侮之。」——《素問·五運行大論》

## 兩相對照

寫成數字之後，「平衡」有了零點，「偏」有了方向與大小，治療的目標也就成了一件可以計算的事：

> 「謹察陰陽所在而調之，以平為期。」——《素問·至真要大論》

系統的眼光也說明了為什麼中醫的治療很少只對著一個點：補脾，可能是為了護肺（培土生金）；疏肝，可能是為了護胃（抑木扶土）。但古人說的平衡是一刻不停的自我調節，模型看到的只是一個時刻；傳變壓力因此只用來解釋與提醒，不加進症狀的帳。

**模型的簡化：** 傳變的係數是線性近似，「亢則害，承乃制」那種反覆的調節只取了一步；寒熱錯雜、虛實夾雜時，App 標示「錯雜」，而不硬算一個平均。
