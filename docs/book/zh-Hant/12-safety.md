# 十二、安全與邊界

任何推薦都要先通過安全層。安全層不是事後的附註，而是寫在每一步裡的規則。

> 「無盛盛，無虛虛。」——《素問·五常政大論》

## 安全層做的事

| 規則 | 內容 |
|---|---|
| 紅旗 | 該立刻就醫的情況先問；回答「不確定」也當作「是」 |
| 範圍 | 未滿十八歲、懷孕、哺乳、重大疾病：降低可呈現的深度，並清楚說明 |
| 藥對 | 十八反、十九畏的藥對，永遠不同時出現 |
| 妊娠 | 標記為妊娠禁忌或慎用的藥，依規則移除或註記 |
| 藥物交互 | 依正在使用的藥物類別過濾，例如抗凝血藥 |
| 過敏 | 填寫的過敏，不論繁體或簡體寫法，都會比對 |
| 毒性 | 有毒的藥不會被自動加入，也永遠不會被加量 |

> 「藻戟遂芫俱戰草。諸參辛芍叛藜蘆。」——《本草便讀·十八反歌訣》

被規則移除的東西不會悄悄消失：結果頁會列出移除了什麼、為什麼。

## 醫師的判斷，App 不代勞

> 「有故無殞，亦無殞也。」——《素問·六元正紀大論》

這句話說的是：孕婦若真有病，用藥有時反而不傷胎。這是醫師親自診察後才能做的判斷，所以 App **不採用**它——在 App 裡，妊娠禁忌一律照規則處理。

## 邊界

- App 的規則與數據都是草稿，尚未經中醫師、藥師與醫師審閱；公開版本會清楚標示。
- App 只在使用者自己的裝置上運作，回答不會送到任何伺服器。
- 結果是一份整理過的參考，不是診斷，也不是處方。身體有狀況，請找醫師。

> 「聖人不治已病，治未病；不治已亂，治未亂。」——《素問·四氣調神大論》

這也是 App 最想做到的事：幫人更早看見自己的偏向，並把它帶去和醫師討論。

**模型的簡化：** 安全規則是條列的，涵蓋常見的情況，不可能窮盡；藥物交互只依藥物的類別判斷，不辨認填寫的每一個藥名。
