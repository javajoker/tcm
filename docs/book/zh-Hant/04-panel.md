# 四、臟腑與氣血津液：人體的帳本

如果把人體當成一本帳，App 記的是**與平均健康的人相比，哪裡多了、哪裡少了**。這本帳叫做「盤面」，全部從零起算。

## 帳上有什麼

| 層 | 記什麼 | 範圍 |
|---|---|---|
| 臟腑 | 肝心脾肺腎與膽、小腸、胃、大腸、膀胱，各記氣、血、陰、陽 | −3 … +3 |
| 氣滯 | 各臟腑之氣是否鬱滯 | 0 … 3 |
| 六邪 | 風、寒、暑、濕、燥、火 | 0 … 3 |
| 病理產物 | 痰、飲、瘀、食積 | 0 … 3 |
| 營衛 | 衛氣、營氣，以及衛所主司的腠理開闔（汗出為開，無汗為閉） | −3 … +3 |

> 「脾氣虛則四肢不用。」——《靈樞·本神》

> 「肝藏血，血舍魂。」——《靈樞·本神》

## 證素如何入帳

每個證型由一兩個**證素**組成——一個病位（如脾、肝、表）乘上一個病性（如氣虛、陽虛、濕、氣滯）。每個證素有固定的「入帳方式」，例如脾氣虛記為脾的氣減一分；腎陽虛記為腎的陽減一分，同時寒增一分半；肝氣鬱結記為肝的氣滯加一分。證型越典型，入帳的分量越重。

兩個證型若描述同一件事（例如脾氣虛與中氣下陷），帳上不會重複記兩次：App 用「飽和」的方式合成，越接近上限越難再加。

> 「血氣不和，百病乃變化而生。」——《素問·調經論》

## 營衛：脈中與脈外

> 「其清者為營，濁者為衛，營在脈中，衛在脈外。」——《靈樞·營衛生會》

> 「衛氣者，所以溫分肉，充皮膚，肥腠理，司開闔者也。」——《靈樞·本藏》

營在脈中，化生血液；衛在脈外，護衛肌表，主司汗孔的開闔。所以帳上有三欄：衛氣、營氣、腠理開闔。太陽中風是「營弱衛強」——營弱不能內守，於是汗出：

> 「太陽中風，陽浮而陰弱。陽浮者，熱自發；陰弱者，汗自出。」——《傷寒論·辨太陽病脈證並治上》

古人對同一句話的讀法未必相同。「衛強」二字，字面是衛氣強；成無己說是風邪實於衛；《醫宗金鑑》說是衛陽被風邪所阻、不能敷布。App 的做法是**按各說的適用度給權重**——看哪一種讀法最貼近帳上要記的「人自身的狀態」——取加權平均，並算出各家一致的程度。三說權重 0.2、0.3、0.5，得出衛 −0.3，一致程度 0.65。

營衛也從臟腑而來：衛靠肺宣發，也靠脾胃化生，以腎陽為根；營出於中焦，與心血相屬。所以臟腑虛損的人，帳上的營衛也會略弱。

這本帳就是後面一切推理的基礎：八綱從它算出，方劑看能不能把它拉回零點，加減看它還剩下哪些沒有拉回。

**模型的簡化：** 津液主要藉陰、燥、飲、痰表現，沒有單獨一欄；經絡與奇恆之腑不在帳上；衛氣晝行於陽、夜行於陰與失眠的關係，只用來解釋，不入帳。
