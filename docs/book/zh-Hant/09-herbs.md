# 九、本草：一味藥的座標

在 App 裡，每一味藥都有一組**座標**，就像地圖上的一個點。座標的每一維都由一條寫明的規則推得，並記下用了哪條規則——錯了，改規則，而不是改數字。

> 「藥有酸、鹹、甘、苦、辛五味，又有寒、熱、溫、涼四氣，及有毒無毒。」——《神農本草經·序錄》

## 座標

| 座標 | 怎麼來 |
|---|---|
| 四氣 | 大寒到大熱，記為 −3 到 +3 |
| 五味 | 酸、苦、甘、辛、鹹、淡、澀 |
| 歸經 | 依記載的順序，排在前面的分量較重 |
| 陰陽 | 氣占五成、味占三成、升降占兩成：溫熱為陽、寒涼為陰；辛甘淡為陽、酸苦鹹為陰 |
| 五行 | 五味所入（六成）加上歸經的五行（四成） |
| 升降浮沉 | 藥的類別與功效、氣味、入藥部位，三者合成 |
| 毒性 | 無毒、小毒、有毒、大毒 |
| 補瀉、潤燥、氣血分 | 由類別與功效的字詞判斷 |

> 「辛甘發散為陽，酸苦湧洩為陰，鹹味湧洩為陰，淡味滲洩為陽。」——《素問·至真要大論》

> 「酸鹹無升，甘辛無降，寒無浮，熱無沉，其性然也。」——《本草綱目·序例上·升降浮沉》

> 「凡藥輕虛者浮而升，重實者沉而降。」——《本草備要·藥性總義》

所以花葉多升、子實多降、金石更沉；但古人也記下了例外，例如旋覆花降氣、蔓荊子上行，這些由一張小小的特例表補上。

> 「枯燥者入氣分，潤澤者入血分。」——《本草備要·藥性總義》

## 藥量與藥效

一味藥的作用並不與藥量成正比。App 的假設是：**效用會飽和**——加倍不會加倍；**負擔會加速**——超過常量後增加得更快；毒性藥永遠不加量。有些藥，量不同、作用就不同，古籍也記下了：

> 「葛根輕浮，少用則浮而外散，多用則沉而內降矣。」——《本草新編·葛根》

## 炮製與配伍

炮製會改變藥性：

> 「入鹽走腎臟，仍使軟堅；用醋注肝經，且資住痛。」——《本草蒙筌·總論·製造資水火》

兩味藥放在一起，也會互相影響，這就是七情：

> 「有單行者，有相須者，有相使者，有相畏者，有相惡者，有相反者，有相殺者。」——《神農本草經·序錄》

App 從《本草綱目》的「相須相使相畏相惡諸藥」表中讀出兩百多組關係，每一組都保留原文出處。

**模型的簡化：** 座標由規則推得，是草稿；走守、剛柔、《藥品化義》的八個面向，目前只作說明，不進入計算。
