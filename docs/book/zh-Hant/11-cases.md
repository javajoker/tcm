# 十一、案例：三個人

## 一個問題

同一套規則，遇到三個不同的人，會怎樣走？下面三位都是虛構的典型病人。

## 中醫怎麼看

阿明淋雨之後怕冷、無汗、頭身疼痛、流清涕，苔薄白：風寒束表。

> 「無汗而喘者，麻黃湯主之。」——《傷寒論·辨太陽病脈證並治中》

小芳工作壓力大，常嘆氣，近來胃脘脹痛、噯氣、泛酸，爭吵之後更甚：肝氣犯胃，即肝胃不和。

> 「見肝之病，知肝傳脾，當先實脾。」——《金匱要略·臟腑經絡先後病脈證》

陳伯年過七十，怕冷、腰膝痠冷、夜尿頻多，舌淡胖：腎陽虛。

> 「八味腎氣丸主之。」——《金匱要略·血痺虛勞病脈證並治》

## 模型怎麼寫

| | 阿明 | 小芳 | 陳伯 |
|---|---|---|---|
| 必要的症狀 | 惡寒 | 胃脘脹痛、噯氣 | 腰膝痠冷、畏寒、夜尿頻多 |
| 帳上 | 表、寒、腠理閉 | 肝與胃的氣滯 | 腎的陽不足、寒 |
| 追問 | 有沒有汗、咽痛：分開風熱與表虛 | 有沒有胃的症狀：分開單純的肝氣鬱結 | 寒還是熱：分開腎陰虛 |
| 治法與方名 | 辛溫解表；麻黃湯 | 疏肝和胃；柴胡疏肝散 | 溫補腎陽；腎氣丸、右歸丸 |
| 安全與提醒 | 麻黃對高血壓、心悸的人要謹慎 | 木乘土：留意脾胃 | 方中有毒的溫熱藥只能由醫師掌握；冬季腎當令只作提醒 |

## 兩相對照

三個人走的是同一條路——篩檢、量測、推理、記帳、選方、安全——但每一步得到的都不同；這就是「隨證治之」與「同病異治」在模型裡的樣子。真實的病人很少這麼典型：常常兼有幾個證，症狀互相矛盾，或者正在用藥、懷孕、年紀很小。

**模型的簡化：** 三個案例都是典型的病人；遇到兼夾與矛盾，App 會標示錯雜、降低信心並建議就醫，而不是勉強給出一個乾淨的答案。
