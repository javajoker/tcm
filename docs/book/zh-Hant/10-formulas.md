# 十、方劑：君臣佐使是一種分工

一個方劑不是幾味藥的清單，而是一個**分工明確的團隊**。

> 「主病之謂君，佐君之謂臣，應臣之謂使。」——《素問·至真要大論》

## 方劑做了什麼

App 把方中每味藥在其份量下的作用加起來，再算上它們之間的七情：相須、相使互相增強共同的作用；相畏，一味藥的毒副作用被另一味制住；相惡，一味藥的效用被削弱；相反則根本不允許出現。

> 「當用相須、相使者良，勿用相惡、相反者。若有毒宜制，可用相畏、相殺者。」——《神農本草經·序錄》

例如小柴胡湯中的半夏與生薑：

> 「半夏有毒，用之必須生薑，此是取其所畏，以相制耳。」——《本草經集注·序錄上》

## 為什麼這個方合這個證：方解

App 把方解寫成五步，每一步都有數字：

| 步 | 說的是 |
|---|---|
| 病機 | 偏差最大的幾處，例如脾氣虛、心血虛 |
| 治法 | 方劑的治法，以及它真正照顧到哪幾處 |
| 方 | 整體能把偏差拉回多少 |
| 藥 | 每一味藥各自出了多少力，合起來恰好等於整方 |
| 未盡 | 還沒拉回的部分——這就是加減的理由 |

> 「論治病之方，則又以汗、和、下、消、吐、清、溫、補，八法盡之。」——《醫學心悟·醫門八法》

## 君臣佐使，可以量出來

既然知道每味藥出了多少力，就可以回頭檢查古人的分工：君藥是否對主要的病機出力最多；臣藥是否助君；佐藥是佐助、佐制，還是反佐；使藥是引經、調和，還是帶著全方升降（例如桔梗載藥上行、牛膝引血下行）。

量出來的結果，大多數與古人的標記相符；不相符的地方，App 不會擅自改標記，而是列給醫師審閱。有時是模型看不到的東西——例如補中益氣湯的黃耆，在盤面上補脾氣的力量不如人參，但它的「升陽」是方向，不是份量；有時則是資料本身的缺漏。

App 也用同樣的方法，逐一檢查方劑庫裡的 33 個方劑：計算出來的作用是否與記錄一致、是否真的照顧到它所主的證、方向是否對、負擔是否過重、有沒有相反的藥對。這份檢查報告同樣只列問題，不自動修改。

**模型的簡化：** 盤面沒有「少陽」，所以和解少陽的方劑在模型裡看起來「效果不大」——這是模型的盲點，不是方劑的問題。營衛原本也不在帳上，補入之後，桂枝湯已是太陽中風的首選。
