# 六、四診：量測與可信度

四診就是量測。量測有誤差，App 因此替每一筆資料標上**可信度**。

> 「有諸內者形諸外。」——《丹溪心法·能合色脈可以萬全》

## 以問為主

線上自助看不到也摸不到，所以 App 以問診為核心：沿用十問歌，再補上睡眠與情志，共十二個面向，並依前面的回答決定下一題問什麼——先問最能分辨兩個相近證型的題目。

> 「一問寒熱二問汗，三問頭身四問便，五問飲食六問胸，七聾八渴俱當辨，九因脈色察陰陽，十從氣味章神見。」——《景岳全書·傳忠錄·十問篇》

## 可信度

| 資料 | 係數 |
|---|---|
| 自述的症狀 | 1.0 |
| 器材量到的脈率 | 0.9 |
| 依指引自己看的舌象、面色 | 0.7 |
| 自己判斷的脈象 | 0.5 |

明確回答「沒有」，是一筆**反對的證據**，有助鑑別；回答「不確定」或跳過，則不計分，但會讓資料覆蓋率下降、信心降低。

舌象依《傷寒指掌》分區：

> 「滿舌屬胃。中心亦屬胃。舌尖屬心。舌根屬腎。兩旁屬肝膽。四畔屬脾。」——《傷寒指掌·察舌》

> 「診法常以平旦。」——《素問·脈要精微論》

所以 App 會請使用者在早晨、未進食時，在自然光下看舌。

## 紅旗先於一切

在任何辨證之前，App 先問一組「該立刻就醫」的問題，例如胸痛伴冷汗、突然單側無力。只要回答是、甚至只是不確定，就先顯示就醫通知；確認之後才繼續。

> 「小大不利治其標，小大利治其本。」——《素問·標本病傳論》

**模型的簡化：** 望、切兩診只能讀使用者自己的觀察，因此被打折；聞診只靠自述。
