# 一、以模型讀中醫

## 一個問題

讀教科書，學到的是中醫說什麼。這本書問另一件事：中醫的推理，能不能寫成一步一步、可以計算、可以回頭追查的規則？寫下來之後，又會看見什麼？

## 中醫怎麼看

中醫本來就是一套模型：用陰陽、五行、臟腑、氣血這幾個概念，把千變萬化的病情整理成可以推理的「象」，由象推到病機，由病機定治法。

> 「謹守病機，各司其屬。」——《素問·至真要大論》

這正是建模的第一個要求：先定下有哪些「屬」，再把每一個表現歸到它所屬之處。

## 模型怎麼寫

| 步驟 | 做什麼 |
|---|---|
| 安全篩檢 | 先問有沒有該立刻就醫的情況；有，就先說清楚 |
| 四診收集 | 以問診為主，舌象與脈象由使用者自己觀察、可以不填 |
| 辨證 | 為每個證型計分，拆成「病位 × 病性」的證素 |
| 盤面 | 把證素寫進一張「與平均健康的人相比」的帳 |
| 論治 | 找出最能把偏差拉回來的方劑，並說明為什麼 |
| 安全過濾與輸出 | 依年齡、懷孕、用藥、過敏過濾，再把理由與引文一併呈現 |

> 「觀其脈證，知犯何逆，隨證治之。」——《傷寒論·辨太陽病脈證並治上》

App 也依情況決定能說到多深：L0 只給一般調養，L1 說出方名，L2 談加減，L3 才有配比與份量。加減與份量屬於「學習參考」，只供學習與輔助醫師，旁邊一定附上說明；公開版本在這些內容經過審閱之前不提供。

## 兩相對照

寫成模型，好處是每一步都說得出理由、查得到出處；代價是只能處理寫下來的東西。它想守住的，仍是傳統的那一句：

> 「治病必求於本」——《素問·陰陽應象大論》

後面十一章，每章換一個角度——系統、狀態、量測、推理、時間、語言、藥、方、個人、案例與邊界——看傳統怎樣說、模型怎樣寫，兩者在哪裡相合、在哪裡分開。

**模型的簡化：** 所有權重與門檻都是待校準的草稿；證型庫目前只有 23 個常見證型；它不診斷疾病，也不開藥。
