# 一、以模型讀中醫

中醫本來就是一套模型：用陰陽、五行、臟腑、氣血這些概念，把千變萬化的病情整理成可以推理的「象」。這個 App 做的事，是把這套推理寫成**可以計算、每一步都能回頭追查**的規則。

> 「謹守病機，各司其屬。」——《素問·至真要大論》

## 一條流程

| 步驟 | 做什麼 |
|---|---|
| 安全篩檢 | 先問有沒有該立刻就醫的情況；有，就先說清楚 |
| 四診收集 | 以問診為主，舌象與脈象由使用者自己觀察、可以不填 |
| 標準化 | 把每個回答變成標準症狀，並記下它有多可信 |
| 辨證 | 為每個證型計分，拆成「病位 × 病性」的證素 |
| 盤面 | 把證素投影成一張「與平均健康的人相比」的偏差地圖 |
| 鑑別與信心 | 排出最可能的證，說明證據夠不夠 |
| 論治 | 找出最能把偏差拉回來的方劑，並說明為什麼 |
| 安全過濾與輸出 | 依年齡、懷孕、用藥、過敏過濾，再把理由與引文一併呈現 |

> 「觀其脈證，知犯何逆，隨證治之。」——《傷寒論·辨太陽病脈證並治上》

## 它能做的，與不能做的

能做的：把使用者說的症狀整理成一張有條理的地圖，指出最可能的證型、支持與反對的證據，以及每個結論背後的條文。

不能做的：它看不到舌、摸不到脈，只能讀使用者自己觀察的結果，所以這些資料會被**打折計算**；它不診斷疾病，也不開藥。

## 輸出等級

App 依情況決定能說到多深：L0 只給一般調養；L1 可以說出方名；L2 可以談加減；L3 才看得到配比與份量。**公開版本最多到 L1**；更深的內容只在開發版本中，供研究與將來給中醫師使用。

**模型的簡化：** 所有權重與門檻都是待校準的草稿；證型庫目前只有 23 個常見證型。
