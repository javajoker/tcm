前面各章講的是理論與方法：怎樣診察、怎樣辨證、怎樣立法、方藥如何組成。這一章把它們放回臨床，以內科最常見的十三種病證為例，說明每一種病證常見哪些證型、怎樣分辨，以及——最重要的——出現哪些情況必須立即就醫。最後概覽婦、兒、外、五官、皮膚與骨傷各科的特點，並說明自我調養的範圍與限度。

本章的目的是建立臨床的思路，不是教人自行診治。書中所舉的證型與治法方向，只用來說明辨證的推理；任何真實的不適，都應由醫師診察。

## 學習目標

1. 說明辨病與辨證相結合的臨床思路。
2. 掌握內科常見病證的定義、常見證型與辨證要點。
3. 能把常見病證與第十二、十三章的證型對應起來。
4. 說出每一種病證中必須立即就醫的危險徵象。
5. 了解婦科、兒科、外科、五官科、皮膚科與骨傷科的基本特點。
6. 說明自我調養的範圍與限度。

## 一、辨病與辨證

臨床上，中醫既辨「病」，也辨「證」。病名說明疾病的整體特點與發展規律，例如感冒、胃痛、不寐；證說明疾病在某一階段、某一個人身上的具體病機。同一個病可以有幾種證，同一個證也可以見於幾種病（第一章的同病異治與異病同治）。

今天的臨床還有一層：現代醫學的診斷。一個胃痛的人，可能是胃炎、潰瘍，也可能是膽囊或心臟的問題；後者必須用現代醫學的檢查才能確定。所以合理的順序是：**先排除危急與嚴重的疾病，再在安全的範圍內辨證調治**。這就是「病證結合」。

臨床推理的一般步驟是：

1. 問清主訴與經過，先找危險徵象；
2. 確定病名（中醫的病名，必要時結合現代醫學的診斷）；
3. 依四診資料辨證，確定證型；
4. 依證立法，依法選方；
5. 隨病情變化調整，不適持續或加重時重新評估。

## 二、內科常見病證

### （一）感冒

感冒是感受外邪，以鼻塞、流涕、噴嚏、頭痛、惡寒發熱為主的常見外感病。

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 風寒感冒 | 惡寒重、發熱輕、無汗、流清涕、苔薄白、脈浮緊 | 辛溫解表 |
| 風熱感冒 | 發熱重、惡寒輕、咽痛、口微渴、舌邊尖紅、脈浮數 | 辛涼解表 |
| 表虛感冒 | 發熱、惡風、有汗、脈浮緩 | 解肌發表，調和營衛 |
| 暑濕感冒 | 夏季發病，身熱、頭重如裹、胸悶、噁心 | 清暑祛濕解表 |
| 氣虛感冒 | 平素易感冒、乏力氣短、反覆不癒 | 益氣解表 |

**必須就醫**：高熱持續不退；呼吸困難或胸痛；神志改變或嗜睡難醒；頸部僵硬、劇烈頭痛；皮膚出現斑點；嬰幼兒、老人、孕婦與有慢性病的人發熱。

### （二）咳嗽

咳嗽是肺失宣降、肺氣上逆所致的病證，分外感與內傷兩大類。

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 風寒襲肺 | 咳嗽、痰白清稀、伴風寒表證 | 疏風散寒，宣肺止咳 |
| 風熱犯肺 | 咳嗽、痰黃稠、咽痛、伴風熱表證 | 疏風清熱，宣肺止咳 |
| 燥邪傷肺 | 乾咳、鼻咽乾燥，秋季多見 | 疏風清肺，潤燥止咳 |
| 痰濕蘊肺 | 咳嗽痰多、色白易咳、胸悶、苔白膩 | 燥濕化痰 |
| 肺陰虧耗 | 乾咳少痰、口燥咽乾、潮熱盜汗、舌紅少苔 | 養陰潤肺 |
| 肺氣虧虛 | 咳聲無力、氣短、自汗、易感冒 | 補益肺氣 |

**必須就醫**：咯血或痰中帶血；呼吸困難、喘促；胸痛；高熱；咳嗽持續數週不癒；伴體重下降、夜間盜汗。

### （三）胃痛

胃痛又稱胃脘痛，指上腹部近心窩處的疼痛。

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 寒邪客胃 | 受寒或吃生冷後突然胃痛、得溫痛減 | 溫胃散寒 |
| 飲食傷胃 | 暴飲暴食後脹痛、噯腐吞酸、吐後痛減 | 消食導滯 |
| 肝氣犯胃 | 脹痛連脅、噯氣、泛酸、因情緒加重 | 疏肝和胃 |
| 脾胃虛寒 | 隱痛、喜溫喜按、空腹痛甚、得食稍減 | 溫中健脾 |
| 胃陰不足 | 隱隱灼痛、饑不欲食、口燥咽乾、舌紅少苔 | 養陰益胃 |
| 濕熱中阻 | 脘痛痞悶、口苦口黏、苔黃膩 | 清熱化濕 |

**必須就醫**：嘔血或排黑色柏油樣大便；劇烈的腹痛，或腹部變硬；持續嘔吐；吞嚥困難；不明原因的體重下降；疼痛牽連胸部、背部、左臂或下顎，或伴冷汗、氣短——這可能是心臟的急症，不是胃病。

### （四）泄瀉

泄瀉指排便次數增多、糞質稀溏，甚至如水樣。

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 寒濕泄瀉 | 起病急、瀉下清稀、腹痛腸鳴、得溫則減 | 散寒化濕 |
| 濕熱泄瀉 | 瀉下急迫、糞色黃褐而臭、肛門灼熱、苔黃膩 | 清熱利濕 |
| 傷食泄瀉 | 腹痛腸鳴、瀉下臭如敗卵、瀉後痛減 | 消食導滯 |
| 脾虛泄瀉 | 大便時溏時瀉、食少、飯後腹脹、乏力 | 健脾益氣 |
| 腎陽虛泄瀉 | 天亮前腹痛即瀉、瀉後即安、畏寒肢冷 | 溫腎健脾 |
| 肝脾不和 | 每因情緒緊張而腹痛泄瀉、瀉後痛減 | 抑木扶土 |

**必須就醫**：大便帶血或呈黑色；高熱；口乾、尿少、頭暈等脫水的表現；嬰幼兒與老人；腹瀉持續數日不止；伴劇烈腹痛或體重下降。

### （五）便秘

便秘指排便間隔延長，或糞質乾硬、排出困難。

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 熱秘 | 大便乾結、腹脹、口乾口臭、小便短黃 | 清熱潤腸 |
| 氣秘 | 欲便不得、腹脹、噯氣、與情緒相關 | 順氣導滯 |
| 氣虛秘 | 有便意而排出無力、便後乏力、大便不一定乾硬 | 益氣潤腸 |
| 血虛、陰虛秘 | 大便乾結、面色無華或口燥咽乾、舌紅少苔 | 養血滋陰潤腸 |
| 冷秘 | 大便艱澀、腹中冷痛、畏寒肢冷 | 溫陽通便 |

**必須就醫**：大便帶血；排便習慣突然改變且持續；不明原因的體重下降；腹痛腹脹、嘔吐、不能排氣。

### （六）不寐

不寐即失眠，指經常不能獲得正常的睡眠。

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 心脾兩虛 | 多夢易醒、心悸健忘、食少乏力、面色萎黃 | 補益心脾，養血安神 |
| 心腎不交 | 心煩不寐、五心煩熱、腰痠耳鳴、舌紅少苔 | 滋陰降火，交通心腎 |
| 痰熱擾心 | 難以入睡、易驚、口苦痰多、苔黃膩 | 清熱化痰，和中安神 |
| 肝火擾心 | 不寐多夢、急躁易怒、口苦目赤 | 清肝瀉火，鎮心安神 |
| 肝血不足 | 虛煩不眠、目乾、舌淡脈細 | 養血安神 |
| 胃氣不和 | 飽食後不能安睡、脘腹脹滿 | 和胃消食 |

**必須就醫**：長期嚴重失眠影響日常生活；伴持續的情緒低落、對事物失去興趣；**有傷害自己的念頭時，必須立即向醫療機構或緊急求助專線求助**。

### （七）心悸

心悸是自覺心跳異常、心慌不安的病證。

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 心血不足 | 心悸、頭暈、面色淡白、舌淡脈細 | 補血養心 |
| 心脾兩虛 | 心悸健忘、食少乏力 | 補益心脾 |
| 陰虛火旺 | 心悸心煩、少寐、手足心熱、舌紅少苔 | 滋陰清火 |
| 痰火擾心 | 心悸時發時止、胸悶煩躁、口苦、苔黃膩 | 清熱化痰 |
| 心脈瘀阻 | 心悸、胸悶刺痛、唇甲青紫、舌紫暗 | 活血化瘀 |

**必須就醫**：心悸伴胸痛、胸悶、氣短、暈厥或眼前發黑；脈搏極快、極慢或明顯不規則；有心臟病史的人出現新的心悸。這些可能是心臟急症，必須立即處理。

### （八）頭痛

頭痛分外感與內傷，並可依部位辨經（第七章）。

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 風寒頭痛 | 頭痛連及項背、遇風寒加重 | 疏風散寒 |
| 風熱頭痛 | 頭脹痛、發熱、面紅目赤、口渴 | 疏風清熱 |
| 肝陽或肝火頭痛 | 頭脹痛、眩暈、急躁、面紅口苦 | 平肝或清肝 |
| 血虛頭痛 | 隱隱作痛、頭暈、心悸、面色淡白 | 養血 |
| 痰濁頭痛 | 頭痛昏蒙、胸悶、噁心、苔白膩 | 化痰降逆 |
| 瘀血頭痛 | 痛處固定、如針刺、經久不癒、舌紫暗 | 活血化瘀 |

**必須就醫**：突然發生的劇烈頭痛；伴發熱與頸部僵硬；伴肢體無力、麻木、言語不清、口眼歪斜或視力改變；頭部外傷後的頭痛；逐漸加重的頭痛；中年以後新出現的頭痛。

### （九）眩暈

眩暈指頭暈眼花，嚴重時如坐舟車、站立不穩。

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 肝陽上亢 | 眩暈耳鳴、頭脹痛、因煩勞惱怒加重 | 平肝潛陽 |
| 氣血虧虛 | 眩暈動則加劇、面色淡白、心悸乏力 | 補益氣血 |
| 痰濁中阻 | 眩暈、頭重如裹、胸悶噁心、苔白膩 | 化痰祛濕 |
| 腎精不足 | 眩暈日久、腰膝痠軟、耳鳴、健忘 | 補腎填精 |

**必須就醫**：眩暈伴單側肢體無力或麻木、口眼歪斜、言語不清、劇烈頭痛、看東西重影或昏倒——這些可能是中風的徵兆，必須立即送醫。

### （十）鬱證

鬱證是由情志不舒、氣機鬱滯引起的病證，表現為心情抑鬱、情緒不寧、脅肋脹痛，或咽中如有異物梗塞。

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 肝氣鬱結 | 精神抑鬱、善太息、脅肋脹痛、脈弦 | 疏肝解鬱 |
| 氣鬱化火 | 急躁易怒、口苦、頭痛、舌紅苔黃 | 疏肝解鬱，清肝瀉火 |
| 痰氣鬱結 | 咽中如有異物、吞之不下、吐之不出 | 行氣開鬱，化痰散結 |
| 心脾兩虛 | 多思善疑、心悸健忘、失眠、食少 | 健脾養心 |
| 心腎陰虛 | 情緒不寧、心悸、失眠、五心煩熱 | 滋養心腎 |

**必須就醫**：情緒低落、失去興趣持續兩週以上，影響工作與生活；出現傷害自己或他人的念頭時，必須立即向醫療機構或緊急求助專線求助。情志的問題需要專業的身心醫療協助，中醫的調理可以配合，但不能取代。

### （十一）虛勞與疲倦

虛勞是多種原因所致臟腑虧損、氣血陰陽不足的慢性虛弱病證。

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 氣虛 | 神疲乏力、氣短懶言、自汗、易感冒 | 益氣 |
| 血虛 | 面色淡白、頭暈眼花、心悸、唇甲色淡 | 養血 |
| 陰虛 | 五心煩熱、潮熱盜汗、口燥咽乾、舌紅少苔 | 滋陰 |
| 陽虛 | 畏寒肢冷、腰膝痠冷、夜尿多、舌淡胖 | 溫陽 |
| 氣血兩虛 | 氣虛與血虛的表現並見 | 益氣補血 |

**必須就醫**：不明原因的體重下降；持續的發熱或明顯的夜間盜汗；頸部或腋下摸到腫塊；面色蒼白伴心悸氣短；疲倦逐漸加重。長期疲倦可能是貧血、甲狀腺疾病、糖尿病、感染或腫瘤的表現，應先檢查。

### （十二）汗證

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 肺衛不固 | 自汗、怕風、易感冒、氣短 | 益氣固表 |
| 營衛不和 | 時發熱自汗、身體並無他病 | 調和營衛 |
| 陰虛火旺 | 盜汗、五心煩熱、潮熱、舌紅少苔 | 滋陰降火 |

**必須就醫**：夜間大汗伴發熱、消瘦；突然冷汗淋漓伴胸痛、氣短或頭暈；伴心悸、手抖、體重下降。

### （十三）腰痛

| 證型 | 辨證要點 | 治法方向 |
|---|---|---|
| 腎陰虛 | 腰痠軟、手足心熱、潮熱盜汗 | 滋補腎陰 |
| 腎陽虛 | 腰痠冷、畏寒肢冷、夜尿多 | 溫補腎陽 |
| 寒濕 | 腰部冷痛重著、遇陰雨天加重 | 散寒祛濕 |
| 濕熱 | 腰痛而有熱感、小便短黃 | 清熱利濕 |
| 瘀血 | 腰痛如刺、痛處固定、日輕夜重 | 活血化瘀 |

**必須就醫**：外傷後的腰痛；伴發熱；伴下肢無力、麻木或大小便失禁；伴血尿或劇烈的絞痛；夜間痛甚、休息不能緩解。

## 三、各科概覽

### （一）婦科

婦科以「經、帶、胎、產」為主要內容。月經病包括月經週期、經量、經色的異常與痛經：經前乳房脹痛、經行腹脹痛，多屬氣滯；經色紫暗有塊、痛如針刺，多屬血瘀；小腹冷痛、得溫痛減，多屬寒凝；經後隱痛、量少色淡，多屬氣血不足。**懷孕期間的任何用藥都必須由醫師決定**。異常的陰道出血、劇烈的下腹痛、懷孕期間的出血或腹痛，都必須立即就醫。

### （二）兒科

小兒的生理特點是臟腑嬌嫩、形氣未充，同時生機蓬勃、發育迅速；病理特點是發病容易、傳變迅速，但也容易康復。小兒常見感冒、咳嗽、食積、泄瀉。由於變化快、表達能力有限，小兒的病情要特別重視：高熱、精神萎靡、拒食、嘔吐腹瀉不止、呼吸急促，都應立即就醫。小兒用藥必須由醫師決定。

### （三）外科

中醫外科以瘡瘍為主，分陽證與陰證：紅、腫、熱、痛明顯，起病急的，屬陽證；漫腫不紅、不熱、痛輕，起病緩的，屬陰證。明代陳實功的《外科正宗》等書總結了內治的消、托、補三法。今天的感染與膿腫常需要現代醫學的處理，不可自行擠壓或延誤。

### （四）五官科

眼科古籍以《銀海精微》等書為代表，古人用「五輪學說」把眼的各部分配屬五臟。耳鳴、聽力減退多與腎、肝有關；鼻塞流涕多與肺有關；咽喉腫痛多與肺胃有熱有關；口舌生瘡多與心胃有火有關。突然的視力喪失、眼痛、聽力驟降，都必須立即就醫。

### （五）皮膚科

皮膚病多從風、濕、熱、血來辨：濕疹多屬濕熱，日久則屬血虛風燥；突發成片、時起時消的風團多屬風邪；青春期面部的痤瘡多屬肺胃有熱。大範圍的皮疹伴發熱、皮膚或黏膜大片脫落，都是急症。

### （六）骨傷科

跌打損傷要先排除骨折、脫位與內臟損傷，必須就醫並接受必要的影像檢查。中醫在骨傷的復健與舒筋活絡上有豐富的經驗，但急性外傷不可自行處理。

## 四、自我調養的範圍與限度

| 可以自我調養 | 應該就醫 |
|---|---|
| 輕微、短暫、沒有危險徵象的不適 | 有任何危險徵象 |
| 生活作息、飲食、運動與情志的調整 | 不適持續、反覆或逐漸加重 |
| 安全的穴位按壓（第七章） | 診斷不明，或需要用藥 |
| 依體質與季節的養生（第十九章） | 孕婦、哺乳期、嬰幼兒、高齡與有慢性病的人 |
| 學習、記錄自己的身體狀態，帶去與醫師討論 | 正在使用藥物、需要調整藥物 |

自我調養的目的，是保養身體、及早發現偏向，而不是自己當自己的醫生。

## 古籍原文選讀

> 「觀其脈證，知犯何逆，隨證治之」——《傷寒論·辨太陽病脈證並治上》

**白話**：觀察脈象與症狀，弄清病情發生了什麼變化，再依當下的證來治療。這句話是臨床思路的總綱：每一種病證都可能有不同的證，而且證會變化，治療必須隨之調整。

> 「胃不和，則臥不安」——《素問·逆調論》

**白話**：胃氣不和，睡眠就不安穩。這說明不寐不一定只從心論治，飲食積滯、胃氣上逆也會影響睡眠；調和胃氣，睡眠自然改善。

> 「春傷於風，邪氣留連，乃為洞洩」——《素問·生氣通天論》

**白話**：春天受了風邪，邪氣滯留不去，就會發生嚴重的腹瀉。這是古人對泄瀉病因的一種觀察：泄瀉不只與飲食有關，外邪與季節也有影響。

> 「諸溼腫滿，皆屬於脾」——《素問·至真要大論》

**白話**：凡是濕邪停聚所致的浮腫、脹滿，大多與脾有關。泄瀉、胃痛、水腫等病證中，脾虛濕盛都是常見的病機，所以健脾化濕是這些病證常用的治法。

> 「思則氣結」——《素問·舉痛論》

**白話**：思慮過度，氣就會鬱結。鬱證、胃痛、不寐等病證，常與思慮過度、情志不舒有關；調暢情志是這些病證調養的重要部分。

> 「見肝之病，知肝傳脾，當先實脾」——《金匱要略·臟腑經絡先後病脈證》

**白話**：見到肝的病，知道它會傳到脾，就要先調理脾胃。臨床上肝氣犯胃的胃痛、肝脾不和的泄瀉，正是這句話所說的情況；治療時疏肝與健脾和胃常常並用。

> 「同時得病，其病各異」——《靈樞·五變》

**白話**：同一時間得病，每個人的病卻各不相同。同樣是感冒，有的人是風寒，有的人是風熱，有的人是氣虛感冒；這正是臨床上必須逐人辨證的原因。

## 本章小結

- 臨床上辨病與辨證相結合：先排除危急與嚴重的疾病，再在安全的範圍內辨證調治。
- 感冒、咳嗽、胃痛、泄瀉、便秘、不寐、心悸、頭痛、眩暈、鬱證、虛勞、汗證、腰痛等常見病證，各有幾種常見證型，可以對應到第十二、十三章的證型。
- 每一種病證都有必須立即就醫的危險徵象：胸痛、呼吸困難、神志改變、單側無力、口眼歪斜、嘔血黑便、劇烈腹痛、高熱不退、不明原因的體重下降、傷害自己的念頭等。
- 婦科重經帶胎產，兒科重變化迅速，外科分陰陽證，五官與皮膚依臟腑與風濕熱辨，骨傷先排除骨折與內傷。
- 自我調養只適用於輕微、沒有危險徵象的不適；目的是保養與及早發現，不是自行診治。

## 名詞

- **辨證論治**：先辨證、再依證治療的臨床方法；在臨床上與辨病相結合。
- **證型**：同一病證中常見的典型證；本章各病證的表格就是它們的常見證型。
- **中醫師**：能親自診察、辨證並處方的醫師；本章所有「必須就醫」的情況都需要醫師處理。

## 與本 App 對照

三個典型的病人怎樣走過 App 的每一步，見［學習書 第十一章］〈案例：三個人〉；紅旗與安全見［學習書 第十二章］〈邊界：驗證、安全與倫理〉。本章在 App 中對應的記錄：

- **病證與證型**：本章各病證的常見證型，有許多就是 App 證型庫中的證型。例如感冒對應［證型 EX1 風寒束表］、［證型 EX3 風熱犯表］、［證型 EX2 太陽中風］；咳嗽對應［證型 SP4 痰濕內阻］、［證型 LG2 肺陰虛］、［證型 LG1 肺氣虛］；胃痛對應［證型 LV4 肝胃不和］、［證型 SP2 脾陽虛］、［證型 SP6 胃陰虛］、［證型 SP5 濕熱蘊結］；泄瀉對應［證型 SP1 脾氣虛］、［證型 KD2 腎陽虛］；不寐對應［證型 HT1 心脾兩虛］、［證型 HT2 心腎不交］、［證型 HT3 痰熱擾心］、［證型 LV3 肝血虛］、［證型 LV2 肝火上炎］；鬱證對應［證型 LV1 肝氣鬱結］；虛勞對應［證型 QB1 氣血兩虛］；汗證對應［證型 EX4 營衛不和］；頭痛與月經病的瘀血對應［證型 QB2 血瘀］；脫肛、內臟下垂對應［證型 SP3 中氣下陷］；腰痛的腎虛對應［證型 KD1 腎陰虛］。
- **紅旗篩檢**：本章每一種病證的「必須就醫」，在 App 中都由紅旗篩檢處理：任何辨證之前先問，回答是或不確定都先顯示就醫通知，見［SOP §2.3］。
- **範圍策略**：未滿十八歲、懷孕、哺乳與重大疾病的使用者，App 會降低可呈現的深度並清楚說明，見［SOP §0.2］與［SOP §13.3］。
- **與醫師討論**：App 的結果可以整理成給醫師看的摘要，幫助使用者把自己的狀態帶去和醫師討論，這正是本章第四節「學習、記錄、帶去與醫師討論」的做法。

**模型的簡化**：App 只辨證，不辨病，也不能排除任何疾病；本章的許多證型（例如暑濕感冒、肝陽上亢、寒濕腰痛、心脈瘀阻）不在證型庫中。婦、兒、外、五官、皮膚與骨傷各科的病證都不在模型的範圍內。紅旗清單是草稿，尚待醫師審定；它涵蓋常見的危險情況，但不可能窮盡。
