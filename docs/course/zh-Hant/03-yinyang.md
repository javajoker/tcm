陰陽是中醫學最基本的一對概念。它不是神秘的玄學，而是一種把事物分成相對兩面、再觀察兩面如何互相作用的思考工具。中醫用它描述人體的結構與功能、說明疾病的寒熱虛實、指導診斷與用藥。後面每一章都會用到陰陽；學好這一章，等於拿到了讀懂全書的第一把鑰匙。

## 學習目標

1. 說明陰陽的基本概念，以及劃分事物陰陽屬性的原則。
2. 說明陰陽的相對性與可分性，並以晝夜為例。
3. 說明陰陽之間的四種關係：對立制約、互根互用、消長平衡、相互轉化。
4. 運用陰陽說明人體的組織結構與生理功能。
5. 說明陰陽偏盛與偏衰的病理，分辨實熱、實寒、虛熱、虛寒。
6. 說明陰陽在診斷、治療與藥物性質上的應用。

## 一、陰陽的基本概念

### （一）從日照的向背說起

「陰陽」最初的意思很樸素：山坡向著太陽的一面是陽，背著太陽的一面是陰。向陽的一面明亮、溫暖；背陰的一面晦暗、寒涼。古人由此引申，把一切**相互關聯而又相互對立**的事物或現象的兩個方面，都用陰陽來概括。

要注意兩個條件：一是「相互關聯」，二是「相互對立」。白天與黑夜是同一個晝夜循環的兩面，可以分陰陽；但「桌子」與「冬天」之間沒有關聯，就不必談陰陽。

### （二）陰陽屬性的劃分

古人以水與火作為陰陽的代表：水寒涼、向下、靜；火溫熱、向上、動。依照這個原則，可以把常見的屬性歸類如下：

| | 陽 | 陰 |
|---|---|---|
| 溫度 | 溫熱 | 寒涼 |
| 亮度 | 明亮 | 晦暗 |
| 方向 | 上升、向外 | 下降、向內 |
| 狀態 | 運動、興奮 | 靜止、抑制 |
| 形態 | 無形、氣化 | 有形、成形 |
| 在人體 | 功能、推動、溫煦 | 物質、滋潤、寧靜 |

在人體，凡是具有推動、溫煦、興奮作用的屬陽；凡是具有滋潤、凝聚、寧靜作用的屬陰。所以「氣」偏於陽，「血」與「津液」偏於陰；功能偏於陽，構成身體的物質偏於陰。

### （三）陰陽的相對性與可分性

**相對性**：一件事物屬陰還是屬陽，要看與什麼比較。溫水與冰水相比，溫水屬陽；溫水與沸水相比，溫水又屬陰。胸與背相比，背屬陽；胸與腹相比，胸在上又屬陽。陰陽不是固定的標籤，而是比較的結果。

**可分性**：陰與陽之中，還可以再分陰陽，所謂「陰中有陽，陽中有陰」。以一天為例：白天屬陽，夜晚屬陰；上午陽氣漸盛，是「陽中之陽」，下午陽氣漸衰，是「陽中之陰」；前半夜是「陰中之陰」，後半夜陽氣漸生，是「陰中之陽」。這種層層細分的方式，讓陰陽可以描述很細緻的變化。

## 二、陰陽之間的關係

### （一）對立制約

陰與陽性質相反，又互相約束。陽的溫熱可以制約陰的寒涼，陰的寒涼也可以制約陽的溫熱；正因為互相制約，雙方才維持在一個適當的範圍。夏天雖熱，人體有汗出、津液可以散熱；冬天雖冷，人體有陽氣可以溫煦。如果一方過強，另一方就被壓制，於是出現病變。

### （二）互根互用

陰陽雖然對立，卻又互相依存，任何一方都不能脫離另一方而單獨存在，這叫「互根」；雙方還互相資生、互相促進，這叫「互用」。在人體，物質（陰）是功能（陽）的基礎，功能又推動物質的生成：沒有血與津液的滋養，氣就無所依附；沒有氣的推動，血與津液也無法生成與運行。

互根互用在病理上的意義是：一方虛損久了，會拖累另一方。陰虛日久，陽也跟著不足，稱為「陰損及陽」；陽虛日久，陰也跟著不足，稱為「陽損及陰」。結果是陰陽兩虛。

### （三）消長平衡

陰陽雙方不是靜止的，而是此消彼長、此長彼消，在變動中維持平衡。一年之中，從冬至到夏至，陽氣漸長、陰氣漸消，天氣由寒轉熱；從夏至到冬至，陰氣漸長、陽氣漸消，天氣由熱轉寒。一天之中也是如此。人體的陰陽隨之消長：白天陽氣在外，人清醒活動；夜晚陽氣內收，人入睡休息。

在一定範圍內的消長是正常的生理變化；超出範圍、不能恢復，就成為病理。

### （四）相互轉化

在一定條件下，陰陽可以向對立的一方轉化。古人說「重陰必陽，重陽必陰」，又說「寒極生熱，熱極生寒」。轉化有兩個要點：一是要到達「極」或「重」的程度，二是要有一定的條件。臨床上，例如高熱持續、大汗不止，陽氣隨汗外脫，病人可能突然面色蒼白、四肢冰冷、脈微欲絕，由熱證轉為寒證；又如寒邪久鬱，也可以化而為熱。

### （五）陰陽自和

除了上述四種關係，古人還注意到陰陽有自我調和、恢復平衡的傾向。許多輕微的失衡，休息、飲食與起居調整之後就能自行恢復。治療的作用，很多時候是幫助身體恢復這種自和的能力，而不是取代它。

## 三、陰陽與人體

### （一）組織結構

人體的各部分都可以分陰陽：

- 上部為陽，下部為陰；體表為陽，體內為陰；背為陽，腹為陰。
- 五臟藏精氣而不瀉，屬陰；六腑傳化水穀，屬陽。
- 五臟之中，心、肺在上屬陽，肝、脾、腎在下屬陰；每一臟又可以再分陰陽，例如心陰與心陽、腎陰與腎陽。

### （二）生理功能

人體的正常活動，是陰陽雙方協調配合的結果。陽氣在外，保護身體、抵禦外邪；陰精在內，滋養臟腑、維持生命的物質基礎。陽氣固密、陰精充足而安寧，陰陽協調，稱為「陰平陽秘」，這是健康的狀態。

### （三）晝夜節律

衛氣白天行於體表（陽），人清醒；夜晚入於體內（陰），人入睡。所以睡眠也可以用陰陽來理解：陽氣不能入於陰，就會失眠；這一點在第六章與第十二章還會詳細討論。

## 四、陰陽失調：疾病的基本病理

中醫認為，一切疾病的發生，歸根結柢都是陰陽失去平衡。失衡有兩種基本形式：**偏盛**（某一方太過）與**偏衰**（某一方不足）。

### （一）陰陽偏盛：多為實證

- **陽勝則熱**：陽邪亢盛，例如外感熱邪或體內熱盛，表現為發熱、面紅、口渴喜冷飲、煩躁、舌紅苔黃、脈數有力，稱為**實熱**。陽熱太盛又會耗傷陰液，所以說「陽勝則陰病」。
- **陰勝則寒**：陰邪亢盛，例如受寒或過食生冷，表現為怕冷、腹部冷痛、肢體拘急、舌苔白、脈緊或遲，稱為**實寒**。陰寒太盛又會損傷陽氣，所以說「陰勝則陽病」。

### （二）陰陽偏衰：多為虛證

- **陽虛則外寒**：陽氣不足，溫煦無力，表現為畏寒、手足冰冷、面色淡白、喜溫喜熱、精神疲倦、小便清長、舌淡胖、脈沉遲無力，稱為**虛寒**。
- **陰虛則內熱**：陰液不足，不能制約陽氣，陽氣相對亢盛而生熱，表現為手足心熱、午後潮熱、夜間盜汗、口燥咽乾、舌紅少苔、脈細數，稱為**虛熱**。

### （三）實熱與虛熱、實寒與虛寒的分別

| | 實熱 | 虛熱 | 實寒 | 虛寒 |
|---|---|---|---|---|
| 原因 | 陽偏盛 | 陰偏衰 | 陰偏盛 | 陽偏衰 |
| 熱或寒的特點 | 壯熱、持續 | 低熱、午後或夜間明顯 | 寒冷明顯、起病較急 | 畏寒、得溫則減、病程較長 |
| 舌 | 舌紅苔黃 | 舌紅少苔 | 苔白 | 舌淡胖 |
| 脈 | 數而有力 | 細數 | 緊或遲而有力 | 沉遲無力 |
| 調整方向 | 清熱 | 滋陰 | 散寒 | 溫陽 |

這張表是後面八綱辨證（第十一章）的基礎：熱與寒要再分虛實，治法才不會錯。虛熱如果誤用苦寒清熱，會更傷陰液；虛寒如果誤用發散，會更耗陽氣。

### （四）陰陽互損與危重的變化

陰虛或陽虛日久，會發展為陰陽兩虛。病情危重時，還可能出現陰陽互不相容的「格拒」（例如真寒假熱，詳見第十一章），以及陰液或陽氣突然大量喪失的「亡陰」「亡陽」。這些都是危急的情況，必須立即就醫。

## 五、陰陽在診斷與治療中的應用

### （一）診斷：先別陰陽

診察時，首先要分辨病證屬陰還是屬陽：

- 色澤鮮明的屬陽，晦暗的屬陰；
- 聲音高亢有力的屬陽，低微無力的屬陰；
- 脈象浮、數、洪、滑的屬陽，沉、遲、細、澀的屬陰；
- 表證、熱證、實證屬陽，裡證、寒證、虛證屬陰。

第十一章的八綱辨證，就是以陰陽為總綱，統攝表裡、寒熱、虛實。

### （二）治療：調整陰陽，以平為期

治療的基本原則，是補其不足、瀉其有餘，使陰陽恢復平衡：

- **偏盛者瀉其有餘**：陽勝的實熱用寒涼清熱，陰勝的實寒用溫熱散寒，即「熱者寒之，寒者熱之」。
- **偏衰者補其不足**：陰虛的虛熱以滋陰為主，陽虛的虛寒以溫陽為主。唐代王冰把這個原則說成「壯水之主，以制陽光；益火之源，以消陰翳」：虛熱不是去清熱，而是補足陰液，熱自然平息；虛寒不是去散寒，而是溫補陽氣，寒自然消退。
- **陰中求陽，陽中求陰**：由於陰陽互根，明代張介賓主張補陽時在補陰藥的基礎上加溫陽藥，補陰時也照顧陽氣，使雙方互相資生。

### （三）藥物與食物的陰陽

藥物的性質也可以分陰陽：

- **四氣**：溫、熱屬陽，寒、涼屬陰。
- **五味**：辛、甘、淡屬陽，酸、苦、鹹屬陰。
- **作用方向**：升、浮屬陽，沉、降屬陰。

所以治陽勝的熱證，用屬陰的寒涼藥；治陰勝的寒證，用屬陽的溫熱藥。第十五章會詳細討論藥性。

### （四）養生：順應陰陽

養生的道理也是調和陰陽：順應四時與晝夜的陰陽消長安排起居，春夏養陽、秋冬養陰，飲食不偏寒偏熱。第十九章會詳細討論。

## 古籍原文選讀

> 「陰勝則陽病，陽勝則陰病。陽勝則熱，陰勝則寒」——《素問·陰陽應象大論》

**白話**：陰氣太盛，陽氣就會受損而生病；陽氣太盛，陰液就會受損而生病。陽氣偏盛就表現為熱，陰氣偏盛就表現為寒。這句話說明了陰陽偏盛的兩層後果：一是直接表現為寒或熱，二是會損傷對立的一方。

> 「陽虛則外寒，陰虛則內熱」——《素問·調經論》

**白話**：陽氣不足，身體得不到溫煦，就會怕冷；陰液不足，不能制約陽氣，就會從內生熱。這是虛寒與虛熱的根據。與上一段合讀，就得到本章的四種基本病理：陽勝則熱、陰勝則寒、陽虛則外寒、陰虛則內熱。

> 「陽者，衛外而為固也」——《素問·生氣通天論》

**白話**：陽氣的作用，是在外面護衛身體、使身體固密。陽氣充足，外邪就不容易侵入；陽氣不足，人就容易怕冷、容易感冒、容易汗出。這句話說明了陽氣「衛外」的功能，也是第六章衛氣學說的源頭。

> 「陽加於陰，謂之汗」——《素問·陰陽別論》

**白話**：陽氣蒸動陰液，使它從體表排出，就是汗。汗的本質是津液（陰），推動它外出的是陽氣。所以汗出過多既傷陰液，也耗陽氣；而汗的有無與多少，也是判斷陰陽狀態的重要線索。

> 「氣至陽而起，至陰而止」——《靈樞·營衛生會》

**白話**：衛氣運行到陽分（體表）時，人就醒來活動；運行到陰分（體內）時，人就停止活動而入睡。這句話用陰陽解釋了晝夜的作息：睡眠與清醒，是陽氣出入的結果。

> 「善診者，察色按脈，先別陰陽」——《素問·陰陽應象大論》

**白話**：善於診病的醫者，觀察面色、按切脈搏時，首先要分辨病證屬陰還是屬陽。陰陽是辨證的總綱，先定陰陽，其他的判斷才有方向。

> 「辛甘發散為陽，酸苦湧洩為陰」——《素問·陰陽應象大論》

**白話**：味辛、味甘而有發散作用的藥物屬陽；味酸、味苦而有湧吐、泄下作用的藥物屬陰。這是用陰陽劃分藥物性味與作用方向的最早說法，第十五章的藥性理論由此展開。

> 「謹察陰陽所在而調之，以平為期」——《素問·至真要大論》

**白話**：要仔細察明陰陽失調在哪裡，然後加以調整，以恢復平衡為目標。治療不是越多越好，而是恰好把偏差調回來；這是中醫治療的總目標。

## 本章小結

- 陰陽是對相互關聯又相互對立的事物兩面的概括；以水火為代表，陽主溫熱、上升、運動、功能，陰主寒涼、下降、靜止、物質。
- 陰陽具有相對性（看與什麼比較）與可分性（陰中有陽，陽中有陰）。
- 陰陽之間有對立制約、互根互用、消長平衡、相互轉化四種關係，並有自和的傾向。
- 疾病的基本病理是陰陽失調：陽勝則熱、陰勝則寒（實證）；陽虛則外寒、陰虛則內熱（虛證）；久則陰陽互損。
- 熱與寒都要再分虛實：實熱清熱、虛熱滋陰；實寒散寒、虛寒溫陽。
- 診斷先別陰陽；治療調整陰陽、以平為期；藥物也有陰陽屬性。

## 名詞

- **陰陽**：對相互關聯又相互對立的事物或現象兩個方面的概括；陽主溫熱、上升、運動，陰主寒涼、下降、靜止。
- **寒**：病性之一，表現為怕冷、喜溫、分泌物清稀、舌淡或苔白；可由陰盛（實寒）或陽虛（虛寒）引起。
- **熱**：病性之一，表現為發熱、口渴、面紅、舌紅、脈數；可由陽盛（實熱）或陰虛（虛熱）引起。
- **虛**：正氣不足的病性，包括氣、血、陰、陽的虧虛；表現為功能減退、無力。
- **實**：邪氣亢盛或病理產物停聚的病性；表現為反應劇烈、脹滿疼痛拒按。
- **陰虛**：陰液不足，不能制約陽氣而生虛熱，表現為手足心熱、潮熱盜汗、口燥咽乾、舌紅少苔。
- **陽虛**：陽氣不足，溫煦無力而生虛寒，表現為畏寒肢冷、面白、喜溫、舌淡胖、脈沉遲無力。
- **寒熱**：辨別病性屬寒還是屬熱的一對綱領，是八綱之一。
- **虛實**：辨別邪正盛衰的一對綱領，是八綱之一；虛指正氣不足，實指邪氣亢盛。

## 與本 App 對照

在 App 裡，陰陽不是一個抽象的總結，而是**有正有負的尺**，以「平均健康的人」為零點，見［學習書 第二章］：

- **寒熱尺**：由寒（負）到熱（正）。火、暑與陰虛把它往熱推；寒與陽虛把它往寒推。這正是本章「陽勝則熱、陰勝則寒、陽虛則外寒、陰虛則內熱」的寫法：［證型 KD1 腎陰虛］與［證型 LG2 肺陰虛］會被算成偏熱，［證型 KD2 腎陽虛］與［證型 SP2 脾陽虛］會被算成偏寒，即使它們都沒有外邪。
- **虛實尺**：由虛（負）到實（正）。虛損往虛推；邪氣、痰瘀、氣滯往實推。
- **表的尺**：只在外感初起、惡寒為主時升高，例如［證型 EX1 風寒束表］。
- **陰陽總綱**由這三把尺推得，不另外計算；八綱由盤面推得的方法見［SOP §10.4］，問診時的初判見［SOP §8.2］。
- **陰中求陽**：［方劑 腎氣丸］在知識庫中的治法正是「補腎助陽、陰中求陽」：以溫陽的［本草 附子］與［本草 桂枝］為君，配伍滋補腎陰的［本草 地黃］、［本草 山茱萸］、［本草 山藥］，使陽氣有陰液作為依托。相對地，［方劑 六味地黃丸］不用溫陽藥，只滋陰。
- **藥物的陰陽**：每一味藥都有一個陰陽座標，由四氣、五味與升降方向合成，見［學習書 第九章］。例如［本草 附子］大熱，偏於陽；［本草 黃連］苦寒，偏於陰。

**模型的簡化**：陰陽轉化、格拒、亡陰亡陽這些劇烈的動態與危重變化不在模型裡；遇到可能的危重表現，App 先以紅旗篩檢請使用者就醫（［SOP §2］）。寒熱錯雜、虛實夾雜時，App 不硬算一個平均值，而是標示「錯雜」、降低信心並建議就醫。陰陽的可分性（例如上午與下午的細分）也沒有進入計算。

## 練習

1. （選擇）下列屬性中屬陰的是：（A）上升（B）溫煦（C）寧靜（D）向外。
2. （選擇）「陰虛則內熱」所說的熱屬於：（A）實熱（B）虛熱（C）表熱（D）假熱。
3. （簡答）陰陽之間有哪四種關係？各舉一個人體或自然的例子。
4. （簡答）以晝夜為例，說明陰陽的相對性與可分性。
5. （簡答）比較實熱與虛熱的成因、表現與調整方向；為什麼虛熱不宜單用苦寒清熱？
6. （案例）甲長期畏寒、手足冰冷、喜熱飲、夜尿多、舌淡胖；乙手足心熱、午後潮熱、夜間盜汗、口燥咽乾、舌紅少苔。以陰陽理論分析兩人的失衡，並說明調整的方向。
