# 第五章　藏象學說

| 項目 | 內容 |
|---|---|
| **篇** | 第一篇　入門與理論基礎 |
| **建議時數** | 14 小時（講授 9、練習 5） |
| **先修** | 第三、四章 |
| **對應學科** | 中醫基礎理論 |

「藏象」二字，「藏」指藏在體內的臟腑，「象」指臟腑表現在外的生理與病理現象。藏象學說研究的，是各臟腑的功能、它們之間的關係，以及它們怎樣表現於外。它是中醫基礎理論的核心：後面的診斷、辨證與治療，幾乎都要落實到某一臟腑上。本章依次講五臟、六腑、奇恆之腑，再講臟腑之間的關係，最後練習把常見症狀歸到相關的臟腑。

## 學習目標

1. 說明藏象的含義，以及五臟、六腑、奇恆之腑的分類依據與功能特點。
2. 掌握五臟各自的主要功能，以及它們在體、竅、志、液、華上的聯繫。
3. 掌握六腑的功能，以及「六腑以通為用」的意義。
4. 了解奇恆之腑的組成與功能。
5. 說明臟與臟、臟與腑、腑與腑之間的主要關係。
6. 能把常見的症狀初步歸到相關的臟腑。

## 一、藏象學說概說

### （一）以五臟為中心的功能系統

藏象學說以五臟為中心，每一臟配一腑，並聯繫一定的形體、官竅、情志與體液，構成五個功能系統。例如肝系統包括肝、膽、筋、目、爪、怒、淚。第四章的五行歸類表，就是這五個系統的總覽。

要特別注意：中醫的臟腑**不等於**解剖學上的同名器官。中醫的「心」除了推動血液，還主管精神意識；「脾」主要指消化吸收與營養輸布的功能，與解剖上的脾臟關係不大；「腎」包括生長發育、生殖、水液代謝等多方面的功能。學習時要以中醫的定義為準，不要直接與現代醫學的器官對應。

### （二）臟腑的分類

依形態與功能的特點，臟腑分為三類：

| 類別 | 組成 | 功能特點 |
|---|---|---|
| 五臟 | 肝、心、脾、肺、腎 | 化生、貯藏精氣，宜充滿而不宜外泄；多為實體性器官 |
| 六腑 | 膽、胃、小腸、大腸、膀胱、三焦 | 受納、傳化水穀，宜通暢而不宜停滯；多為中空的器官 |
| 奇恆之腑 | 腦、髓、骨、脈、膽、女子胞 | 形態似腑（中空），功能似臟（貯藏精氣） |

古人用一句話分別臟與腑：五臟貯藏精氣而不外泄，所以充滿而不能壅實；六腑傳導飲食而不貯藏，所以時而壅實而不能常滿。這個分別在治療上很重要：五臟病多虛，治宜補；六腑病多實，治宜通。

## 二、五臟

### （一）心

**主要功能**

1. **主血脈**：心推動血液在脈管中運行，周流全身。心氣充足，脈搏和緩有力，面色紅潤；心氣不足，可見心悸、脈弱、面色無華。
2. **主神明（藏神）**：心主管人的精神、意識、思維與睡眠。心神安寧，則精神飽滿、思維敏捷、睡眠安穩；心神不安，則失眠、多夢、健忘、心煩。

**系統聯繫**：在體合脈，其華在面，開竅於舌，在志為喜，在液為汗。所以觀察面色、舌（尤其舌尖）可以了解心的狀態；汗為心之液，汗出過多也會耗傷心氣心血。

**附：心包**：心包是包在心外的膜，有保護心的作用，古人認為外邪侵犯心時，往往先由心包承受。

### （二）肺

**主要功能**

1. **主氣、司呼吸**：肺吸入自然界的清氣，呼出體內的濁氣；吸入的清氣與脾胃化生的水穀精氣合為「宗氣」，貫注心脈、推動呼吸。
2. **主宣發與肅降**：宣發是向上、向外布散，把衛氣與津液輸布到體表，溫潤皮毛、調節汗孔開合；肅降是向下、向內清肅，使呼吸通暢、氣機下行、水液下輸。
3. **通調水道**：肺的宣發肅降推動水液的輸布與排泄，所以肺被稱為「水之上源」。
4. **朝百脈、主治節**：全身的血液都流經肺，肺協助心推動血行，並調節全身的氣機。

**系統聯繫**：在體合皮，其華在毛，開竅於鼻，在志為悲（憂），在液為涕。肺位置最高、質地嬌嫩，外邪從口鼻皮毛侵入時首先犯肺，所以稱為「嬌臟」。肺氣虛的人容易感冒、自汗；肺失宣降則咳嗽、氣喘、鼻塞。

### （三）脾

**主要功能**

1. **主運化**：包括兩方面。一是**運化水穀**：把飲食消化吸收，化為精微，輸布全身，是氣血生化的來源；二是**運化水液**：吸收、輸布水液，防止水濕停聚。脾運化正常，則食慾良好、精力充沛、大便成形；脾失健運，則食少、腹脹、便溏、倦怠、消瘦，或水濕停聚而生痰、水腫。
2. **主升清**：脾把水穀精微向上輸送到心肺頭目，並維持內臟位置的相對穩定。脾氣不升，則頭暈、腹瀉；甚至中氣下陷，出現胃下垂、脫肛、子宮下垂等內臟下垂。
3. **主統血**：脾氣統攝血液在脈中運行而不外溢。脾不統血，可見各種慢性出血，例如皮下出血、月經過多。

**生理特性**：脾喜燥惡濕。濕邪最容易困阻脾氣，所以長夏濕盛、過食生冷甜膩，都容易傷脾。

**系統聯繫**：在體合肉、主四肢，開竅於口，其華在唇，在志為思，在液為涎。脾為「後天之本」「氣血生化之源」：人出生以後的生長與活動，都依靠脾胃化生的氣血。

### （四）肝

**主要功能**

1. **主疏泄**：肝使全身的氣機舒暢通達，不鬱不滯。這個功能表現在幾個方面：
   - **調暢情志**：疏泄正常則心情舒暢；疏泄不及則抑鬱、多嘆氣，疏泄太過則急躁易怒。
   - **促進消化**：肝的疏泄協助脾胃的升降與膽汁的分泌排泄。肝氣鬱結會引起胃脘脹痛、噯氣、食慾不振。
   - **促進血與津液的運行**：氣行則血行，氣滯則血瘀、水停。
   - **調節月經與生殖**：女子的月經與肝的疏泄、藏血密切相關。
2. **主藏血**：肝貯藏血液、調節血量。人在活動時血液流向四肢，休息時血液回歸於肝。肝血充足，則眼睛明亮、筋脈柔順、指甲紅潤；肝血不足，則視物模糊、眼睛乾澀、肢體麻木、指甲枯脆、月經量少。

**生理特性**：肝喜條達而惡抑鬱；肝「體陰而用陽」——以血為體，以疏泄為用；肝氣易於上逆、亢奮，所以又稱「剛臟」。

**系統聯繫**：在體合筋，其華在爪，開竅於目，在志為怒，在液為淚。

### （五）腎

**主要功能**

1. **藏精，主生長、發育與生殖**：腎貯藏先天之精（得自父母）與後天之精（由脾胃化生），腎精化生腎氣，主導人一生的生長、發育、生殖與衰老。腎精充足，則發育正常、精力旺盛；腎精不足，則小兒發育遲緩、成人早衰、生殖功能減退。
2. **主水**：腎的氣化作用調節全身的水液代謝，尤其是尿液的生成與排泄。腎陽不足，氣化失常，可見水腫、小便清長或夜尿頻多。
3. **主納氣**：肺吸入的清氣，要靠腎的攝納才能深沉。腎不納氣，則呼吸淺短、動則氣喘。

**腎陰與腎陽**：腎陰是全身陰液的根本，滋養各臟腑；腎陽是全身陽氣的根本，溫煦各臟腑。所以腎陰虛常見五心煩熱、潮熱盜汗、腰膝痠軟；腎陽虛常見畏寒肢冷、腰膝痠冷、夜尿頻多。古人又把腎陽稱為「命門之火」。

**系統聯繫**：在體合骨，生髓、通於腦，其華在髮，開竅於耳及二陰，在志為恐，在液為唾。腎為「先天之本」。

### （六）五臟功能總表

| 臟 | 主要功能 | 在體 | 其華 | 開竅 | 在志 | 在液 |
|---|---|---|---|---|---|---|
| 心 | 主血脈、主神明 | 脈 | 面 | 舌 | 喜 | 汗 |
| 肺 | 主氣司呼吸、宣發肅降、通調水道 | 皮 | 毛 | 鼻 | 悲 | 涕 |
| 脾 | 主運化、主升清、主統血 | 肉、四肢 | 唇 | 口 | 思 | 涎 |
| 肝 | 主疏泄、主藏血 | 筋 | 爪 | 目 | 怒 | 淚 |
| 腎 | 藏精、主水、主納氣 | 骨、髓 | 髮 | 耳、二陰 | 恐 | 唾 |

## 三、六腑

六腑共同的功能是受納、消化、吸收、傳導與排泄。它們的共同特點是「以通為用，以降為順」：保持通暢、向下傳導就是正常；一旦停滯、上逆就是病。

1. **膽**：貯藏與排泄膽汁，幫助消化；古人又說膽「主決斷」，與人的決斷力有關。膽的形態中空像腑，但它貯藏的膽汁屬於精汁，所以又列入奇恆之腑。膽熱上蒸可見口苦。
2. **胃**：主受納、腐熟水穀，是「水穀之海」；胃氣以下降為順。胃失和降，可見胃脘脹痛、噯氣、噁心嘔吐。胃喜潤惡燥，胃陰不足則口乾、饑而不欲食。
3. **小腸**：接受胃初步消化的食物，進一步消化，並「泌別清濁」：清者（精微與部分水液）被吸收，濁者下傳大腸，多餘的水液滲入膀胱。所以小腸的功能也關係到小便。
4. **大腸**：接受小腸下傳的糟粕，吸收其中的水分，形成糞便排出，稱為「傳導」。
5. **膀胱**：貯存與排泄尿液；它的開合依賴腎的氣化。
6. **三焦**：是氣與水液運行的通道。依部位分為上焦（膈以上，心肺）、中焦（膈至臍，脾胃肝膽）、下焦（臍以下，腎、膀胱、大小腸）。古人形容上焦「如霧」（像霧一樣布散精氣），中焦「如漚」（像浸泡一樣腐熟水穀），下焦「如瀆」（像水溝一樣排泄濁物）。第十三章的三焦辨證，就以這個劃分為基礎。

## 四、奇恆之腑

奇恆之腑包括腦、髓、骨、脈、膽、女子胞。「奇恆」是異於平常的意思：它們形態中空像腑，卻貯藏精氣像臟。

- **腦**：「元神之府」，主管精神、感覺與運動；由髓匯聚而成，與腎精關係密切。
- **髓、骨**：腎主骨生髓，骨髓充足則骨骼堅強。
- **脈**：血液運行的管道，與心相連。
- **女子胞**：即子宮，主月經與孕育，與腎、肝、脾以及衝脈、任脈的關係最為密切。

## 五、臟腑之間的關係

### （一）臟與臟

| 兩臟 | 關係的重點 | 失調時的常見證 |
|---|---|---|
| 心與肺 | 心主血、肺主氣，氣血互相推動 | 心肺氣虛 |
| 心與脾 | 脾化生血液並統血，心主血；心神也賴脾所化的血滋養 | 心脾兩虛：心悸、失眠、健忘、食少、乏力 |
| 心與肝 | 心主血、肝藏血；心主神明、肝主疏泄情志 | 心肝血虛、心肝火旺 |
| 心與腎 | 心火下降溫腎，腎水上濟制心火，稱為「心腎相交」「水火既濟」 | 心腎不交：心煩失眠、腰痠、潮熱盜汗 |
| 肺與脾 | 氣的生成相輔；水液代謝相關，「脾為生痰之源，肺為貯痰之器」 | 脾肺氣虛、痰濕犯肺 |
| 肺與肝 | 肝氣左升、肺氣右降，共同調節氣機升降 | 肝火犯肺 |
| 肺與腎 | 肺主呼氣、腎主納氣；肺腎共同調節水液，金水相生 | 腎不納氣、肺腎陰虛 |
| 肝與脾 | 肝的疏泄助脾運化；肝藏血、脾生血統血 | 肝脾不調、肝胃不和 |
| 肝與腎 | 肝藏血、腎藏精，精血互生，稱為「肝腎同源」 | 肝腎陰虛 |
| 脾與腎 | 脾為後天之本、腎為先天之本，互相資助；共同調節水液 | 脾腎陽虛 |

### （二）臟與腑：表裡關係

五臟與六腑之間有經脈相連，形成表裡配對：心與小腸、肺與大腸、脾與胃、肝與膽、腎與膀胱（另有心包與三焦）。臟屬裡，腑屬表；表裡之間在生理上互相配合，病理上互相影響：

- **心與小腸**：心火旺可以下移小腸，出現小便短赤、灼熱澀痛。
- **肺與大腸**：肺氣肅降有助於大腸傳導；肺氣不降可見大便不暢，大腸積熱也會影響肺氣，加重咳喘。
- **脾與胃**：脾主升、胃主降；脾喜燥、胃喜潤；兩者一升一降、燥濕相濟，共同完成消化。
- **肝與膽**：膽汁來源於肝之餘氣，肝的疏泄正常則膽汁排泄通暢；肝膽濕熱常同時出現。
- **腎與膀胱**：膀胱的開合依賴腎的氣化；腎氣不固則小便頻數、遺尿。

### （三）腑與腑

六腑在飲食的消化與排泄中依次接力：胃受納腐熟，膽汁助消化，小腸泌別清濁，大腸傳導糟粕，膀胱排出尿液，三焦是這一切通行的道路。任何一腑不通，都會影響其他各腑，所以說「六腑以通為用」。

## 六、從症狀到臟腑：初步的歸納

學完藏象，就可以把常見的症狀初步歸到相關的臟腑。這只是第一步，真正的辨證還要結合病性（寒熱虛實等），在第十二章完成。

| 常見表現 | 首先想到的臟腑 |
|---|---|
| 心悸、失眠多夢、健忘、心煩、舌尖紅 | 心 |
| 咳嗽、氣喘、氣短、容易感冒、自汗、鼻塞 | 肺 |
| 食少、飯後腹脹、大便溏稀、倦怠乏力、內臟下垂 | 脾 |
| 胃脘脹痛、噯氣、噁心、口乾而饑不欲食 | 胃 |
| 情緒抑鬱或急躁、嘆氣、脅肋脹痛、月經不調、眼睛乾澀 | 肝 |
| 口苦、脅痛 | 膽（常與肝同見） |
| 腰膝痠軟、耳鳴、夜尿頻多、早衰、呼吸淺短 | 腎 |
| 小便短赤、灼痛 | 小腸、膀胱 |
| 大便乾結或稀溏 | 大腸（常與脾、肺相關） |

## 古籍原文選讀

> 「脾氣虛則四肢不用」——《靈樞·本神》

**白話**：脾氣虛弱，四肢就會軟弱無力、不能靈活運用。脾主四肢與肌肉，脾化生的精微要輸送到四肢，四肢才有力量。所以脾虛的人常說「手腳沒力氣」。

> 「肝藏血，血舍魂」——《靈樞·本神》

**白話**：肝貯藏血液，而魂寄居在肝血之中。魂是精神活動的一部分，與睡眠和夢有關。肝血不足時，魂不安守，人就容易多夢、睡不安穩。這說明了肝藏血與精神活動的關係。

> 「肝受血而能視」——《素問·五藏生成》

**白話**：肝得到血液的滋養，眼睛才能看得清楚。肝開竅於目，肝血充足則目明；肝血不足則視物模糊、眼睛乾澀。這是肝血虛常見眼部症狀的理論根據。

> 「脾氣通於口」——《靈樞·脈度》

**白話**：脾的氣與口相通。脾氣調和，口能辨別五穀的味道，食慾正常；脾氣不和，就會口淡無味、口黏或食慾不振。這是「脾開竅於口」的根據。

> 「腎氣通於耳」——《靈樞·脈度》

**白話**：腎的氣與耳相通。腎氣充足，聽覺靈敏；腎精虧虛，則耳鳴、聽力減退。年長者聽力漸退，也與腎氣漸衰有關。

> 「女子七歲，腎氣盛」——《素問·上古天真論》

**白話**：女孩到了七歲左右，腎氣開始旺盛，換牙、頭髮生長。這一段原文接著以七年為一個階段，描述女子一生的發育與衰老；男子則以八年為一個階段。它說明了腎氣、腎精主導人的生長、發育、生殖與衰老。

> 「南方赤色，入通於心，開竅於耳，藏精於心」——《素問·金匱真言論》

**白話**：南方、紅色與心相通，心的精氣貯藏於心，而這裡說心「開竅於耳」。這與通行的「心開竅於舌」不同，說明古書中的五行歸類有不同的版本。教材以通行的說法為準，但知道這種差異，有助於理解五行歸類是功能的類比，而不是固定不變的規定。

> 「北方黑色，入通於腎，開竅於二陰，藏精於腎」——《素問·金匱真言論》

**白話**：北方、黑色與腎相通，腎開竅於前陰與後陰，精氣貯藏於腎。前陰主排尿與生殖，後陰主排便，都與腎的氣化與固攝有關，所以腎虛可見夜尿頻多、遺精、久瀉。

> 「胃不和，則臥不安」——《素問·逆調論》

**白話**：胃氣不和，就睡不安穩。飲食過飽、食積停滯或胃氣上逆，都會影響睡眠。這說明臟腑之間互相牽動：失眠不一定只是心的問題，也可能來自胃。

> 「中氣不足，溲便為之變」——《靈樞·口問》

**白話**：中焦脾胃之氣不足，大小便就會發生變化，例如大便溏稀、小便頻數或失禁。這說明了脾胃之氣對排泄的影響，也是中氣下陷時常見二便異常的根據。

## 本章小結

- 藏象指藏於體內的臟腑及其表現於外的現象；中醫的臟腑是功能系統，不等於解剖器官。
- 五臟貯藏精氣而不外泄，六腑傳化水穀而不貯藏，奇恆之腑形似腑而功能似臟。
- 心主血脈、主神明；肺主氣司呼吸、主宣發肅降、通調水道；脾主運化、升清、統血；肝主疏泄、藏血；腎藏精、主水、主納氣。
- 六腑以通為用、以降為順：膽、胃、小腸、大腸、膀胱、三焦各司其職。
- 臟與臟之間有氣血、水火、升降、精血等關係；臟與腑之間是表裡關係；腑與腑之間依次接力。
- 學會把常見症狀歸到臟腑，是第十二章臟腑辨證的基礎。

## 名詞

- **臟腑**：內臟的總稱，包括五臟、六腑與奇恆之腑；在中醫是功能系統而不只是解剖器官。
- **肝**：五臟之一，主疏泄、主藏血，在體合筋，開竅於目，在志為怒。
- **心**：五臟之一，主血脈、主神明，在體合脈，開竅於舌，在志為喜。
- **脾**：五臟之一，主運化、主升清、主統血，為後天之本，開竅於口，在志為思。
- **肺**：五臟之一，主氣司呼吸、主宣發肅降、通調水道，在體合皮，開竅於鼻。
- **腎**：五臟之一，藏精、主水、主納氣，為先天之本，在體合骨，開竅於耳及二陰。
- **膽**：六腑之一，貯藏與排泄膽汁，又屬奇恆之腑；與肝相表裡。
- **小腸**：六腑之一，主受盛化物、泌別清濁；與心相表裡。
- **胃**：六腑之一，主受納、腐熟水穀，以降為順；與脾相表裡。
- **大腸**：六腑之一，主傳導糟粕；與肺相表裡。
- **膀胱**：六腑之一，貯存與排泄尿液，依賴腎的氣化；與腎相表裡。
- **精**：構成人體與維持生命活動的精微物質，包括先天之精與後天之精，主要藏於腎。
- **神**：人的精神、意識、思維活動，以及生命活動的外在表現；由心所主。

## 與本 App 對照

模型怎樣把臟腑記成一本帳（盤面）、證型怎樣以證素入帳，見［學習書 第三章］〈狀態：人體的帳本〉與［SOP §10.1］。本章在 App 中對應的記錄：

- **證素的病位**：［證素 脾氣虛］、［證素 肝氣滯］、［證素 心血虛］、［證素 腎陽虛］、［證素 胃陰虛］、［證素 肺氣虛］——病位就是本章的臟腑。
- **一臟的功能與證型**：脾主運化對應［證型 SP1 脾氣虛］的食少、腹脹、便溏；脾主升清對應［證型 SP3 中氣下陷］的下墜感；肝藏血、肝受血而能視對應［證型 LV3 肝血虛］的視物模糊、爪甲不榮；腎藏精對應［證型 KD1 腎陰虛］與［證型 KD2 腎陽虛］的腰膝痠軟；肺主皮毛、衛外對應［證型 LG1 肺氣虛］的容易感冒、自汗；胃喜潤惡燥對應［證型 SP6 胃陰虛］的饑不欲食。
- **臟腑之間的關係**：心與脾對應［證型 HT1 心脾兩虛］，心與腎對應［證型 HT2 心腎不交］，肝與胃對應［證型 LV4 肝胃不和］；證型庫依臟腑的分組見［SOP §9.4］。

**模型的簡化**：盤面上只有十個臟腑；三焦、心包與奇恆之腑不在帳上；精與神沒有單獨的欄位，分別藉腎的陰陽與心的狀態間接表現；臟腑之間的關係只透過少數合併的證型與五行傳變表現。
