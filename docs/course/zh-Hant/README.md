# 中醫學系統課程——教科書

一門從零開始、完整而自足的中醫學課程，連同它的教科書。全書二十二章、五篇：由中醫的思維方式與理論基礎開始，經四診、辨證、治則、本草、方劑，到臨床病證、體質養生、運氣與時間醫學，再以一章導覽歷代典籍、一章整合臨床思維與安全倫理作結。

這是一本**自足的教科書**：學習者**不必另讀任何古籍原典**，也不必先讀過其他中醫書。每一個概念都在書中以現代白話講清楚；書中選錄的古籍原文只是例證，每一段之後都附有**白話**解說，讀懂白話就讀懂了那段原文要說的事。想讀原典的人，可以在讀完本書之後再讀，但那是延伸，不是本課程的要求。

寫給想系統學習中醫的人：中醫院校以外的自學者、本 App 的學習者與執業者角色、想把傳統理論與可計算的模型對照來讀的人。先備只需要高中程度的語文與生物常識。

## 四個約定

1. **自足。** 正文用現代中文寫成；學習者讀本書即可完成課程，不必另讀原典。書末的[本書依據的資料](sources.md)說明本書的講解出自哪些教材與典籍，供查證與延伸，不是指定讀物。
2. **引文都經過核對，並附白話。** 書中每一段放在引文框裡的古籍原文，都已在專案收錄的原典中逐字找到，出處標在引文後，緊接著是它的白話解說。書中點名的每一部書，都在專案的來源登錄（`data/sources.json`）中；指名到篇章的，該篇章都在參考語料庫裡找得到。
3. **只講道理，不談份量。** 本課程**不是醫療建議**，也不培養處方能力：書中沒有任何份量，不教任何人服用什麼。是否用藥、如何用藥，必須由執業中醫師親自診察後決定；出現危險徵象時，應先就醫。
4. **內容是草稿。** 本書的講解屬教材層級的整理，依據全國中醫藥行業高等教育規劃教材與歷代典籍；所對照的知識庫與模型也都是**草稿**，尚未經中醫師、藥師與語文審閱者審定。凡模型簡化之處，每一章都明白寫出。

## 每一章的編排

每一章都依同一順序編排：

| 段落 | 內容 |
|---|---|
| 學習目標 | 讀完這一章應該能做到的事 |
| 正文 | 以「一、二、三……」分節，用現代中文完整講解；本書的主體 |
| 古籍原文選讀 | 與本章相關的經典原句；每一句後面都有**白話**解說，說明它的意思與它在本章的位置 |
| 本章小結 | 以條列方式回顧重點 |
| 名詞 | 本章的術語與簡短定義，與 App 的詞彙表一致 |
| 與本 App 對照 | 本章的內容在專案的知識庫與模型裡如何呈現，以及**模型的簡化**之處 |
| 練習 | 選擇、簡答與案例題；答案在[習題解答](answers.md) |

讀法建議：先讀學習目標，再讀正文；古籍原文選讀可以與正文對照著讀，也可以讀完正文再讀；最後做練習、對答案。原文讀不懂沒有關係，白話已經說明了它的意思。

## 與本專案對照的標記

本專案把傳統的思路寫成可計算、可追溯的規則。書中以方括號標出可在專案中查到的資料，例如［證型 SP1 脾氣虛］、［方劑 桂枝湯］、［本草 人參］、［穴位 足三里］、［體質 氣虛質］、［食物 山藥］、［證素 脾氣虛］、［學習書 第二章］、［SOP §9.4］。這些名稱都與知識庫一致，可在 App 的「學習」區、學習書《以模型讀中醫》與辨證 SOP 中找到。學習模型是為了更清楚地看見傳統，不是用模型取代傳統。

## 先修關係

第一、二章可與任何一章並讀；第三、四章是一切之本；第五、六、七章在三、四章之後；第八章在五、六章之後；第九、十章在第八章之後；第十一至十三章依序；第十四章在第十一章之後；第十五、十六、十七章依序，並以第十四章為先修；第十八章以第十二、十七章為先修；第十九、二十章可在第一篇之後任何時候學；第二十一章可在第二篇之後任何時候讀；第二十二章最後。

## 用於教學

以一學年、每週六小時計：上學期教第一、二篇（十三章，152 小時），下學期教第三至五篇（九章，112 小時）。每章的練習可作課堂討論或作業；第二十二章的總結專題可作期末評量。自學者可以照章節順序，每週讀一章，約半年讀完正文，再以半年反覆練習與對照 App。
