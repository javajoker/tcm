# 第九章　四診（上）：望、聞、問

| 項目 | 內容 |
|---|---|
| **篇** | 第二篇　診斷與辨證 |
| **建議時數** | 12 小時（講授 7、練習 5） |
| **先修** | 第八章 |
| **對應學科** | 中醫診斷 |

辨證需要材料，材料來自四診：望、聞、問、切。望診用眼睛觀察，聞診用耳朵聽、用鼻子嗅，問診用語言詢問，切診用手觸按。本章講前三診，下一章專講舌診與脈診。學習四診，要記住一個原則：任何單一的發現都只是線索，必須「四診合參」，把所有線索放在一起，才能得出可靠的判斷。

## 學習目標

1. 說明四診的意義，以及四診合參的原則。
2. 掌握望神的四種情況，以及常色、病色與五色主病。
3. 了解望形體、姿態、局部與排出物的意義。
4. 說明聞診中聽聲音與嗅氣味的要點。
5. 掌握問診的內容與十問歌，熟悉寒熱、汗、疼痛、睡眠、飲食口味、二便與月經的問法與意義。
6. 分辨惡寒與畏寒、自汗與盜汗、潮熱與往來寒熱等常用症狀。

## 一、四診概說

### （一）四診的內容

| 診法 | 方法 | 內容 |
|---|---|---|
| 望診 | 用眼睛觀察 | 神、色、形、態、局部、舌象、排出物 |
| 聞診 | 用耳朵聽、用鼻子嗅 | 聲音、語言、呼吸、咳嗽，以及口氣、體味、排出物的氣味 |
| 問診 | 詢問病人或陪診者 | 主要不適、發病經過、寒熱、汗、疼痛、飲食、睡眠、二便、月經、舊病與用藥 |
| 切診 | 用手觸按 | 脈象，以及按壓胸腹、肌膚、手足 |

### （二）四診合參

四診各有長處，也各有局限：望診直觀但容易受光線、化妝、飲食的干擾；聞診需要經驗；問診內容最豐富，但依賴病人的描述；切診需要長期訓練。所以必須把四診所得合起來，互相印證，這稱為「四診合參」。當四診的結果彼此矛盾時（例如症狀像熱證而脈象像寒證），更要仔細分辨，第十一章會講到寒熱真假的問題。

### （三）診察的幾個原則

1. **整體審察**：既看局部，也看全身；既看身體，也看情志與生活。
2. **抓住主症**：病人最主要的不適是什麼？其他的症狀都圍繞它來理解。
3. **先排除危急**：有胸痛、呼吸困難、意識改變、突然單側無力、大量出血、高燒不退等危險徵象時，首先要就醫，而不是辨證。

## 二、望診

### （一）望神

「神」是人體生命活動的總體外在表現，包括精神、意識、目光、面色、表情、動作與反應。望神是望診的第一步，可以大致判斷正氣的盛衰與病情的輕重。

| 情況 | 表現 | 意義 |
|---|---|---|
| 得神（有神） | 目光明亮、神志清楚、表情自然、反應靈敏、面色榮潤 | 正氣充足，病情較輕，預後良好 |
| 少神 | 精神不振、目光少神、倦怠乏力、少氣懶言 | 正氣不足，多見於虛證或病後恢復期 |
| 失神（無神） | 目光晦暗、精神萎靡、反應遲鈍，甚至神志不清 | 正氣大傷，病情嚴重 |
| 假神 | 久病、重病的人突然精神好轉、想吃東西、面色泛紅 | 精氣將竭的危險徵兆，俗稱「迴光返照」 |

此外，神志錯亂（例如煩躁不安、言語錯亂、哭笑無常）稱為「神亂」，必須就醫。

### （二）望面色

**常色**：健康人的面色。東亞人的常色是紅黃隱隱、明潤含蓄，也就是透著淡淡的紅與黃、有光澤而不過分外露。常色又分兩種：一生基本不變的「主色」，以及隨季節、氣候、情緒、飲酒、運動而暫時改變的「客色」。

**病色**：疾病時的面色。病色中，明潤有光澤的稱為「善色」，說明病輕、正氣未衰；晦暗枯槁的稱為「惡色」，說明病重、精氣已傷。

**五色主病**：

| 色 | 主病 | 常見情況 |
|---|---|---|
| 青 | 寒、痛、瘀血、驚風 | 面色青灰見於寒凝或劇痛；口唇青紫見於瘀血；小兒眉間、鼻樑青色見於驚風 |
| 赤 | 熱 | 滿面通紅屬實熱；只有兩顴潮紅屬陰虛虛熱；久病面色蒼白而兩顴泛紅如妝，是危候 |
| 黃 | 脾虛、濕 | 面色萎黃（黃而枯槁無華）屬脾虛氣血不足；面黃而浮腫屬脾虛有濕；身目俱黃為黃疸，必須就醫 |
| 白 | 虛、寒、失血 | 面色淡白屬血虛或氣血兩虛；面白而虛浮屬陽虛；突然面色蒼白伴冷汗，是危急的表現 |
| 黑 | 腎虛、寒、水飲、瘀血 | 面色黧黑晦暗多屬腎陽虛或久病瘀血；眼眶周圍發黑多屬腎虛或水飲 |

古人還把面部分成幾個區域，分別對應不同的臟腑，其中鼻（古稱「明堂」）位於面部中央，是觀察的重點。

### （三）望形體與姿態

- **形體**：形體壯實的人多氣血充盛，瘦弱的人多氣血不足。肥胖而肌肉鬆軟、容易困倦的人多屬痰濕；形體消瘦而兩顴發紅、手足心熱的人多屬陰虛火旺。
- **姿態**：喜歡蜷縮而臥、加衣蓋被的，多屬寒證；喜歡仰臥伸展、掀去衣被的，多屬熱證；坐而不能平臥、呼吸困難的，多為肺病或心病，必須就醫。

### （四）望局部

- **頭髮**：髮為血之餘，腎其華在髮。頭髮稀疏易落、早白，多屬腎虛或血虛。
- **眼睛**：目赤腫痛多屬肝火或風熱；眼瞼浮腫多屬水濕；白睛發黃是黃疸。
- **口唇**：唇色淡白屬血虛；唇色深紅屬熱；唇色青紫屬瘀血或寒；口唇乾裂屬燥或津傷。
- **咽喉**：紅腫疼痛屬實熱；色淡紅而微痛屬陰虛。
- **皮膚**：皮膚乾燥粗糙、像魚鱗一樣（肌膚甲錯）多屬瘀血日久；皮膚出現斑疹，要辨別顏色與分布；皮膚發黃要排除黃疸。
- **指甲**：指甲淡白屬血虛；指甲青紫屬瘀血或寒；指甲枯脆屬肝血不足。

### （五）望排出物

痰、涕、嘔吐物、二便、帶下等排出物，清稀色白的多屬寒，黃稠渾濁的多屬熱（見第八章的病機十九條）。例如痰白而清稀屬寒痰，痰黃而黏稠屬熱痰，痰少而黏、難以咳出屬燥痰或陰虛。

舌診是望診中最重要的部分，下一章專門講解。

## 三、聞診

### （一）聽聲音

1. **語聲**：聲音高亢有力，多屬實證、熱證；聲音低微無力，多屬虛證、寒證。新病聲音嘶啞多屬外邪犯肺的實證；久病聲音嘶啞多屬肺腎陰虛。
2. **語言**：神志不清、胡言亂語、聲高有力的，稱為「譫語」，多屬熱擾心神的實證；神志不清、語言重複、聲音低弱的，稱為「鄭聲」，多屬心氣大傷的虛證。兩者都是危重的表現。說話聲音低弱、說了一句之後很久才接下一句，是氣虛的表現。
3. **呼吸**：呼吸氣粗、急促，多屬實證；呼吸氣微、短淺，多屬虛證。呼吸困難、張口抬肩稱為「喘」；喉中有哮鳴音稱為「哮」。突然的呼吸困難必須立即就醫。
4. **咳嗽**：咳聲重濁、痰多，多屬寒濕或痰濁；乾咳無痰或少痰，多屬燥邪或陰虛；咳聲低弱無力，多屬肺氣虛。
5. **其他聲音**：噯氣（胃氣上逆，常與肝胃不和或食積有關）、呃逆、嘔吐聲；常常不自覺地長嘆一口氣，稱為「善太息」，多屬肝氣鬱結。

### （二）嗅氣味

- **口氣**：口氣酸臭多屬食積；口氣臭穢多屬胃熱。
- **排出物**：分泌物與排泄物氣味腥臭而清稀的多屬寒，氣味臭穢而黏稠的多屬熱；大便酸臭多屬食積。

## 四、問診

問診是收集資料最主要的方法：許多症狀，例如疼痛、怕冷、口渴、失眠，只有病人自己知道。問診的態度要耐心、細緻，不誘導、不暗示；用詞要通俗，讓病人聽得懂。

### （一）問診的內容

1. **一般情況**：年齡、性別、職業、居住地等。
2. **主訴**：最主要的不適及其持續時間，例如「胃脘脹痛三個月」。
3. **現病史**：從發病到現在的經過、變化，以及做過的檢查與治療。
4. **既往史**：過去的疾病、手術、過敏。
5. **個人生活史**：飲食習慣、起居作息、情緒、嗜好（菸酒等）、工作環境。
6. **月經生育史**（女性）。
7. **正在使用的藥物**：這一點與安全直接相關，任何調整都要考慮。

### （二）十問歌

明代張介賓把問診的要點編成「十問歌」，便於記誦：一問寒熱，二問汗，三問頭身，四問二便，五問飲食，六問胸腹，七問耳聾，八問口渴，九從脈色辨陰陽，十從氣味察神情。後人加以修改，補入問舊病、問病因、問用藥、問月經與小兒的內容。十問歌不是死板的順序，而是提醒醫者不要遺漏重要的方面。

### （三）問寒熱

寒熱是問診的第一項，因為它直接關係到病性（寒熱）與病位（表裡）。先要分清兩個詞：

- **惡寒**：病人怕冷，即使加衣蓋被、靠近火爐也不能緩解。多見於外感表證，是外邪束表、衛陽被遏的表現。
- **畏寒**：病人怕冷，但加衣蓋被、靠近溫暖就能緩解。多見於裡寒證，尤其是陽虛。

寒熱的常見類型：

| 類型 | 表現 | 意義 |
|---|---|---|
| 惡寒發熱 | 怕冷與發熱同時出現 | 表證。惡寒重、發熱輕屬風寒；發熱重、惡寒輕屬風熱；發熱輕而怕風、有汗，屬表虛 |
| 但寒不熱 | 只怕冷不發熱 | 裡寒證。久病畏寒、肢冷屬陽虛；新病突然腹部冷痛屬寒邪直中 |
| 但熱不寒 | 只發熱不怕冷 | 裡熱證。高熱持續（壯熱）屬裡實熱；定時發熱或定時熱甚（潮熱）見下 |
| 往來寒熱 | 怕冷與發熱交替出現 | 半表半裡的少陽病，或瘧疾 |

**潮熱**是像潮水一樣按時發作或按時加重的發熱：午後或夜間發熱、伴手足心熱、盜汗，屬陰虛潮熱；下午三至五時熱甚、伴腹滿便秘，屬陽明腑實；身熱不揚、午後較明顯、伴身重胸悶，屬濕溫。

### （四）問汗

- **表證有無汗**：無汗而惡寒，屬表實（風寒束表）；有汗而惡風，屬表虛或風熱。
- **自汗**：白天不因勞動、天熱、衣厚而經常汗出，活動後更甚，多屬氣虛、衛表不固。
- **盜汗**：入睡後出汗、醒來後汗止，多屬陰虛內熱。
- **大汗**：高熱、大渴、大汗、脈洪大，屬裡實熱；汗出不止、冷汗淋漓、四肢冰冷、脈微，是亡陽的危候，必須立即就醫。
- **局部汗出**：只有頭部出汗、手足心出汗、半身出汗，各有不同的意義，要結合全身判斷。

### （五）問疼痛

疼痛要問性質、部位、時間與喜按或拒按：

| 性質 | 意義 |
|---|---|
| 脹痛 | 氣滯，脹多於痛，時輕時重 |
| 刺痛 | 瘀血，痛如針刺，部位固定 |
| 冷痛 | 寒證，得溫則減 |
| 灼痛 | 熱證，有灼熱感 |
| 重痛 | 濕證，痛而沉重 |
| 隱痛 | 虛證，痛勢綿綿，可以忍受 |
| 絞痛 | 有形實邪阻塞，例如結石，劇痛應就醫 |
| 走竄痛 | 風或氣滯，部位不定 |

一般來說，疼痛喜歡按壓、按之減輕的屬虛；拒絕按壓、按之加重的屬實。胸痛（尤其伴冷汗、呼吸困難、痛連左臂或下顎）是危險徵象，必須立即就醫。

### （六）問頭身與胸腹

頭暈目眩要分辨虛實：伴頭脹痛、面紅、急躁的多屬肝陽上亢或肝火；伴頭重如裹、胸悶噁心的多屬痰濕；伴面色淡白、心悸乏力的多屬氣血不足。**心悸**是病人自覺心跳不安、心慌，多與心有關，可由心血不足、心氣虛、心陰虛或痰火擾心引起；若伴胸痛、暈厥或心跳極快極慢，必須就醫。胸悶多與心肺或痰濕有關；脅脹多與肝膽有關；胃脘痞脹多與脾胃有關；腹脹要分虛實。

### （七）問耳目

耳鳴突然發作、聲音大如潮水、按耳不減的，多屬實證，常與肝火有關；耳鳴逐漸發生、聲音細小如蟬鳴、按耳可減的，多屬虛證，常與腎虛有關。眼睛乾澀、視物模糊，多屬肝血不足。

### （八）問睡眠

失眠要問清楚是難以入睡、容易醒來、早醒，還是多夢：難以入睡、心煩，多屬心火或陰虛火旺；容易醒、多夢、心悸健忘，多屬心脾兩虛；心煩不得眠、腰痠、潮熱，多屬心腎不交；失眠伴易驚、口苦、痰多，多屬痰熱擾心；飲食過飽後睡不安，多屬胃不和。嗜睡、困倦多屬陽虛或痰濕。

### （九）問飲食與口味

- **口渴與飲水**：口渴喜冷飲屬熱；口不渴屬寒或濕；渴而不想多喝，多屬濕或痰飲阻滯、津液不能上承；口燥咽乾而少飲，多屬陰虛。
- **食慾**：食少、飯後腹脹，屬脾胃氣虛；容易餓、吃得多而消瘦，屬胃火；餓了卻不想吃，屬胃陰不足；厭食、噯腐，屬食積。
- **口味**：口苦屬肝膽有熱；口甜或口黏膩屬脾胃濕熱或濕濁；口淡無味屬脾虛；口酸屬食積或肝胃不和。

### （十）問二便

- **大便**：便秘而乾結、口渴，多屬熱或陰虛；排便無力、便後乏力，多屬氣虛；大便溏稀，多屬脾虛；大便夾有未消化的食物（完穀不化），多屬脾腎陽虛；大便黏滯不爽、臭穢，多屬濕熱；天亮前腹瀉，多屬腎陽虛。大便帶血或呈黑色，必須就醫。
- **小便**：小便短少色黃屬熱；小便清長屬寒；夜尿頻多屬腎陽虛；小便頻急、澀痛屬濕熱。小便帶血必須就醫。

### （十一）問月經與帶下

月經要問週期、經期、量、色、質與伴隨的不適：週期提前、量多色紅，多屬血熱；週期延後、量少色淡，多屬血虛或寒；經色紫暗有塊、痛如針刺，多屬瘀血；經前乳房脹痛、情緒波動，多屬肝氣鬱結；經期小腹冷痛、得溫則減，多屬寒。帶下色白清稀多屬脾虛或寒濕；色黃黏稠、有臭味多屬濕熱。異常出血或停經應就醫。

### （十二）問情志與舊病

詢問情緒、壓力、作息與過去的疾病，有助於了解病因（第八章），也有助於判斷體質（第十九章）。正在使用的藥物與過敏，則是用藥安全的基本資料。

## 五、四診資料的整理

收集到的資料要整理：

1. **分主次**：找出主症，其他症狀作為兼症。
2. **辨真偽**：注意症狀之間的矛盾，以及受飲食、藥物、環境干擾的發現（例如吃了有顏色的食物後的舌苔）。
3. **評可信度**：病人親口描述的症狀較可靠；自己觀察的舌象、面色次之；沒有經過訓練的自我把脈最不可靠。
4. **先排危急**：一旦出現危險徵象，就醫優先。

整理好的資料，就是第十一至十三章辨證的材料。

## 古籍原文選讀

> 「望而知之謂之神」——《難經·六十一難》

**白話**：只憑觀察就能了解病情的，稱為「神」。《難經》依次把望、聞、問、切四診的高下排列，望診居首，說明它的重要與困難。這是四診並稱最早的系統說法之一。

> 「得神者昌，失神者亡」——《素問·移精變氣論》

**白話**：病人有神，預後良好；病人失神，預後險惡。望神可以判斷正氣的存亡，所以望診首先要看神。

> 「五色獨決於明堂」——《靈樞·五色》

**白話**：觀察五色，主要在「明堂」——也就是鼻部——來決斷。鼻位於面部中央，是古人觀察面色的重點區域；這一篇也把面部各區與臟腑相配。

> 「見其色，知其病，命曰明」——《靈樞·邪氣藏府病形》

**白話**：看見病人的面色，就能知道他的病，這叫做「明」。這說明了望色在診斷上的價值：面色是內在狀態最直接的外在表現之一。

> 「青如草茲者死」——《素問·五藏生成》

**白話**：面色青得像枯死的草一樣，是死亡的徵兆。古人用一系列比喻區分善色與惡色：同樣是青色，明潤的是善色，像枯草一樣晦暗沒有光澤的是惡色，說明臟氣已經衰敗。重點不在顏色本身，而在有沒有光澤與生氣。

> 「視喘息，聽音聲」——《素問·陰陽應象大論》

**白話**：觀察病人的呼吸喘息，聽病人的聲音。這一句說明了聞診與望診的配合：呼吸的粗細、聲音的強弱，都是判斷虛實的重要依據。

> 「言而微，終日乃復言者」——《素問·脈要精微論》

**白話**：說話聲音微弱，說了一句之後要過很久才能再說下一句。原文接著指出，這是氣被奪、氣虛的表現。聽聲音可以判斷氣的盛衰。

> 「一問寒熱二問汗，三問頭身四問便，五問飲食六問胸，七聾八渴俱當辨，九因脈色察陰陽，十從氣味章神見」——《景岳全書·傳忠錄·十問篇》

**白話**：問診的次序是：一問寒熱，二問汗出，三問頭身的不適，四問大小便，五問飲食，六問胸腹，七問耳聾，八問口渴，九是結合脈象與面色辨別陰陽，十是從氣味與神情觀察精神狀態。這就是張介賓的「十問歌」，至今仍是問診的基本框架。

## 本章小結

- 四診是望、聞、問、切；四診必須合參，任何單一發現都只是線索；危險徵象優先就醫。
- 望神分得神、少神、失神、假神；常色紅黃隱隱、明潤含蓄；病色分善惡；五色各主不同的病。
- 望形體、姿態、局部與排出物都有診斷意義：清稀屬寒、黃稠屬熱。
- 聞診聽語聲、語言、呼吸、咳嗽與其他聲音，嗅口氣與排出物的氣味。
- 問診以十問歌為框架：寒熱、汗、頭身、二便、飲食、胸腹、耳目、口渴、睡眠、月經、舊病與用藥。
- 惡寒加衣不減、多屬表證；畏寒得溫則減、多屬裡寒陽虛。自汗多屬氣虛，盜汗多屬陰虛。潮熱按時而發，往來寒熱寒熱交替。

## 名詞

- **四診**：望、聞、問、切四種診察方法的合稱，必須四診合參。
- **望診**：用眼睛觀察病人的神、色、形、態、局部、舌象與排出物。
- **聞診**：聽病人的聲音、呼吸、咳嗽，嗅病人的口氣與排出物氣味。
- **問診**：詢問病人的主要不適、發病經過與寒熱、汗、飲食、睡眠、二便等情況。
- **切診**：用手觸按病人的脈搏與身體部位，包括脈診與按診。
- **十問歌**：明代張介賓把問診要點編成的歌訣，是問診的基本框架。
- **惡寒**：怕冷，加衣蓋被或近火取暖仍不能緩解，多見於外感表證。
- **畏寒**：怕冷，加衣蓋被或近溫暖即可緩解，多見於裡寒證，尤其是陽虛。
- **自汗**：白天不因勞動、天熱而經常汗出，活動後加重，多屬氣虛、衛表不固。
- **盜汗**：入睡後汗出、醒後汗止，多屬陰虛內熱。
- **潮熱**：按時發熱或按時熱甚，如潮水有定時；常見陰虛潮熱、陽明潮熱與濕溫潮熱。
- **心悸**：自覺心跳不安、心慌，多與心有關，可由心血不足、心氣虛、陰虛或痰火引起。
- **往來寒熱**：怕冷與發熱交替出現，是少陽病半表半裡的典型表現。

## 與本 App 對照

模型怎樣把四診當成量測、給每一筆資料標上可信度，見［學習書 第四章］〈量測：由外知內〉。本章在 App 中對應的記錄：

- **以問為主**：十問歌加上睡眠與情志，共十二個面向，見［SOP §4.2］；下一題問什麼依前面的回答決定，見［SOP §4.8］。
- **常用症狀的分辨**：「惡寒（加衣被仍冷）」與「畏寒（得溫則減）」是兩個不同的症狀：［證型 EX1 風寒束表］以惡寒為必要症狀，［證型 SP2 脾陽虛］與［證型 KD2 腎陽虛］以畏寒為必要症狀；［證型 LG1 肺氣虛］看重自汗與容易感冒；［證型 KD1 腎陰虛］與［證型 LG2 肺陰虛］看重盜汗與午後潮熱；［證型 HT1 心脾兩虛］以心悸與健忘為必要症狀；［證型 LV1 肝氣鬱結］看重善太息，這是一個聞診與問診交會的症狀。
- **望與聞**：望診的指引見［SOP §4.3］，聞診只靠自述，見［SOP §4.5］，各類資料的可信度見［SOP §4.7］。
- **紅旗優先**：任何辨證之前，App 先問一組應立即就醫的問題，見［SOP §2.3］。

**模型的簡化**：望神、望形態、聽聲音、嗅氣味都只能靠使用者自述；假神、神亂、譫語這些危重表現，App 不做辨證，只以紅旗請使用者就醫；問診的題庫是固定的，不能像醫師那樣隨病人的回答自由追問。
