# 第七章　經絡與腧穴

| 項目 | 內容 |
|---|---|
| **篇** | 第一篇　入門與理論基礎 |
| **建議時數** | 12 小時（講授 7、練習 5） |
| **先修** | 第五、六章 |
| **對應學科** | 針灸推拿、中醫基礎理論 |

經絡是運行氣血、聯絡臟腑與肢體的通道；腧穴是經絡之氣輸注於體表的部位。臟腑在內，經絡把它們與體表、四肢、官竅連成一體，所以內在的病變可以反映到體表的某條線、某個點上，刺激體表的某些點也能影響內在的臟腑。本章講經絡系統的組成、十二經脈的分布與流注、奇經八脈、經絡的功能與應用，以及腧穴的分類與定位。本課程只講理論、定位與穴位按壓，不講針刺與艾灸：那些需要專業訓練與執照。

## 學習目標

1. 說明經絡的概念與經絡系統的組成。
2. 說出十二經脈的名稱、命名規律、分布規律、表裡關係與流注次序。
3. 說明奇經八脈的組成，以及督脈、任脈、衝脈、帶脈的主要作用。
4. 說明經絡的生理功能，以及它在解釋病理、診斷與治療上的應用。
5. 說明腧穴的分類、特定穴的概念與三種定位方法。
6. 認識常用穴位的位置與按壓的安全須知。

## 一、經絡的概念與系統

### （一）經與絡

經絡是經脈與絡脈的合稱。「經」有路徑的意思，是經絡系統的主幹，大多循行於深部，有固定的路線；「絡」有網絡的意思，是經脈的分支，循行於較淺的部位，縱橫交錯，遍布全身。經絡把臟腑、四肢、五官、皮肉筋骨聯結成一個整體。

### （二）經絡系統的組成

| 部分 | 內容 | 作用 |
|---|---|---|
| 十二經脈 | 手足三陰三陽經，各屬一臟或一腑 | 經絡系統的主體，氣血運行的主要通道 |
| 奇經八脈 | 督、任、衝、帶、陰蹻、陽蹻、陰維、陽維 | 調節十二經脈的氣血 |
| 十二經別 | 由十二經脈別出的分支 | 加強表裡兩經在體內的聯繫 |
| 十五絡脈 | 十二經脈與督任各一絡，加脾之大絡 | 加強表裡兩經在體表的聯繫 |
| 浮絡、孫絡 | 浮於淺表的絡脈與最細小的分支 | 遍布全身，輸布氣血 |
| 十二經筋 | 十二經脈之氣結聚於筋肉的部分 | 約束骨骼，主管關節運動 |
| 十二皮部 | 十二經脈在體表皮膚的分區 | 反映經脈的病變，抵禦外邪 |

## 二、十二經脈

### （一）名稱與命名規律

十二經脈的名稱由三部分組成：**手或足**（循行於上肢或下肢）＋**陰陽**（三陰為太陰、少陰、厥陰；三陽為陽明、太陽、少陽）＋**所屬的臟腑**。

| 手三陰 | 手三陽 | 足三陽 | 足三陰 |
|---|---|---|---|
| 手太陰肺經 | 手陽明大腸經 | 足陽明胃經 | 足太陰脾經 |
| 手厥陰心包經 | 手少陽三焦經 | 足少陽膽經 | 足厥陰肝經 |
| 手少陰心經 | 手太陽小腸經 | 足太陽膀胱經 | 足少陰腎經 |

屬臟的是陰經，屬腑的是陽經。

### （二）分布規律

- **四肢**：陰經分布於四肢內側，陽經分布於四肢外側。上肢內側由前到後依次是太陰、厥陰、少陰；上肢外側依次是陽明、少陽、太陽。下肢外側與背面是陽明（前）、少陽（側）、太陽（後）；下肢內側在小腿下半部是厥陰在前、太陰在中，往上則太陰在前、厥陰在中，少陰都在後。
- **頭面**：陽明經行於面部與前額，少陽經行於頭側，太陽經行於後頭與頭頂。所有陽經都上行到頭，所以說「頭為諸陽之會」。
- **軀幹**：手三陰從胸部走出；足三陽中，陽明行於胸腹前面，少陽行於側面，太陽行於背部；足三陰行於腹部。

### （三）走向與交接

- 手三陰經從胸走手；手三陽經從手走頭；足三陽經從頭走足；足三陰經從足走腹、胸。
- 表裡相配的陰經與陽經在手足末端交接；同名的陽經（例如手陽明與足陽明）在頭面部交接；陰經與陰經在胸部交接。

這樣，十二經脈首尾相接，形成一個「陰陽相貫，如環無端」的循環。

### （四）表裡關係

十二經脈中，屬臟的陰經與屬腑的陽經兩兩相配，成為表裡：肺經與大腸經、脾經與胃經、心經與小腸經、腎經與膀胱經、心包經與三焦經、肝經與膽經。表裡兩經在四肢末端交接，在體內屬絡相應的臟腑，所以臟與腑的病變可以互相影響（見第五章）。

### （五）流注次序

氣血在十二經脈中依一定的次序循環流注：

肺 → 大腸 → 胃 → 脾 → 心 → 小腸 → 膀胱 → 腎 → 心包 → 三焦 → 膽 → 肝 → 再回到肺。

古人把這個次序與一天的十二個時辰相配，認為每條經在某個時辰氣血最旺，第二十章會再提到這種時間醫學的觀點。

### （六）從循行理解症狀：幾個例子

經絡的循行路線，可以解釋許多症狀出現的部位：

- **足太陽膀胱經**起於眼內角，上額、交會於頭頂，下行後頭與項部，沿脊柱兩旁下行到腰。所以外感風寒、太陽經受邪時，常見頭痛連及後頸、項背拘緊。
- **足少陽膽經**起於眼外角，行於頭側，下行經脅肋。所以少陽病見口苦、目眩、胸脅苦滿，偏頭痛也常歸於少陽。
- **足厥陰肝經**繞陰器、抵小腹、布於脅肋、上達頭頂。所以肝氣鬱結常見脅肋脹痛、乳房脹痛、小腹脹，肝的病也可見頭頂痛。
- **足陽明胃經**行於面部與前額，所以胃熱可見前額痛、牙齦腫痛。

## 三、奇經八脈

奇經八脈不直屬臟腑，也沒有表裡配對，所以稱為「奇經」。它們縱橫交錯於十二經脈之間，作用像湖泊之於江河：十二經脈氣血充盛時，蓄積於奇經；不足時，奇經又能補充。

| 奇經 | 循行 | 主要作用 |
|---|---|---|
| 督脈 | 行於背部正中，上至頭頂 | 總督一身的陽經，稱為「陽脈之海」 |
| 任脈 | 行於胸腹正中 | 總任一身的陰經，稱為「陰脈之海」；與妊娠有關 |
| 衝脈 | 與足少陰腎經並行，上至頭、下至足 | 調節十二經氣血，稱為「十二經脈之海」「血海」；與月經有關 |
| 帶脈 | 環繞腰腹一周 | 約束縱行的各經 |
| 陰蹻、陽蹻 | 起於足跟，上行至眼 | 主肢體運動與眼瞼開合，與睡眠有關 |
| 陰維、陽維 | 分別聯絡陰經與陽經 | 維繫諸陰經與諸陽經 |

督脈與任脈有自己的穴位，與十二經脈合稱「十四經」。

## 四、經絡的生理功能

1. **溝通內外，聯絡臟腑肢節**：使臟腑與體表、四肢、官竅聯為一體。
2. **運行氣血，濡養全身**：氣血通過經絡輸送到全身各處。
3. **抵禦外邪，反映病候**：衛氣通過絡脈布散於體表，抵禦外邪；臟腑的病變也通過經絡反映到體表。
4. **傳導感應，調節平衡**：刺激體表的穴位，感應可以沿經絡傳導，調節臟腑的功能。這是穴位按壓與針灸能發揮作用的理論基礎。

## 五、經絡學說的應用

### （一）解釋病理

外邪可以由皮毛經絡傳入臟腑；臟腑的病變也可以沿經絡反映到體表與官竅。例如心火上炎見舌尖紅、口舌生瘡；肝火上炎見目赤、脅痛；胃火上炎見牙齦腫痛。

### （二）指導診斷

1. **依部位辨經**：以頭痛為例，前額痛多屬陽明經，兩側痛多屬少陽經，後頭痛連及項部多屬太陽經，頭頂痛多屬厥陰經。
2. **循經觸察**：在經絡循行路線或特定穴位上出現壓痛、結節或皮膚變化，可以提示相關臟腑的病變。

### （三）指導治療

1. **循經取穴**：病在某經，就在該經或相表裡的經上選穴，所謂「經脈所過，主治所及」。例如胃痛取胃經的足三里，頭頂痛取肝經的太衝。
2. **藥物歸經**：藥物對某些經絡臟腑有選擇性的作用，稱為歸經，第十五章會詳細討論。

## 六、腧穴

### （一）概念

腧穴（俗稱穴位）是臟腑經絡之氣輸注於體表的部位。它既是疾病的反應點，也是治療時施加刺激的部位。

### （二）分類

1. **經穴**：歸屬於十四經、有固定名稱與位置的穴位，是腧穴的主體。
2. **奇穴**：有固定名稱與位置、但未歸入十四經的穴位。
3. **阿是穴**：沒有固定位置，以壓痛點或病變局部為穴，所謂「以痛為腧」。

### （三）特定穴

十四經中有一些具有特殊作用的穴位，稱為特定穴：

| 特定穴 | 意思 | 例子 |
|---|---|---|
| 五輸穴 | 肘膝以下依井、滎、輸、經、合排列的五個穴，比喻經氣由小到大的流注 | 湧泉是腎經井穴，行間是肝經滎穴，崑崙是膀胱經經穴，足三里是胃經合穴 |
| 原穴 | 臟腑原氣經過與留止的部位，多用於臟腑虛實的調治 | 太淵（肺）、太溪（腎）、太衝（肝）、神門（心）、合谷（大腸） |
| 絡穴 | 絡脈從經脈分出之處，溝通表裡兩經 | 列缺（肺經）、內關（心包經）、豐隆（胃經） |
| 背俞穴 | 臟腑之氣輸注於背腰部的穴位 | 腎俞 |
| 募穴 | 臟腑之氣匯聚於胸腹部的穴位 | 中脘（胃）、膻中（心包）、關元（小腸）、石門（三焦） |
| 八會穴 | 臟、腑、氣、血、筋、脈、骨、髓精氣會聚之處 | 中脘為腑會，膻中為氣會，膈俞為血會，太淵為脈會 |
| 下合穴 | 六腑之氣下合於足三陽經的穴位 | 足三里為胃的下合穴 |
| 八脈交會穴 | 十二經脈與奇經八脈相通的穴位 | 列缺通任脈，內關通陰維脈 |
| 交會穴 | 兩條或兩條以上經脈交會的穴位 | 三陰交（足三陰經）、大椎（諸陽經與督脈）、百會、風池 |

### （四）定位方法

1. **骨度分寸法**：以骨節為標誌，把身體各部的長度折算成一定的「寸」數，再按比例定穴。例如肘橫紋到腕橫紋為 12 寸，胸骨下端到肚臍為 8 寸，肚臍到恥骨聯合上緣為 5 寸，膝後橫紋到外踝尖為 16 寸。因為是按比例折算，高矮胖瘦的人都適用。
2. **體表標誌法**：以五官、毛髮、指甲、乳頭、肚臍、骨節突起與凹陷、肌肉隆起等標誌定穴，或以關節屈伸時出現的皺紋、凹陷為標誌。
3. **手指同身寸法**：以本人的手指為尺度。中指中節兩端橫紋之間為 1 寸；拇指指間關節的寬度為 1 寸；食指、中指、無名指、小指四指併攏，以中指中節橫紋處的寬度為 3 寸（又稱「一夫法」）。

這裡的「寸」是比例單位，不是固定長度。

### （六）穴位按壓的安全須知

穴位按壓是簡單的自我保健方法，但也有幾條必須遵守的原則：

1. 力道輕到中等，以有痠脹感而不疼痛為度；頸部與腹部尤其要輕。
2. 皮膚破損、發炎、瘀青或腫脹的地方不要按。
3. 懷孕或可能懷孕時，不要按壓上表註明「孕期避按」的穴位。
4. 按壓時如果出現疼痛加劇、頭暈、噁心、冒冷汗或麻木，要立即停止。
5. 有胸痛、胸悶時不要自行按壓胸部穴位，應先就醫。
6. 穴位按壓不能取代就醫；不適持續或加重時，應請醫師診察。

## 古籍原文選讀

> 「盛則瀉之，虛則補之」——《靈樞·經脈》

**白話**：經脈之氣過盛就用瀉法，不足就用補法。這出自《靈樞》專門講十二經脈循行與病候的一篇：每條經脈的病候之後，都附上這個治療原則。它說明經絡的病變也有虛實之分，調治要依虛實而定。

> 「實則瀉之，虛則補之」——《素問·三部九候論》

**白話**：邪氣盛實就瀉，正氣虛弱就補。這一篇講的是全身分上、中、下三部，每部各有三處動脈可以診察的「三部九候」方法。與上一段合讀，可知補虛瀉實是經絡調治與一切治療共同的大原則，第十四章會再討論。

> 「太陽之為病，脈浮，頭項強痛而惡寒」——《傷寒論·辨太陽病脈證並治上》

**白話**：太陽病的表現是脈浮、頭痛而項部拘緊不舒、怕冷。足太陽膀胱經行於頭頂、後頭與項背，是人體最外層的一條經，外邪侵襲時首當其衝，所以太陽病的頭痛連及後頸。這句話是用經絡循行理解症狀部位的好例子，第十三章會再詳細討論。

> 「少陽之為病，口苦、咽乾、目眩也」——《傷寒論·辨少陽病脈證並治》

**白話**：少陽病的表現是口苦、咽喉乾、頭暈眼花。足少陽膽經起於眼外角、行於頭側，膽汁味苦，所以膽經有熱時，口苦、目眩相繼出現。這也說明了經絡所屬的臟腑與循行部位，如何共同決定症狀的樣貌。

> 「腎氣通於耳」——《靈樞·脈度》

**白話**：腎的氣與耳相通。《靈樞》在討論經脈長度的一篇中，說明五臟之氣各自通於七竅：肺通於鼻，心通於舌，肝通於目，脾通於口，腎通於耳。臟腑之氣通過經脈上達頭面官竅，所以官竅的病變可以反映臟腑的狀態。

## 本章小結

- 經絡是經脈與絡脈的合稱，是運行氣血、聯絡臟腑肢節的通道；系統包括十二經脈、奇經八脈、經別、絡脈、經筋與皮部。
- 十二經脈依手足、陰陽、臟腑命名；陰經行於四肢內側，陽經行於外側；手三陰從胸走手，手三陽從手走頭，足三陽從頭走足，足三陰從足走腹胸。
- 十二經脈表裡相配，依肺、大腸、胃、脾、心、小腸、膀胱、腎、心包、三焦、膽、肝的次序流注，如環無端。
- 奇經八脈調節十二經氣血；督脈為陽脈之海，任脈為陰脈之海，衝脈為血海，帶脈約束諸經。
- 經絡能溝通內外、運行氣血、抵禦外邪、反映病候、傳導感應；在解釋病理、診斷與治療上都有應用。
- 腧穴分經穴、奇穴、阿是穴；特定穴包括五輸、原、絡、背俞、募、八會、下合、八脈交會與交會穴；定位用骨度分寸、體表標誌與手指同身寸。
- 穴位按壓要輕柔、避開傷處與孕期禁按的穴位，不能取代就醫。

## 名詞

- **經絡**：經脈與絡脈的合稱，是運行氣血、聯絡臟腑與肢體官竅的通道。
- **穴位**：即腧穴，臟腑經絡之氣輸注於體表的部位，是疾病的反應點與施加刺激的部位。

## 與本 App 對照

學習書沒有專章談經絡：經絡不在模型的帳上（見［學習書 第三章］〈狀態：人體的帳本〉），App 只把穴位當成調養的參考。本章在 App 中對應的記錄：

- **穴位資料**：App 收錄了上表的三十一個常用穴位，位置依世界衛生組織西太平洋區的標準穴位定位，以專案自己的白話描述；每個穴位都有經脈、代號與注意事項，孕期應避免按壓的穴位都有標記。
- **證型的穴位建議**：每個證型附有少數穴位作為調養參考，例如［證型 EX1 風寒束表］配［穴位 風池］、［穴位 列缺］、［穴位 合谷］；［證型 SP1 脾氣虛］配［穴位 足三里］、［穴位 中脘］；［證型 LV1 肝氣鬱結］配［穴位 太衝］、［穴位 內關］、［穴位 膻中］；［證型 KD2 腎陽虛］配［穴位 關元］、［穴位 腎俞］、［穴位 湧泉］；［證型 HT2 心腎不交］配［穴位 神門］、［穴位 湧泉］、［穴位 太溪］；［證型 QB2 血瘀］配［穴位 血海］、［穴位 膈俞］、［穴位 三陰交］。這些建議的原則見［SOP §12.7］。
- **安全過濾**：使用者表示懷孕或可能懷孕時，標記為孕期避按的穴位會被移除，並說明原因，見［SOP §13.2］。

**模型的簡化**：App 不計算經氣的盛衰，也不做循經取穴的推理；每個證型的穴位是固定的清單，不依個人調整。App 只介紹穴位按壓，不涉及針刺與艾灸；自己找穴可能有偏差，不確定時應請專業人員示範。
