# 第十章　四診（下）：舌診與脈診

| 項目 | 內容 |
|---|---|
| **篇** | 第二篇　診斷與辨證 |
| **建議時數** | 14 小時（講授 8、練習 6） |
| **先修** | 第九章 |
| **對應學科** | 中醫診斷 |

舌診與脈診是中醫最有特色的兩種診法。舌在口中，卻能直接看到，舌色、舌形與舌苔的變化能相當客觀地反映氣血、寒熱與胃氣；脈在腕上，按之可得，脈象的位置、速率、形態與力量反映氣血的盛衰與邪氣的性質。本章先講舌診，再講脈診，最後講兩者如何合參。要提醒的是：舌診可以靠練習與正確的觀察條件學會，脈診則需要經過訓練的手指與大量的實際操作，書本只能提供原理與標準。

## 學習目標

1. 說明舌診的原理、觀察方法與注意事項，描述正常舌象。
2. 掌握舌色、舌形、舌態與舌下絡脈的主要變化及其意義。
3. 掌握苔色與苔質的主要變化及其意義，以及舌面分區與臟腑的對應。
4. 說明脈診的原理、寸口診法、寸關尺分候臟腑與診脈的方法。
5. 描述正常脈象，掌握常見病脈的特徵與主病，以及常見的相兼脈。
6. 說明舌脈合參的原則，以及自我觀察舌象與脈象的限度。

## 一、舌診概說

### （一）原理

舌與臟腑有密切的聯繫：心開竅於舌，舌又是脾胃的外候，舌苔由胃氣蒸化而成；許多經脈也直接或間接聯繫到舌。所以臟腑的虛實、氣血的盛衰、津液的盈虧、病邪的性質與深淺，都會在舌上表現出來。

### （二）觀察的方法與注意事項

1. **光線**：在充足的自然光下觀察，避開有顏色的燈光。
2. **時間**：以早晨起床後、尚未進食飲水、尚未刷舌時最為準確。
3. **姿勢**：自然地把舌伸出口外，舌面放平、舌尖略向下，不要用力，時間不要太長。
4. **順序**：先看舌尖，再看舌中、舌邊，最後看舌根；先看舌質，再看舌苔。
5. **避免干擾**：咖啡、茶、有顏色的糖果與某些藥物會把舌苔染色；剛喝過熱飲或冷飲、剛刮過舌，舌象也會改變。

### （三）正常舌象

正常的舌象是「淡紅舌、薄白苔」：舌體柔軟、活動自如、大小適中，顏色淡紅而潤澤；舌苔薄而色白，分布均勻，乾濕適中，透過舌苔可以隱約看見舌體。

## 二、望舌質

舌質又稱舌體，是舌的肌肉部分。觀察舌質主要看顏色、形態、動態與舌下絡脈。

### （一）舌色

| 舌色 | 特徵 | 意義 |
|---|---|---|
| 淡紅 | 淡紅潤澤 | 正常；也見於外感初起，病情輕淺 |
| 淡白 | 比正常淺淡，紅少白多 | 氣血兩虛或陽虛 |
| 紅 | 比正常深紅 | 熱證：苔黃者多屬實熱，少苔或無苔者多屬陰虛虛熱 |
| 絳 | 深紅色 | 熱入營血，或陰虛火旺之甚 |
| 紫 | 紫暗或青紫 | 血瘀；淡紫濕潤多屬寒凝，絳紫乾燥多屬熱極 |

### （二）舌形

- **老與嫩**：舌質紋理粗糙、堅斂蒼老，多屬實證；紋理細膩、浮胖嬌嫩，多屬虛證。
- **胖大**：舌體比正常胖大，多屬脾腎陽虛、水濕痰飲停聚。
- **齒痕**：舌邊有牙齒壓出的痕跡，常與胖大舌並見，多屬脾虛、濕盛。
- **瘦薄**：舌體瘦小而薄，多屬氣血兩虛或陰虛。
- **點刺**：舌面上突起的紅點或刺狀小點（芒刺），多屬熱盛。出現在舌尖多屬心火，出現在舌邊多屬肝膽有熱，出現在舌中多屬胃腸熱盛；外感風熱初起也可見舌尖紅點。
- **裂紋**：舌面上有各種形狀的裂溝，多屬陰血不足或熱盛傷津。舌中有裂紋，多屬胃陰不足；滿舌都有裂紋，多屬陰液耗損、精血虧虛。要注意，有些人生來就有裂紋而沒有不適，這不屬病態。
- **瘀斑瘀點**：舌上有青紫色的斑塊或小點，多屬血瘀。

### （三）舌態

舌體的動態異常，例如舌體強硬、痿軟無力、顫動、伸舌歪斜、短縮不能伸出，多見於危重的病證或中風，必須立即就醫。

### （四）舌下絡脈

把舌尖向上翹起、抵住上顎，可以看到舌下兩條靜脈，稱為舌下絡脈。正常時顏色淡紫，粗細適中，長度不超過從舌根到舌尖距離的大半。如果兩條絡脈粗大怒張、顏色紫暗，或周圍有許多細小的紫色分支，多屬血瘀。

## 三、望舌苔

舌苔是舌面上的一層苔狀物，由胃氣蒸化而成。觀察舌苔主要看顏色與質地。

### （一）苔色

| 苔色 | 意義 |
|---|---|
| 白苔 | 表證、寒證、濕證；薄白苔是正常舌苔，也見於表證初起；白厚膩苔多屬濕濁、痰飲 |
| 黃苔 | 熱證；淡黃熱輕，深黃熱重，焦黃熱極；黃膩苔多屬濕熱或痰熱 |
| 灰黑苔 | 多屬重症：灰黑而潤滑多屬陽虛寒盛，灰黑而乾燥多屬熱極傷陰，都需要就醫 |

### （二）苔質

1. **厚薄**：透過舌苔能隱約看見舌體的是薄苔，看不見舌體的是厚苔。薄苔多屬正常或病在表、病情輕；厚苔多屬邪氣入裡，或有食積、痰濕。舌苔由薄變厚，表示病進；由厚變薄，表示病退。
2. **潤燥**：苔面濕潤適中是正常；水分過多、伸舌時欲滴，稱為滑苔，多屬水濕內停；苔面乾燥、摸之無津，稱為**苔乾**，多屬熱盛傷津或陰液不足。
3. **膩與腐**：苔質顆粒細小緻密、像一層油膩的黏液、刮之不易去除的，是**膩苔**，多屬濕濁、痰飲、食積；苔質顆粒粗大疏鬆、像豆腐渣堆在舌面、刮之易去的，是腐苔，多屬食積、胃熱。
4. **剝落**：舌苔部分或全部脫落，脫落處光滑無苔，稱為**剝苔**，多屬胃氣不足、胃陰虧虛。舌苔全部脫落、舌面光滑如鏡，是胃陰枯竭、胃氣大傷的表現。

## 四、舌面分區

古人把舌面分成幾個區域，各與某些臟腑相對應，用來判斷病位。分區有兩種說法：

| 說法 | 舌尖 | 舌中 | 舌邊 | 舌根 |
|---|---|---|---|---|
| 《傷寒指掌》 | 心 | 胃（整個舌面也屬胃；舌的四周屬脾） | 肝膽 | 腎 |
| 現代教材 | 心肺 | 脾胃 | 肝膽 | 腎 |

兩種說法大同小異。臨床上常用的例子有：**舌尖**紅或有紅點，多屬心火；舌邊紅，多屬肝膽有熱；舌中有裂紋、苔少，多屬胃陰不足；舌中苔厚膩，多屬脾胃濕濁或食積；**舌根**苔厚膩，多屬下焦濕熱；舌根少苔或剝落，多屬腎陰不足。

分區只是參考，必須與全身的表現結合判斷。

## 五、脈診概說

### （一）原理

心主血脈，肺朝百脈，全身的血液都經過心肺而周流於脈中，所以脈搏的變化可以反映全身氣血與臟腑的狀態。

### （二）寸口診法

古代有幾種診脈的部位，其中最常用的是「寸口」，也就是手腕掌側、拇指一側橈動脈搏動的地方。《難經》提出「獨取寸口」：只在寸口診脈，就可以了解全身。寸口分為三部：以腕後高起的骨頭（橈骨莖突）內側為「關」，關之前（靠手掌的一側）為「寸」，關之後為「尺」。兩手各有寸、關、尺三部，共六部。

### （三）寸關尺分候臟腑

| | 寸 | 關 | 尺 |
|---|---|---|---|
| 左手 | 心 | 肝、膽 | 腎 |
| 右手 | 肺 | 脾、胃 | 腎（命門） |

這是明代李時珍《瀕湖脈學》的說法，也是今天最通行的分候。例如右關脈弱，提示脾胃虛弱；左關脈弦，提示肝氣不舒；兩尺脈弱，提示腎虛。

### （四）診脈的方法

1. **時間**：以清晨最好，因為這時人體尚未活動、飲食，氣血較為平靜；但臨床上隨時都可以診脈，只要讓病人先安靜休息片刻。
2. **體位**：病人坐正或仰臥，手臂平放，手腕與心臟大致同高，手掌向上。
3. **布指**：先以中指按在關部，再以食指按寸部、無名指按尺部；三指指端平齊。
4. **指力**：輕按稱為「舉」，重按稱為「按」，不輕不重稱為「尋」。三種指力都要用，以體會脈的深淺。
5. **平息**：醫者保持呼吸平穩，以自己的一呼一吸（一息）計算病人脈搏的次數；每次診脈要有足夠的時間，古人要求不少於五十次搏動。

### （五）脈象的要素

描述一個脈象，要從幾個方面體會：**位置**（浮或沉）、**速率**（遲或數）、**節律**（整齊或不整齊）、**寬度**（大或細）、**力量**（有力或無力）、**流利度**（滑或澀）、**緊張度**（弦、緊或緩）。每一種脈象，都是這些要素的某種組合。

## 六、正常脈象

正常的脈象稱為「平脈」，特點是：一息四至五至（大約相當於每分鐘六十至九十次左右），不浮不沉，不大不小，從容和緩，柔和有力，節律一致，尺脈沉取也應指有力。古人把這些特點概括為三點：**有胃**（從容和緩）、**有神**（柔和有力）、**有根**（尺脈沉取有力）。

平脈也會隨生理狀況而變化：小兒的脈較快，老人的脈較弱；胖人的脈較沉，瘦人的脈較浮；運動、飲食、情緒激動之後脈會變快；季節不同，脈象也略有不同，春季略弦，夏季略洪，秋季略浮，冬季略沉。

## 七、常見病脈

古人歸納的病脈有二十八種。下表列出最常用的十六種，其餘的種類在理解這十六種之後再學。

| 脈象 | 特徵 | 主病 |
|---|---|---|
| 浮脈 | 輕按即得，重按稍減而不空 | 表證；有力為表實，無力為表虛 |
| 沉脈 | 輕按不應，重按才能摸到 | 裡證；有力為裡實，無力為裡虛 |
| 遲脈 | 一息不足四至，脈來緩慢 | 寒證；有力為寒積，無力為虛寒 |
| 數脈 | 一息五至以上，脈來急速 | 熱證；有力為實熱，無力為虛熱 |
| 滑脈 | 往來流利，如珠走盤 | 痰飲、食積、實熱；健康的孕婦也可見 |
| 澀脈 | 往來艱澀不暢，如輕刀刮竹 | 血瘀、氣滯、精血虧少 |
| 弦脈 | 端直而長，如按琴弦 | 肝膽病、疼痛、痰飲 |
| 細脈 | 脈細如線，但應指明顯 | 氣血兩虛、諸虛勞損，也主濕 |
| 洪脈 | 脈體寬大，來盛去衰，如波濤洶湧 | 熱盛 |
| 緊脈 | 繃急彈指，如轉繩索 | 寒證、疼痛、宿食 |
| 緩脈 | 一息四至，來去和緩 | 濕證、脾虛；從容和緩者也是平脈 |
| 濡脈 | 浮而細軟，如棉絮浮在水面 | 虛證、濕證 |
| 弱脈 | 沉而細軟無力 | 陽虛、氣血俱虛 |
| 結脈 | 脈來緩慢，時有一止，止無定數 | 陰盛氣結、寒痰瘀血 |
| 代脈 | 脈來時有一止，止有定數，良久方還 | 臟氣衰微 |
| 促脈 | 脈來急數，時有一止，止無定數 | 陽盛熱結，或氣血痰食停滯 |

其餘十二種是：虛脈（舉按無力）、實脈（舉按皆有力）、長脈、短脈、微脈（極細極軟，若有若無）、芤脈（浮大中空，如按蔥管）、革脈、牢脈、散脈、伏脈、動脈與疾脈（一息七八至）。

**相兼脈**：臨床上的脈象常是兩種以上的組合，例如：浮緊（外感風寒的表實證）、浮緩（太陽中風的表虛證）、浮數（外感風熱）、沉遲（裡寒）、弦數（肝火）、滑數（痰熱或濕熱）、細數（陰虛內熱）、細弱（氣血兩虛）、沉細而尺部尤弱（腎陽虛）。

**要特別注意**：結脈、代脈、促脈都是節律不整齊的脈，可能與心律不整有關；脈搏極快、極慢或忽有忽無，都必須就醫檢查。

## 八、舌脈合參

舌象與脈象各有所長：舌象比較直觀穩定，脈象比較敏感而變化快。兩者一致時，判斷較為可靠，例如舌紅苔黃、脈數有力，都指向實熱。兩者不一致時，要仔細分辨：有時症狀是真、脈象是假，有時脈象是真、症狀是假，古人稱為「舍脈從症」與「舍症從脈」。這需要豐富的臨床經驗，初學者遇到這種情況，應該把它當成「需要更多資料」的訊號，而不是勉強下結論。

還要記住：自己觀察舌象需要正確的光線與時間，結果仍然可能有偏差；自己摸脈更難，沒有受過訓練的人往往連浮沉、遲數都分不準。所以在自我觀察時，舌象與脈象都只能作為參考。

## 古籍原文選讀

> 「滿舌屬胃。中心亦屬胃。舌尖屬心。舌根屬腎。兩旁屬肝膽。四畔屬脾。」——《傷寒指掌·察舌》

**白話**：整個舌面都屬胃，舌的中心也屬胃；舌尖屬心，舌根屬腎，舌的兩邊屬肝膽，舌的四周邊緣屬脾。這是清代《傷寒指掌》的舌面分區，與現代教材的分區大同小異。舌苔由胃氣所生，所以整個舌面都能反映胃氣。

> 「診法常以平旦」——《素問·脈要精微論》

**白話**：診察通常在清晨進行。原文接著說明原因：清晨人體還沒有活動，沒有進食，氣血還沒有擾動，這時診察最能反映真實的狀態。看舌、診脈都以清晨為佳，道理在此。

> 「人一呼脈再動，一吸脈亦再動，呼吸定息，脈五動，閏以太息，命曰平人」——《素問·平人氣象論》

**白話**：健康的人，呼氣一次脈搏跳兩下，吸氣一次脈搏也跳兩下，一呼一吸之間的停頓再跳一下，共五次；偶爾一次較深長的呼吸時多跳一下，這就是健康人的脈率。古人以醫者自己的呼吸為計時單位，「一息四至五至」的標準就從這裡來。

> 「心肝居左肺脾居右腎與命門居兩尺部」——《瀕湖脈學·四言舉要》

**白話**：心與肝的脈在左手，肺與脾的脈在右手，腎與命門的脈在兩手的尺部。這是李時珍以四字歌訣寫成的寸口分候：左寸心、左關肝、右寸肺、右關脾、兩尺腎與命門。它是今天最通行的寸關尺分候法。

> 「善診者，察色按脈，先別陰陽」——《素問·陰陽應象大論》

**白話**：善於診病的醫者，在察看面色、按切脈搏時，首先分辨陰陽。舌脈的每一種變化，最終都要歸到陰陽、寒熱、虛實的判斷上：舌紅脈數屬陽屬熱，舌淡脈遲屬陰屬寒。這是舌脈合參的總方向。

## 本章小結

- 舌與臟腑經絡相通，舌象能反映氣血、寒熱、津液與胃氣；觀察要在自然光下、晨起未進食時進行，注意染苔等干擾。正常舌象是淡紅舌、薄白苔。
- 舌色：淡白主虛寒或氣血虛，紅主熱，絳主熱入營血或陰虛火旺，紫主瘀。舌形：胖大齒痕主脾虛濕盛，瘦薄主虛，點刺主熱，裂紋主陰血不足，瘀斑主瘀。舌態異常多屬危重。舌下絡脈怒張紫暗主瘀。
- 苔色：白主表、寒、濕，黃主熱，灰黑多屬重症。苔質：厚薄看邪氣深淺，潤燥看津液，膩腐看濕濁食積，剝落看胃氣胃陰。
- 舌面分區：舌尖心（肺），舌中脾胃，舌邊肝膽，舌根腎。
- 脈診獨取寸口，分寸關尺；左寸心、左關肝膽、左尺腎，右寸肺、右關脾胃、右尺腎（命門）。
- 平脈有胃、有神、有根；常見病脈十六種要熟記特徵與主病；結、代、促等節律不整的脈要就醫檢查。
- 舌脈合參；兩者矛盾時需要更多資料；自我觀察的舌脈只能作參考。

## 名詞

- **舌象**：舌質與舌苔所呈現的整體表現，是望診的重要內容。
- **舌質**：舌的肌肉部分，觀察其顏色、形態與動態。
- **舌苔**：舌面上由胃氣蒸化而成的苔狀物，觀察其顏色與質地。
- **齒痕**：舌邊被牙齒壓出的痕跡，多屬脾虛、濕盛。
- **裂紋**：舌面上的裂溝，多屬陰血不足或熱盛傷津；先天裂紋不屬病態。
- **芒刺**：舌面上突起的紅色刺狀小點，多屬熱盛。
- **瘀斑**：舌上青紫色的斑塊或斑點，多屬血瘀。
- **舌下絡脈**：舌下兩條靜脈；粗大怒張、紫暗者多屬血瘀。
- **舌尖**：舌的前端，多對應心（與肺）；舌尖紅多屬心火。
- **舌根**：舌的後部，多對應腎；舌根少苔多屬腎陰不足，苔厚膩多屬下焦濕熱。
- **薄白苔**：薄而色白、均勻的舌苔，是正常舌苔，也見於表證初起。
- **膩苔**：顆粒細膩緻密、刮之不易去除的舌苔，多屬濕濁、痰飲、食積。
- **剝苔**：舌苔部分或全部脫落的舌象，多屬胃氣不足、胃陰虧虛。
- **苔乾**：舌苔乾燥、摸之無津，多屬熱盛傷津或陰液不足。
- **脈象**：手指感覺到的脈搏形象，包括位置、速率、節律、寬度、力量與流利度。
- **寸關尺**：寸口脈的三部，以腕後高骨內側為關，關前為寸，關後為尺。
- **浮脈**：輕按即得、重按稍減的脈，主表證。
- **沉脈**：輕按不應、重按始得的脈，主裡證。
- **遲脈**：一息不足四至的脈，主寒證。
- **數脈**：一息五至以上的脈，主熱證。
- **滑脈**：往來流利、如珠走盤的脈，主痰飲、食積、實熱，也見於孕婦。
- **澀脈**：往來艱澀、如輕刀刮竹的脈，主血瘀、氣滯、精血虧少。
- **弦脈**：端直而長、如按琴弦的脈，主肝膽病、疼痛、痰飲。
- **細脈**：脈細如線而應指明顯，主氣血兩虛、諸虛勞損。
- **洪脈**：脈體寬大、來盛去衰的脈，主熱盛。
- **緊脈**：繃急彈指、如轉繩索的脈，主寒、痛、宿食。
- **緩脈**：一息四至、來去和緩的脈，主濕與脾虛，和緩有力者也是平脈。
- **濡脈**：浮而細軟的脈，主虛與濕。
- **弱脈**：沉而細軟無力的脈，主陽虛、氣血俱虛。
- **結脈**：緩而時有一止、止無定數的脈，主陰盛氣結、寒痰瘀血。
- **代脈**：時有一止、止有定數、良久方還的脈，主臟氣衰微。
- **促脈**：數而時有一止、止無定數的脈，主陽盛熱結或氣血痰食停滯。

## 與本 App 對照

- **舌診**：App 依《傷寒指掌》分區，教材的分區並列；收錄的舌象特徵包括舌淡、舌淡胖、舌紅、舌絳、舌紫暗、胖大、瘦薄、質嫩、舌邊齒痕、舌中裂紋、滿舌裂紋、舌尖紅點或芒刺、舌邊紅點、舌中芒刺、瘀斑瘀點與舌下絡脈怒張，見［SOP §4.4］。App 會請使用者在早晨、未進食、未刮舌時，在自然光下觀察，見［學習書 第六章］。
- **脈診是可選的**：App 收錄了二十八種脈象與寸關尺的分候，但脈象只有在使用者能自行分辨時才填，不確定就留空；自述的脈象以較低的可信度進入計算，見［SOP §4.6］。
- **證型的舌脈**：每個證型都附有典型的舌脈，例如［證型 EX1 風寒束表］苔薄白、脈浮緊；［證型 EX3 風熱犯表］舌邊尖紅、苔薄黃、脈浮數；［證型 SP1 脾氣虛］舌淡胖有齒痕、脈緩弱；［證型 SP4 痰濕內阻］苔白膩、脈滑；［證型 SP5 濕熱蘊結］苔黃膩、脈滑數；［證型 SP6 胃陰虛］舌中裂紋、少苔；［證型 KD1 腎陰虛］舌根少苔或剝落；［證型 HT2 心腎不交］舌尖紅；［證型 LV2 肝火上炎］舌邊紅、脈弦數；［證型 QB2 血瘀］舌紫暗、有瘀斑瘀點、舌下絡脈怒張、脈澀。
- **照片觀察（只在開發版本中）**：開發版本可以讓使用者拍攝舌與面部的照片，由 AI 提出觀察建議，再由使用者逐一確認；這是一種引導式的自我觀察。照片只在使用者按下送出時傳送一次，不附任何中繼資料，也不會被保存。公開版本沒有這個功能。

**模型的簡化**：App 看不到舌、摸不到脈，只能讀使用者自己觀察的結果：舌象以七折、脈象以五折計算可信度。舌態的異常（強硬、歪斜、顫動）不在證型的計算中，相關的危險表現由紅旗篩檢處理。舌脈矛盾時，App 不做「舍脈從症」或「舍症從脈」的取捨，而是把所有證據依權重加總，並在證據互相矛盾時降低信心。

## 練習

1. （選擇）舌淡胖、邊有齒痕，多提示：（A）實熱（B）脾虛濕盛（C）陰虛（D）血瘀。
2. （選擇）依《瀕湖脈學》，右手關部候：（A）心（B）肝膽（C）脾胃（D）肺。
3. （簡答）觀察舌象時要注意哪些條件？為什麼早晨未進食時最準確？
4. （簡答）比較膩苔與腐苔、薄苔與厚苔的特徵與意義。
5. （簡答）描述平脈的特點，並說明「有胃、有神、有根」的意思。
6. （簡答）寫出浮、沉、遲、數、滑、澀、弦、細八種脈的特徵與主病。
7. （案例）某人舌紅，舌中有裂紋，舌苔少而乾，舌根苔剝落，脈細數。依舌脈分析其病性與可能涉及的臟腑。
