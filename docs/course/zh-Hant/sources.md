# 本書依據的資料

本書是自足的教科書：學習者**不必閱讀這裡列出的任何一部書**。這一頁說明本書的講解從哪裡來，供教師、審閱者與想要延伸學習的人查證。

## 一、現代教材與規範

本書的定義、分類、證型描述與教學次序，以現代中醫院校的規劃教材為準：

- 《全國中醫藥行業高等教育規劃教材（中醫基礎理論、中醫診斷學、中藥學、方劑學、中醫內科學）》：第一至十八章的主要依據。
- 《中華人民共和國藥典》（2025年版）一部：藥材的性味、歸經、功能與注意事項。
- 《中藥學》（教材）：藥典未收品種的性味與功能。
- 《中華本草》《中藥大辭典》：本草的補充查證。
- 《中醫體質分類與判定》：第十九章的九種體質。
- 世界衛生組織西太平洋區的標準穴位定位（2008）與傳統醫學術語標準（2007）：第七章的穴位定位與全書術語的英文對照。

## 三、本專案的資料

- **已核對的古籍引文**（`data/citations.json`）：本書引文框中的每一段原文，都是其中一段核對過的引文或它的一部分。
- **知識庫**（`data/`）：證型、證素、體質、方劑、本草、穴位與食物的記錄；本書以［類別 名稱］標出的名稱都與它一致。
- **學習書**《以模型讀中醫》：說明 App 如何把傳統的推理寫成規則，共十二章。
- **辨證 SOP**（`docs/diagnosis-sop.zh-TW.md`）：App 的辨證流程與規則。

## 四、引文如何核對

1. 每一段引文都先在專案收錄的原典文本中逐字找到，記下書名與篇章，才收入引文登錄。
2. 本書引用時，引文框中的文字必須是登錄中某段引文的一部分，書名必須相同，篇章必須在該段引文的篇章之內；這一點由自動測試逐條檢查。
3. 書中點名的每一部書都必須在來源登錄中；點名到篇章的，該篇章必須在參考語料庫裡找得到。
4. 古籍的版本不同，文字偶有出入；本書以專案收錄的版本為準。

## 五、讀完本書之後

本書讀完，已足以理解中醫的基本理論、診斷、治法、本草與方劑。若想更進一步，可以：

- 依第二十一章的導覽，挑選感興趣的典籍，配合注本慢慢讀；
- 回到現代教材的進階內容，例如中醫內科學、方劑學的各論；
- 在 App 的學習區對照各證型、方劑與本草的記錄，並閱讀學習書《以模型讀中醫》。

這些都是延伸，不是本課程的要求。若有臨床上的需要，應尋求執業中醫師的協助。
