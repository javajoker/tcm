# 第十六章　中藥學（下）：常用藥物的分類

| 項目 | 內容 |
|---|---|
| **篇** | 第三篇　治則、本草與方劑 |
| **建議時數** | 16 小時（講授 10、練習 6） |
| **先修** | 第十五章 |
| **對應學科** | 中藥學 |

上一章講藥性理論，這一章依功效分類介紹常用的藥物。現代教材與藥典把中藥分為二十多類，例如解表藥、清熱藥、補虛藥。同一類的藥物有共同的性能與適用範圍，也有共同的使用注意；類中再依作用的側重分小類。學習的方法是：先掌握每一類的**共同性能、適用與注意**，再記住每一類中幾味代表藥的**性味與主要功效**，最後比較同類藥物之間的差別。

本章的表格只列性味、歸經與主要功效，不列份量。每一味藥都有它的適用範圍與禁忌，是否使用、如何使用，必須由執業中醫師決定。

## 學習目標

1. 說出中藥依功效分類的主要類別，以及每一類的共同性能、適用範圍與使用注意。
2. 記住各類代表藥的性味與主要功效。
3. 比較同類藥物的異同，例如麻黃與桂枝、黃芩與黃連、人參與黨參、地黃與熟地黃。
4. 說明補虛藥分為補氣、補陽、補血、補陰四類的道理，以及補藥的使用注意。
5. 了解古人關於「份量改變作用方向」的觀察，並說明本書不談份量的理由。
6. 認識藥食同源的概念及其限度。

## 一、解表藥

**共同性能**：多味辛、質輕，主入肺與膀胱經，能發散表邪，使病邪從汗而解。**適用**：表證。**注意**：汗出邪去即止，不可過汗；表虛自汗、陰虛盜汗、失血、津傷的人慎用。

## 十九、其他幾類

- **湧吐藥**：能引起嘔吐，例如［本草 常山］、［本草 瓜蒂］，都有毒，今天已很少使用。
- **攻毒殺蟲止癢藥**：多外用，例如［本草 硫黃］、［本草 雄黃］，都有毒。
- **拔毒化腐生肌藥**：多外用於瘡瘍，例如［本草 爐甘石］。

這幾類多有毒性或只能外用，只能由醫師使用。

## 二十、藥食同源

有些物品既是食物也是藥材，稱為「藥食同源」，例如山藥、茯苓、蓮子、薏苡仁、枸杞子、龍眼肉、大棗、生薑、百合、山楂。方劑中也有一些純粹的食物，例如［本草 粳米］、［本草 冰糖］、［本草 雞子黃］。藥食同源的物品作用較平和，適合作為日常的飲食調養（第十九章）；但它們仍有性味的偏向，例如生薑偏溫、百合偏涼，不對證的長期大量食用也會造成偏頗。

## 二十一、份量與作用的方向

古代醫家觀察到，同一味藥，份量不同，作用的方向甚至會改變。下面幾段原文都是這類觀察（見古籍原文選讀）：葛根少用則上浮外散，多用則沉降；人參少用則上行，多用則下沉；蘇木少用和血，多用破血；升麻多用則散，少用則升；紅花少用活血，多用破血。

這些觀察說明了兩件事：一是份量本身就是治療的一部分，不能隨意增減；二是份量的決定需要專業的判斷。這正是本書只講道理、不談份量的原因：份量必須由醫師依病情、體質、配伍與製法親自決定。

## 古籍原文選讀

> 「葛根輕浮，少用則浮而外散，多用則沉而內降矣」——《本草新編·葛根》

**白話**：葛根質地輕浮，用得少時，藥性上浮而向外發散；用得多時，藥性反而下沉而向內下降。清代陳士鐸的這個觀察說明，升降浮沉不只取決於藥物本身，也與份量有關。

> 「人參氣味陽多於陰，少用則泛上，多用則沉下」——《本草新編·人參》

**白話**：人參的氣味中陽多於陰，用得少時藥力向上浮泛，用得多時藥力向下沉降。同一味藥，份量不同，作用的部位也不同。

> 「少用則和血，多用則破血」——《本經逢原·蘇方木》

**白話**：蘇木用得少，能調和血脈；用得多，就能破血逐瘀。「和血」與「破血」是程度很不同的兩種作用，後者對身體的衝擊大得多。

> 「多用則散，少用則升，蜜炙使不驟升」——《得配本草·升麻》

**白話**：升麻用得多，偏於發散；用得少，偏於升舉陽氣；用蜜炙過，可以使它不要升得太猛。這說明份量與炮製都會影響作用的方向與強弱。

> 「酒灑焙，少用通經活血，多用破血，去瘀血」——《外科全生集·諸藥法制及藥性·紅花》

**白話**：紅花用酒灑後烘焙，用得少能通經活血，用得多則能破血、去除瘀血。與蘇木的觀察相似：活血藥的份量，決定了它是「調和」還是「攻破」。

- 中藥依功效分為解表、清熱、瀉下、祛風濕、化濕、利水滲濕、溫裡、理氣、消食、驅蟲、止血、活血化瘀、化痰止咳平喘、安神、平肝息風、開竅、補虛、收澀、湧吐、攻毒殺蟲止癢、拔毒化腐生肌等類。

- 補虛藥分補氣、補陽、補血、補陰，對應氣虛、陽虛、血虛、陰虛；實邪未清不宜早補，要防虛不受補。
