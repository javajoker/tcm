# 第十一章　八綱辨證

| 項目 | 內容 |
|---|---|
| **篇** | 第二篇　診斷與辨證 |
| **建議時數** | 10 小時（講授 6、練習 4） |
| **先修** | 第九、十章 |
| **對應學科** | 中醫診斷 |

四診收集了材料，接下來要把材料整理成判斷。八綱是最基本的整理框架：表與裡說明病位的深淺，寒與熱說明病的性質，虛與實說明邪正的盛衰，陰與陽則是統攝前三對的總綱。任何一個病證，都可以先用這八個字定出大方向，然後再用臟腑、六經、衛氣營血等方法細分。本章依次講表裡、寒熱、虛實、陰陽，以及它們之間的錯雜、轉化與真假。

## 學習目標

1. 說明八綱的含義，以及八綱在各種辨證方法中的地位。
2. 掌握表證、裡證與半表半裡證的特徵與鑑別。
3. 掌握寒證與熱證的鑑別，以及寒熱錯雜、轉化與真假。
4. 掌握虛證與實證的鑑別，以及虛實夾雜、轉化與真假。
5. 說明陰證與陽證的劃分，以及亡陰與亡陽的危急表現。
6. 能用八綱分析簡單的病例，並說明病位、病性與證素的關係。

## 一、八綱概說

八綱是表、裡、寒、熱、虛、實、陰、陽八個綱領。清代程國彭在《醫學心悟》中把它概括為「八字」，成為今天八綱辨證的直接來源。

| 綱領 | 回答的問題 |
|---|---|
| 表裡 | 病在哪裡？病位是淺還是深？ |
| 寒熱 | 病是什麼性質？ |
| 虛實 | 邪氣與正氣誰強誰弱？ |
| 陰陽 | 總體上屬陰還是屬陽？ |

八綱回答的是兩個最基本的問題：**病位**（在表在裡、在哪一臟腑）與**病性**（寒熱、虛實，以及更具體的氣滯、痰濕、血瘀等）。病位與病性結合，就是一個「證」的骨架。

## 二、表裡

### （一）表證

表證是外邪從皮毛、口鼻侵入，正氣抵抗於肌表所表現的證候，多見於外感病的初期。特點是起病急、病位淺、病程短。

**主要表現**：新起的惡寒（或惡風）與發熱同時出現，頭痛、身體痠痛，鼻塞、流涕、噴嚏，咽喉癢痛，咳嗽，舌苔薄白，脈浮。其中「惡寒發熱並見」與「脈浮」最有代表性。

**類型**：依病性分為表寒（風寒）與表熱（風熱）；依有無汗出分為表實（無汗）與表虛（有汗）。

### （二）裡證

裡證是病位在臟腑、氣血、骨髓等深部的證候。它的來源有三：表邪不解而入裡，外邪直接侵犯臟腑，以及情志、飲食、勞倦等內傷。裡證的範圍很廣，凡不是表證（也不是半表半裡）的，都屬裡證。

**主要表現**：沒有新起的惡寒發熱並見，以臟腑的症狀為主，例如咳喘、心悸、腹痛、嘔吐、腹瀉、便秘；舌苔變化較大，脈多沉。

### （三）半表半裡證

外邪由表入裡的過程中，停留在表與裡之間，稱為半表半裡證，主要指《傷寒論》的少陽病。

**主要表現**：怕冷與發熱交替出現（往來寒熱），胸脅脹滿不舒，口苦，咽乾，頭暈目眩，不想吃東西，心煩想嘔，脈弦。

### （四）表裡的鑑別

| 要點 | 表證 | 裡證 | 半表半裡證 |
|---|---|---|---|
| 寒熱 | 惡寒發熱並見 | 但寒不熱或但熱不寒 | 寒熱往來 |
| 主要症狀 | 頭身痛、鼻塞、咽癢 | 臟腑症狀為主 | 胸脅苦滿、口苦、咽乾、目眩 |
| 舌苔 | 變化不大，多薄白 | 多有變化 | 多薄白或薄黃 |
| 脈 | 浮 | 沉 | 弦 |

### （五）表裡的關係

表證與裡證可以同時存在，稱為表裡同病，例如本有脾虛便溏的人又感受風寒。表邪不解可以入裡，例如風寒感冒幾天後轉為高熱、咳黃痰；裡邪也可以透出於表，例如麻疹透發，一般表示病勢向好。

## 三、寒熱

### （一）寒證與熱證

**寒證**是感受寒邪，或陽虛陰盛所表現的證候。主要表現：怕冷喜暖，面色白，手足冷，喜歡蜷縮而臥，口淡不渴，痰、涕、涎清稀，小便清長，大便溏薄，舌淡苔白而潤，脈遲或緊。

**熱證**是感受熱邪，或陽盛、陰虛所表現的證候。主要表現：發熱喜涼，面紅目赤，口渴喜冷飲，煩躁不安，痰、涕黃稠，小便短黃，大便乾結，舌紅苔黃而乾，脈數。

### （二）寒熱的鑑別

| 要點 | 寒證 | 熱證 |
|---|---|---|
| 寒熱喜惡 | 怕冷喜暖 | 怕熱喜涼 |
| 口渴 | 不渴，或喜熱飲 | 口渴喜冷飲 |
| 面色 | 白 | 紅 |
| 四肢 | 冷 | 熱 |
| 分泌物 | 清稀 | 黃稠 |
| 二便 | 小便清長、大便溏 | 小便短黃、大便乾結 |
| 舌 | 舌淡、苔白潤 | 舌紅、苔黃乾 |
| 脈 | 遲或緊 | 數 |

寒證與熱證都要再分虛實：實寒散寒，虛寒溫陽；實熱清熱，虛熱滋陰（見第三章）。

### （三）寒熱錯雜

寒與熱同時存在於不同的部位，稱為寒熱錯雜：

- **上熱下寒**：例如胸中煩熱、咽痛口乾，同時腹部冷痛、喜溫、大便溏。
- **上寒下熱**：例如胃脘冷痛、嘔吐清水，同時小便短黃、灼痛。
- **表寒裡熱**：例如本有內熱，又感受風寒，既惡寒無汗、身痛，又煩躁口渴、舌紅，俗稱「寒包火」。
- **表熱裡寒**：例如本有脾胃虛寒，又感受風熱。

### （四）寒熱轉化

在一定條件下，寒證可以轉為熱證，熱證也可以轉為寒證。例如風寒感冒未及時處理，寒邪入裡化熱，轉為咽痛、咳黃痰；又如高熱大汗不止，陽氣隨汗外脫，突然轉為四肢冰冷、面色蒼白、脈微的寒證——這是危急的情況。

### （五）寒熱真假

病情危重時，有時會出現與本質相反的假象：

- **真熱假寒**：內熱極盛，陽氣被鬱遏在內，不能通達四肢，反而出現四肢冰冷、脈沉等「寒象」。但仔細檢查，胸腹灼熱，口渴喜冷飲，煩躁，小便短黃，舌紅苔黃而乾，脈雖沉但有力。《傷寒論》說「厥深者熱亦深」：手足越冷，內熱反而可能越重。
- **真寒假熱**：陰寒極盛於內，虛陽被逼浮越於外，反而出現身熱、面紅、口渴、脈大等「熱象」。但仔細檢查，身熱卻想加衣蓋被，面紅只見於兩顴、浮淺如妝，口渴卻不想喝或只想喝熱水，脈大而按之無力，舌淡苔白。

辨別真假的要點是：**看本質不看表面**——熱與寒以胸腹的冷熱為準，不以四肢為準；口渴以喜冷喜熱、喝多喝少為準；脈以按之有力無力為準；舌象較少出現假象，是重要的依據。真假寒熱都是危重的病情，必須立即就醫。

## 四、虛實

### （一）虛證

虛證是正氣不足所表現的證候，多見於久病、體弱、老年人，或大病、失血之後。依不足的物質不同，主要有四類：

| 類型 | 主要表現 | 舌脈 |
|---|---|---|
| 氣虛 | 神疲乏力、少氣懶言、自汗、動則加重 | 舌淡，脈虛無力 |
| 血虛 | 面色淡白或萎黃、唇甲色淡、頭暈眼花、心悸失眠 | 舌淡，脈細 |
| 陰虛 | 五心煩熱、潮熱盜汗、口燥咽乾、形體消瘦 | 舌紅少苔，脈細數 |
| 陽虛 | 畏寒肢冷、面色淡白、小便清長、精神萎靡 | 舌淡胖，脈沉遲無力 |

### （二）實證

實證是邪氣亢盛，或痰、瘀、水、食等病理產物停聚所表現的證候，多見於疾病的初期、中期，體質尚強者。主要表現因邪氣不同而異，常見的有：發熱，腹脹痛而拒按，胸悶煩躁，痰涎壅盛，大便秘結或下利不爽，小便不利，舌質蒼老、苔厚膩，脈實有力。

### （三）虛實的鑑別

| 要點 | 虛證 | 實證 |
|---|---|---|
| 病程 | 多久病 | 多新病 |
| 體質 | 多虛弱 | 多壯實 |
| 精神 | 萎靡 | 亢奮或煩躁 |
| 聲息 | 聲低息微 | 聲高氣粗 |
| 疼痛 | 隱痛、喜按 | 劇痛、拒按 |
| 脹滿 | 時輕時重、時減 | 持續不減 |
| 舌 | 舌質嫩 | 舌質老 |
| 脈 | 無力 | 有力 |

### （四）虛實的關係

- **虛實夾雜**：虛與實同時存在。例如脾虛不能運化水濕而生痰濕，既有乏力、便溏的虛象，又有痰多、苔膩的實象，稱為「本虛標實」。臨床上的慢性病多屬這種情況。
- **虛實轉化**：實證久病，正氣漸傷，可轉為虛證；虛證因臟腑功能減退而產生痰、瘀、水濕，又可兼見實證。
- **虛實真假**：古人觀察到，邪實到了極點，有時反而出現類似虛弱的表現；正虛到了極點，有時反而出現類似邪實的表現。辨別的要點同樣是看本質：脈的有力無力、舌質的老嫩、疼痛的喜按拒按。

## 五、陰陽

### （一）陰證與陽證

陰陽是八綱的總綱，可以統攝其他六綱：表、熱、實屬陽，裡、寒、虛屬陰。

| | 陽證 | 陰證 |
|---|---|---|
| 範圍 | 表證、熱證、實證 | 裡證、寒證、虛證 |
| 精神 | 興奮、煩躁 | 萎靡、倦怠 |
| 面色 | 紅 | 淡白或晦暗 |
| 寒熱 | 發熱、喜涼 | 怕冷、喜暖 |
| 口渴 | 口渴喜冷飲 | 不渴或喜熱飲 |
| 二便 | 大便乾、小便短黃 | 大便溏、小便清長 |
| 舌 | 舌紅苔黃 | 舌淡苔白 |
| 脈 | 浮、數、洪、滑、有力 | 沉、遲、細、澀、無力 |

要注意，陰陽的劃分是相對的：例如陰虛證屬虛，卻有熱象；臨床上要具體分析，不能只套用表格。

### （二）亡陰與亡陽

亡陰與亡陽是陰液或陽氣突然大量耗失的危重證候，常見於高熱、大汗、大吐大瀉、大出血之後：

- **亡陰**：汗出熱而黏，身熱，口渴想喝，煩躁不安，皮膚乾皺，舌紅乾，脈細數而急。
- **亡陽**：冷汗淋漓，四肢冰冷，面色蒼白，精神萎靡，呼吸微弱，舌淡，脈微弱欲絕。

兩者都必須立即就醫急救。

## 六、八綱的綜合運用

### （一）辨證的步驟

1. **先定表裡**：有沒有新起的惡寒發熱並見？脈浮還是沉？
2. **再辨寒熱**：怕冷還是怕熱？口渴與否？分泌物清稀還是黃稠？舌色與脈的速率如何？
3. **再辨虛實**：病程長短？喜按還是拒按？脈有力還是無力？
4. **最後歸納陰陽**：總體屬陰還是屬陽？
5. **注意錯雜、轉化與真假**：資料互相矛盾時，不要勉強平均，而要找出主次與真假。

### （二）一個例子

某人畏寒、手足冷、腹痛喜溫喜按、大便溏稀、口淡不渴，舌淡胖苔白滑，脈沉遲無力。分析：沒有新起的惡寒發熱並見，脈沉，屬**裡**；畏寒喜溫、口不渴、便溏、舌淡苔白、脈遲，屬**寒**；喜按、脈無力、舌胖淡，屬**虛**；裡、寒、虛都屬**陰**。歸納為「裡虛寒證」。再結合腹痛、便溏這些脾胃的症狀，就可以進一步定位到脾，成為「脾陽虛」——這就是下一章臟腑辨證要做的事。

### （三）病位、病性與證素

從這個例子可以看出，一個證可以拆成兩部分：**病位**（脾）與**病性**（陽虛、寒）。現代中醫診斷學把這種最小的辨證單位稱為「證素」：病位證素如表、心、肺、脾、肝、腎、胃、膽，病性證素如寒、熱、氣虛、血虛、陰虛、陽虛、氣滯、血瘀、痰、濕。不同的證素組合，就構成千變萬化的證。

## 古籍原文選讀

> 「病有總要，寒、熱、虛、實、表、裡、陰、陽，八字而已」——《醫學心悟·寒熱虛實表裡陰陽辨》

**白話**：疾病雖然千變萬化，總的要領不過是寒、熱、虛、實、表、裡、陰、陽這八個字。清代程國彭用這句話把辨證的綱領簡化到極致，這就是今天「八綱」的直接來源。

> 「邪氣盛則實，精氣奪則虛」——《素問·通評虛實論》

**白話**：邪氣亢盛就是實，正氣被耗奪就是虛。這是虛實最根本的定義：實是對邪氣而言，虛是對正氣而言。所以同一個人可以既虛又實——正氣不足，同時邪氣停留。

> 「按之不痛為虛，痛者為實」——《金匱要略·腹滿寒疝宿食病脈證治》

**白話**：腹部脹滿，按壓時不痛的屬虛，按壓時疼痛的屬實。這是張仲景辨別虛實最簡單實用的方法：虛證喜按，實證拒按。

> 「腹滿時減，復如故，此為寒」——《金匱要略·腹滿寒疝宿食病脈證治》

**白話**：腹部脹滿，有時減輕，過一陣又回到原來的樣子，這屬於虛寒。實證的脹滿持續不減；虛寒的脹滿時輕時重，因為脾陽不足、運化時好時壞。這一句與上一句合讀，是腹部虛實寒熱的鑑別要點。

> 「發熱惡寒者，發於陽也」——《傷寒論·辨太陽病脈證並治上》

**白話**：發熱與怕冷同時出現的，病發於陽。原文接著說，不發熱而只怕冷的，病發於陰。正氣能與邪氣相爭而發熱，屬陽；正氣不足、不能發熱而只怕冷，屬陰。這是用寒熱的表現分辨陰陽的經典說法。

> 「傷寒脈滑而厥者，裡有熱也，白虎湯主之」——《傷寒論·辨厥陰病脈證並治》

**白話**：外感病中，脈滑而手足冰冷的，是體內有熱，以白虎湯治療。手足冰冷看似寒證，但脈滑有力，說明內熱熾盛、陽氣被鬱而不能達於四肢——這正是「真熱假寒」的例子。治療要清內熱，而不是溫陽。

> 「陽虛則外寒，陰虛則內熱」——《素問·調經論》

**白話**：陽氣不足就外現寒象，陰液不足就內生虛熱。這句話提醒我們：寒熱要再分虛實。看到寒象，要問是寒邪太盛還是陽氣不足；看到熱象，要問是熱邪太盛還是陰液不足。八綱的四對綱領，必須合起來用。

## 本章小結

- 八綱是表、裡、寒、熱、虛、實、陰、陽，回答病位、病性與邪正盛衰的問題，是各種辨證方法的基礎。
- 表證惡寒發熱並見、脈浮；裡證以臟腑症狀為主、脈沉；半表半裡證寒熱往來、胸脅苦滿、口苦咽乾目眩、脈弦。
- 寒證怕冷喜暖、分泌物清稀、舌淡苔白、脈遲；熱證發熱喜涼、口渴、分泌物黃稠、舌紅苔黃、脈數。寒熱可以錯雜、轉化，危重時可出現真假。
- 虛證是正氣不足（氣虛、血虛、陰虛、陽虛），實證是邪氣亢盛或病理產物停聚；喜按為虛，拒按為實。虛實可以夾雜、轉化與真假。
- 陰陽為總綱：表、熱、實屬陽，裡、寒、虛屬陰；亡陰、亡陽都是危急證候。
- 八綱的運用：先定表裡，再辨寒熱、虛實，最後歸納陰陽；一個證可以拆成病位與病性，即證素。

## 名詞

- **八綱**：表、裡、寒、熱、虛、實、陰、陽八個辨證綱領，是各種辨證方法的基礎。
- **表**：病位淺在肌表，多見於外感初期，以惡寒發熱並見、脈浮為特點。
- **裡**：病位深在臟腑、氣血、骨髓，以臟腑症狀為主，脈多沉。
- **表裡**：辨別病位深淺的一對綱領，是八綱之一。
- **病位**：疾病所在的部位，例如表、裡、某一臟腑。
- **病性**：疾病的性質，例如寒、熱、氣虛、陰虛、痰、瘀、氣滯。
- **證素**：構成證的最小單位，由病位與病性組成，例如脾的陽虛、肝的氣滯。
- **寒熱**：辨別病性屬寒還是屬熱的一對綱領；寒熱要再分虛實。
- **虛實**：辨別邪正盛衰的一對綱領；虛指正氣不足，實指邪氣亢盛。

## 與本 App 對照

- **三把尺**：App 把八綱寫成三把以「平均健康的人」為零點的尺：寒熱、虛實與表，見［學習書 第二章］。汗出（腠理開）把虛實尺往虛推，無汗（腠理閉）往實推，這就是表虛與表實。
- **陰陽由三把尺推得**：熱而不虛屬陽；寒而不實屬陰；熱而兼虛（陰虛內熱）也歸陰；只有實屬陽，只有虛屬陰；寒而兼實（寒實）標示為「錯雜」；都不明顯則為「平衡」。八綱由盤面推得的方法見［SOP §10.4］。
- **先看地圖，再定八綱**：問診時，App 會先依幾個關鍵症狀做「八綱初判」，但它只用來決定問哪些題、檢查答案是否矛盾；真正的八綱等全部證據合成盤面之後才算出來，見［SOP §8.2］。這正是本章「不被單一症狀牽著走」的道理。
- **證型的八綱位置**：［證型 EX1 風寒束表］是表寒實；［證型 EX2 太陽中風］是表虛；［證型 EX3 風熱犯表］是表熱；［證型 SP2 脾陽虛］是裡虛寒，正是本章的例子；［證型 LV2 肝火上炎］是裡實熱；［證型 KD1 腎陰虛］是裡虛熱；［證型 SP4 痰濕內阻］是裡實。
- **證素**：App 把每個證型拆成病位 × 病性的證素，例如［證素 表寒］、［證素 脾陽虛］、［證素 腎陰虛］、［證素 胃火熱］、［證素 肝氣滯］，見［SOP §9.3］。證型庫裡找不到時，App 也會用證素拼出一個描述。

**模型的簡化**：「半表半裡」不放在尺上，而由證型的分流處理。寒熱錯雜、虛實夾雜時，App 不硬算一個平均，而是標示「錯雜」、降低信心並建議就醫。寒熱真假與虛實真假需要醫師的親自診察，App 不嘗試判斷；亡陰、亡陽等危急表現由紅旗篩檢處理。

## 練習

1. （選擇）下列最能說明病在表的是：（A）但熱不寒（B）惡寒發熱並見、脈浮（C）寒熱往來（D）腹痛拒按。
2. （選擇）腹部脹滿，按之不痛，時減時復，多屬：（A）實熱（B）實寒（C）虛寒（D）濕熱。
3. （簡答）列表比較寒證與熱證的鑑別要點。
4. （簡答）什麼是真熱假寒與真寒假熱？辨別真假的要點有哪些？
5. （簡答）什麼是虛實夾雜？舉一個例子說明「本虛標實」。
6. （簡答）比較亡陰與亡陽的表現，並說明為什麼兩者都必須立即就醫。
7. （案例）某人三天前淋雨後怕冷、發熱、無汗、頭痛身痛、鼻塞流清涕，舌苔薄白，脈浮緊。用八綱逐一分析，並歸納其證。
