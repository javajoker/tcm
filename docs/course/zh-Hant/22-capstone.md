這是全書的最後一章。前面二十一章分別講了理論、診斷、治法、本草、方劑、臨床、養生與典籍；這一章把它們整合起來，討論四個問題：一個完整的臨床推理應該怎麼走？怎樣避免推理的錯誤？哪些情況必須立即轉診，中醫藥的安全有哪些面向？學習中醫的人應該遵守什麼倫理？最後回顧全書中模型的限度，並提出總結專題的做法。

## 學習目標

1. 說明完整的臨床推理流程，並能依流程分析一個案例。
2. 掌握鑑別推理的方法，說出常見的推理陷阱。
3. 熟記各系統的危險徵象與轉診原則。
4. 說明中醫藥安全的主要面向：藥物本身、交互作用、特殊人群、誤用與不良反應。
5. 說明醫學倫理的要點，以及學習者應守的界限。
6. 回顧模型的限度，並完成一份總結專題。

## 一、臨床推理的完整流程

一次完整的中醫診察，可以分為十個步驟：

1. **安全篩檢**：先問有沒有必須立即就醫的情況。
2. **收集資料**：四診、發病經過、過去的疾病、正在使用的藥物與過敏。
3. **整理資料**：找出主症與兼症，評估每一筆資料的可信度，注意互相矛盾之處。
4. **辨證**：以八綱定大方向，再用臟腑、六經或衛氣營血等方法定位定性，得出證型或證素。
5. **鑑別**：與相近的證型比較，找出支持與反對的證據。
6. **立法**：依證確定治則與治法。
7. **選方與其他手段**：依法選方加減，或選擇針灸、飲食、起居等方法。
8. **安全核對**：檢查禁忌、配伍、特殊人群與藥物交互。
9. **解釋與溝通**：向病人說明判斷的理由、治療的方向與注意事項。
10. **追蹤與調整**：觀察變化，證變則法變，不適持續或加重時重新評估。

這個流程把全書的內容串成一條線：第一步與第八步是安全（第十八章與本章），第二、三步是四診（第九、十章），第四、五步是辨證（第十一至十三章），第六、七步是治法、本草與方劑（第十四至十七章），第九、十步則體現了恆動觀與以平為期（第一章）。

## 二、鑑別推理

### （一）推理的方法

辨證是一種推理：手上有一組證據，要找出最能解釋它們的病機。推理的方法是：

1. **提出假設**：依主症想到幾個可能的證型。
2. **核對證據**：每一個假設，有哪些症狀支持它？有哪些症狀反對它？它的關鍵症狀在不在？
3. **找鑑別點**：兩個假設難分時，找出「一個很看重而另一個不看重」的症狀，加以追問。
4. **下結論並保持開放**：選出最能解釋全部證據的證，但記得新的資料可能改變結論。

### （二）常見的鑑別

| 相近的證型 | 鑑別點 |
|---|---|
| 脾氣虛與脾陽虛 | 有沒有寒象：腹痛喜溫喜按、畏寒肢冷、苔白滑、脈沉遲 |
| 肝氣鬱結與肝胃不和 | 有沒有胃的症狀：胃脘脹痛、噯氣、泛酸 |
| 肝氣鬱結與肝火上炎 | 有沒有火象：急躁、口苦、面紅目赤、舌紅苔黃、脈弦數 |
| 腎陰虛與腎陽虛 | 寒熱：五心煩熱、盜汗，還是畏寒肢冷、夜尿多 |
| 心脾兩虛與心腎不交 | 伴隨的是食少便溏、面色萎黃，還是五心煩熱、腰痠、舌紅少苔 |
| 痰濕內阻與濕熱蘊結 | 有沒有熱象：口苦、小便短黃、苔黃膩、脈滑數 |
| 風寒束表與風熱犯表 | 寒熱的比重、有沒有咽痛口渴、苔白或黃、脈緊或數 |
| 太陽中風與營衛不和 | 是新近的外感，還是平時並無他病而反覆發熱自汗 |
| 肺氣虛與營衛不和 | 有沒有氣短、聲低等肺氣虛的表現 |

### （三）推理的陷阱

1. **先入為主**：一開始就認定某個證，之後只找支持它的證據。
2. **只看單一症狀**：例如看到失眠就認定是心的問題，忽略了胃不和、肝火、痰熱。
3. **忽略反對的證據**：明確的「沒有」同樣是證據；例如沒有寒象，就不太像脾陽虛。
4. **誤用「但見一證便是」**：這句話說的是關鍵症狀，不是任何一個症狀。
5. **把背景當證據**：體質、季節、八字只是背景，不能代替症狀。
6. **忽略危險徵象**：辨證再精細，也不能取代對危急情況的處理。

### （四）資訊不足時

資料不夠或互相矛盾時，正確的態度是：承認不確定，收集更多資料，降低判斷的信心；必要時請醫師親自診察。說「資訊不足」比勉強給一個答案更負責任。

### （五）一個案例

某人近兩個月入睡困難、多夢易醒，白天疲倦、健忘，食慾差，飯後腹脹，大便偏溏，面色萎黃；沒有五心煩熱與盜汗，口不苦，痰不多；舌淡，苔薄白，脈細弱。

1. **安全篩檢**：沒有胸痛、心悸暈厥、情緒低落或自傷念頭等危險徵象。
2. **主症**：失眠（多夢易醒）；兼症：健忘、疲倦、食少、腹脹、便溏、面色萎黃。
3. **提出假設**：失眠的常見證型有心脾兩虛、心腎不交、痰熱擾心、肝血不足、胃不和。
4. **核對證據**：食少、腹脹、便溏、乏力支持脾虛；健忘、多夢、舌淡、脈細支持心血虛；沒有五心煩熱與盜汗，反對心腎不交；口不苦、痰不多、苔不膩，反對痰熱擾心；沒有目乾、肢麻，肝血不足較不像；沒有飽食後臥不安，胃不和也不像。
5. **結論**：心脾兩虛。治法方向是補益心脾、養血安神。
6. **安全與溝通**：若用藥，必須由醫師診察後決定；生活上規律作息、減少思慮、飲食清淡易消化；若失眠持續或出現情緒問題，應就醫。

## 三、危險徵象與轉診

### （一）各系統的危險徵象

| 系統 | 必須立即就醫的情況 |
|---|---|
| 心血管 | 胸痛或胸悶，尤其伴冷汗、氣短、噁心，或疼痛牽連左臂、下顎、背部；心悸伴暈厥；脈搏極快、極慢或明顯不規則 |
| 神經 | 突然單側肢體無力或麻木、口眼歪斜、言語不清；突然劇烈頭痛；意識改變；抽搐 |
| 呼吸 | 呼吸困難、喘促；咯血 |
| 消化 | 嘔血、黑便或便血；劇烈腹痛或腹部變硬；持續嘔吐；吞嚥困難 |
| 全身 | 高熱不退；不明原因的體重下降；夜間大汗伴消瘦；摸到不明的腫塊 |
| 婦產 | 懷孕期間出血或腹痛；異常的陰道出血 |
| 兒童 | 高熱、精神萎靡、拒食、嘔吐腹瀉不止、呼吸急促 |
| 精神 | 傷害自己或他人的念頭——必須立即向醫療機構或緊急求助專線求助 |
| 過敏 | 嘴唇、舌頭或喉嚨腫脹，呼吸困難，全身大片風團 |

### （二）轉診的原則

1. **寧可早，不可遲**：不確定時，當作有危險處理。
2. **先救急，後辨證**：危急的情況先處理，辨證留到之後。
3. **說清楚理由**：告訴病人為什麼要就醫、要去哪裡、要說什麼。
4. **知道自己的界限**：超出自己能力或資格的情況，交給適當的專業人員。

## 四、中醫藥安全

### （一）藥物本身

- **毒性**：有毒的藥物要經過炮製，由醫師掌握使用；「無毒」也不等於無害（第十五章）。
- **品種**：藥材的品種混淆可能造成嚴重的傷害，例如歷史上曾作為木通使用的關木通。
- **品質**：藥材可能受到重金屬、農藥殘留、摻雜或霉變的影響，應從合格的來源取得。
- **份量與療程**：份量與療程都影響安全；古人主張「中病即止」。

### （二）交互作用

- **中藥之間**：十八反、十九畏等配伍禁忌。
- **中藥與西藥**：例如活血藥與抗凝血藥、甘草與某些利尿藥、麻黃與降血壓藥；正在使用藥物的人，任何中藥都要先告知醫師與藥師。

### （三）特殊人群

孕婦、哺乳期婦女、嬰幼兒、高齡者、肝腎功能不全的人、過敏體質的人，用藥都要特別謹慎，必須由醫師決定。

### （四）常見的誤用

- 自行依網路或他人的經驗用藥；
- 把補藥當保健品長期服食；
- 以為「天然」就等於「安全」；
- 有病不就醫，只靠食療或偏方。

### （五）出現不良反應時

立即停止使用，儘快就醫，並把使用過的藥物或藥材帶給醫師看。

## 五、醫學倫理

### （一）大醫精誠

唐代孫思邈在《備急千金要方》卷首的〈大醫精誠〉一文中，提出醫者必須「精」與「誠」：「精」是醫術要精湛，因為醫道是「至精至微」之事，不可粗心；「誠」是品德要誠篤，對待病人不分貴賤貧富、親疏遠近，一視同仁，不求名利，不炫耀自己、不詆毀他人。這篇文章至今仍是中醫醫德的經典表述。

### （二）現代醫學倫理的原則

1. **尊重自主**：病人有權了解自己的病情與治療的選擇，並自主決定；醫者要說明清楚，取得同意。
2. **不傷害**：任何診治都要先考慮可能的傷害。
3. **行善**：以病人的利益為優先。
4. **公正**：公平對待每一位病人。
5. **保密**：尊重病人的隱私。
6. **誠實與能力的界限**：不誇大療效，不隱瞞不確定；超出能力時轉介。

### （三）學習者的界限

學了中醫，不等於可以行醫。診斷與處方是醫師的專業行為，受法律規範，需要經過完整的訓練與執業資格。學習者可以用所學來照顧自己的生活、理解醫師的說明、與醫師討論，但不應為他人診斷或開藥；與人分享知識時，也要說清楚它的限度。

## 六、模型的限度：全書回顧

本書每一章都說明了本專案的模型在那一個主題上的簡化。把它們放在一起，可以看到模型的全貌：

| 主題 | 模型怎麼做 | 主要的簡化 |
|---|---|---|
| 陰陽 | 寒熱、虛實、表三把尺 | 轉化、格拒、亡陰亡陽不在模型中 |
| 五行 | 五行功能值與傳變壓力 | 傳變係數是線性近似，只取一步 |
| 臟腑與氣血 | 十個臟腑各記氣血陰陽，加上六邪、病理產物與營衛 | 三焦、心包、奇恆之腑、津液、精、神沒有欄位 |
| 四診 | 以問診為主，舌脈為選填的自我觀察 | 看不到舌、摸不到脈，可信度打折 |
| 辨證 | 二十三個證型與證素 | 不辨病；許多證型不在庫中 |
| 治療 | 三十三首方劑、君臣佐使的量化、方解五步 | 盤面沒有少陽；劑型與煎服法不計算 |
| 本草 | 七百多味藥的座標 | 座標由規則推得，是草稿 |
| 先驗 | 先天、流年、時令三塊常模 | 有上限、不加分、可關閉 |
| 安全 | 紅旗、範圍、配伍、妊娠、交互、過敏、毒性 | 規則是條列的，不可能窮盡 |

這些簡化提醒我們兩件事：第一，模型的價值在於每一步都說得出理由、查得到出處，讓傳統的推理變得清楚可見；第二，模型永遠不能取代醫師的親自診察。學習模型，是為了更清楚地看見傳統，不是用模型取代傳統。

## 七、總結專題

### （一）專題的選擇

從下列五種題目中選一種，整合全書的知識完成一份專題：

1. **一個證型的完整研究**：從理論（陰陽、臟腑、病因病機）到四診表現、鑑別、治法、代表方與調養，再對照 App 中的記錄，指出模型的簡化。
2. **一首方劑的方解**：依病機、治法、方、藥、未盡五步分析一首方，並介紹它的類方與加減。
3. **一個病證的辨證地圖**：選一個常見病證，畫出它的常見證型、鑑別要點與危險徵象。
4. **一份個人的四時養生計畫**：依自己的體質傾向與四季，設計飲食、起居、運動與情志的調養計畫（只限日常養生，不涉及用藥）。
5. **一句經文的歷代讀法**：選一句經文，整理它在不同典籍與注家中的理解，以及它在今天教材與模型中的位置。

### （二）要求

- 所有的論點都要說明依據；引用古籍原文時，標明書名與篇章，並附白話解說。
- 不使用任何真實個人的資料，不對任何真實的人作診斷。
- 不寫任何份量，不建議任何人用藥。
- 必須包含一節「安全與限度」：說明這個主題中有哪些危險徵象、哪些情況必須就醫、模型在哪裡簡化。

### （三）評量的面向

| 面向 | 看什麼 |
|---|---|
| 正確性 | 概念、證型、方劑與藥性的描述是否正確 |
| 完整性 | 是否從理論貫穿到應用，理法方藥一以貫之 |
| 推理 | 鑑別是否清楚，是否兼顧支持與反對的證據 |

| 出處 | 引用是否準確，是否區分原文與解釋 |

## 古籍原文選讀

> 「謹守病機，各司其屬」——《素問·至真要大論》

**白話**：謹慎地把握病機，分辨每一種表現所屬的病位與病性。臨床推理的核心，就是從表現推回病機；本章的鑑別方法，正是這句話的具體做法。

> 「但見一證便是，不必悉具」——《傷寒論·辨太陽病脈證並治中》

**白話**：只要見到一部分關鍵症狀就可以確定，不必所有症狀都具備。這句話鼓勵醫者抓住關鍵，但也常被誤用：它說的是「關鍵的」症狀，而不是任何一個症狀；缺少關鍵症狀時，就要懷疑另有他證。

> 「大毒治病，十去其六」——《素問·五常政大論》

**白話**：用毒性大的藥治病，病去了六成就要停止。這是古人用藥安全最具體的提醒：治療本身也有風險，必須適可而止，剩下的交給調養與身體自己的恢復。

> 「無盛盛，無虛虛」——《素問·五常政大論》

**白話**：不要使實者更實，不要使虛者更虛。誤補與誤攻都會傷人；這句話是「不傷害」原則在中醫中的表述。

> 「有故無殞，亦無殞也」——《素問·六元正紀大論》

**白話**：古人認為，孕婦若確實有病，用藥針對病邪就不會傷胎。這是需要醫師親自診察才能作的判斷；今天的規範對孕期一律從嚴，學習者更不可據此自行用藥。把這句話放在這裡，是提醒我們：古籍中的許多說法需要放在今天的安全知識之下理解。

> 「聖人雜合以治，各得其所宜。故治所以異而病皆愈者，得病之情，知治之大體也」——《素問·異法方宜論》

**白話**：高明的醫者綜合運用各種方法，使每個病人都得到最適合的治療；治法不同而病都能痊癒，是因為掌握了病情的實質與治療的大原則。這是全書反覆強調的精神：方法要因人而異，但都出於對病情的正確理解。

> 「治病必求於本」——《素問·陰陽應象大論》

**白話**：治病一定要找到根本。本書從這句話開始，也以這句話作結：所有的理論、診法、治法與方藥，最後都要回到「求本」——找出真正的病機，並在安全的前提下恢復平衡。

## 本章小結

- 臨床推理的十個步驟：安全篩檢、收集資料、整理資料、辨證、鑑別、立法、選方與其他手段、安全核對、解釋與溝通、追蹤與調整。
- 鑑別推理：提出假設、核對支持與反對的證據、找鑑別點、下結論並保持開放；避免先入為主、只看單一症狀、忽略反對證據、誤用「但見一證便是」、把背景當證據與忽略危險徵象。
- 危險徵象涵蓋心血管、神經、呼吸、消化、全身、婦產、兒童、精神與過敏；轉診寧早勿遲，先救急後辨證。
- 中醫藥安全包括藥物本身的毒性、品種與品質，交互作用，特殊人群，常見的誤用，以及不良反應的處理。
- 醫學倫理：大醫精誠；尊重自主、不傷害、行善、公正、保密、誠實；學習者不為他人診斷或開藥。
- 模型的價值在於清楚可查，模型的限度在於永遠不能取代醫師的診察。
- 總結專題整合全書，要求說明依據、不涉及真實個人、不寫份量，並包含安全與限度。

## 名詞

- **中醫師**：受過完整專業訓練並依法取得執業資格、能親自診察並處方的醫師；學習者不能取代其角色。
- **辨證論治**：中醫臨床的核心方法；本章的十步流程是它的完整展開。
- **治未病**：未病先防、既病防變、瘥後防復；也是學習中醫最實際的用處。

## 與本 App 對照

- **流程**：本章的十步流程，與 App 的流程一一對應：安全篩檢、基本資料與四診、標準化、先驗、體質、八綱初判、辨證、盤面、鑑別與信心、論治、安全過濾、解釋與輸出，見［SOP §1］。
- **鑑別與信心**：App 在兩個證型分數接近時，找出最能分辨它們的症狀追問，並在結果頁說明，見［SOP §11.2］；結論可不可靠，看核心題答了多少、第一名領先多少與資料的整體可信度，資料不足時就說「資訊不足」，見［SOP §11.3］。本章的案例對應［證型 HT1 心脾兩虛］，鑑別時排除的是［證型 HT2 心腎不交］、［證型 HT3 痰熱擾心］與［證型 LV3 肝血虛］。
- **紅旗**：該立刻就醫的情況先問；回答「不確定」也當作「是」，見［SOP §2.3］。
- **安全層**：範圍、藥對、妊娠、藥物交互、過敏與毒性的規則，見［SOP §13.1］、［SOP §13.2］、［SOP §13.3］與［學習書 第十二章］；被規則移除的東西不會悄悄消失，結果頁會列出移除了什麼、為什麼。
- **誠實與界限**：App 的規則與數據都是草稿，公開版本會清楚標示；結果是一份整理過的參考，不是診斷，也不是處方，見［SOP §14.3］。驗證的計畫與待討論的事項都公開記錄，見［SOP §附錄 C］與［SOP §附錄 D］。
- **隱私**：評估只在使用者自己的裝置上進行；生辰資料是選填的，預設不保存。

**模型的簡化**：本章第六節的表就是全書模型簡化的總覽。最重要的一點是：App 能整理證據、說明理由、提醒危險，但不能看見病人、不能觸摸病人，也不能承擔醫師的責任。
